# Ruleset

## 어떤 노드인가요?

Ruleset 노드를 사용하면 Ruleset(규칙 세트) 객체를 생성하고 출력할 수 있습니다. 규칙 세트는 이름과 규칙 목록으로 구성되며, 워크플로에서 에이전트와 같은 다른 노드와 함께 사용할 수 있습니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- LLM으로부터 응답을 생성하는 다른 노드의 출력을 제한하거나 유도하고자 할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Ruleset 노드를 추가합니다.
1. "name" 파라미터를 설정하여 규칙 세트의 이름을 정의합니다 (선택 사항, 기본값: "Behavior").
1. "rules" 파라미터를 설정하여 규칙 세트의 규칙 목록을 정의합니다 (선택 사항, 기본값: 빈 문자열, 쉼표로 구분).
1. 흐름에 연결합니다 (특히 Ruleset 파라미터를 가진 노드에 연결).

### 파라미터 (Parameters)

- **name**: 이 노드에서 생성되어 출력되는 단일 파라미터
- **rules**: 이 노드에서 생성되어 출력되는 단일 파라미터

### 출력 (Outputs)

- **ruleset**: 다른 노드의 속성 또는 입력으로 사용되는 출력 Ruleset 객체

## 예시

다음과 같은 이름과 규칙을 가진 새 규칙 세트를 생성하려는 경우:

1. 워크플로에 Ruleset 노드를 추가합니다.

1. "name" 파라미터를 다음과 같이 설정합니다:

    ```
    MyBehavioralRules
    ```

1. "rules" 파라미터를 다음과 같이 설정합니다:

    ```
    Rule 1: This is my first rule.
    Rule 2: This is my second rule.
    Rule 3: This is my third rule.
    ```

1. 이 노드의 출력을 에이전트의 Ruleset 파라미터에 연결합니다.

## 중요 참고 사항

- Ruleset 노드는 문자열 값만 지원합니다.
- 초기값이 제공되지 않으면 name과 rules에 기본값이 사용됩니다.
- 이 노드는 다른 파라미터나 속성을 기반으로 동적 Ruleset 객체를 생성하기 위해 다른 노드와 결합하여 사용할 수 있습니다.
