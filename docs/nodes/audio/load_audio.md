# LoadAudio

## 어떤 노드인가요?

LoadAudio 노드는 오디오 파일을 워크플로로 가져올 수 있게 해주는 간단한 기본 구성 요소입니다. 프로젝트에서 사용할 수 있도록 오디오 녹음 파일을 불러오는 것으로 생각하면 됩니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 다른 노드에서 생성된 오디오 파일을 사용할 때
- 워크플로의 다른 노드로 오디오 파일을 전달할 때
- 프로젝트의 일부로 오디오 파일을 처리할 때

## 사용 방법

### 기본 설정

1. 워크플로에 LoadAudio 노드를 추가합니다.
1. 오디오 소스(예: Transcribe Audio 노드 등)에 연결합니다.

### 파라미터 (Parameters)

- **audio**: 로드할 오디오 (다른 노드의 출력에 연결할 수 있음)

### 출력 (Outputs)

- **audio**: 워크플로의 다른 노드에서 사용할 수 있는 로드된 오디오

## 예시

컴퓨터에 녹음해 둔 오디오 파일이 있고 이를 다른 곳에서 사용하려는 경우:

1. LoadAudio 노드를 생성합니다.
1. 오디오 로드 버튼을 클릭하고 디스크에서 오디오 파일을 선택합니다.
1. LoadAudio 노드가 해당 오디오를 워크플로의 나머지 부분에서 사용할 수 있도록 제공합니다.

## 중요 참고 사항

- LoadAudio 노드는 오디오 자체를 변경하지 않고 그대로 전달(Pass through)합니다.
- 파일 브라우저 아이콘을 클릭하여 컴퓨터에서 오디오 파일을 선택할 수 있습니다.
- 재생(Play) 버튼을 클릭하여 오디오를 재생할 수 있습니다.
