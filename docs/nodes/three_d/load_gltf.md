# Load3D

## 어떤 노드인가요?

Load3D는 GLTF 파일을 워크플로로 가져올 수 있게 해주는 기본 구성 요소입니다. 다양한 소스에서 3D 모델을 로드하여 프로젝트 내에서 사용하고 표시할 수 있습니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 파일에서 GLTF 모델을 사용할 때
- 워크플로의 다른 노드로 GLTF 모델을 전달할 때
- 프로젝트의 일부로 GLTF 모델을 표시할 때
- 워크플로에서 사용할 GLTF 모델의 스크린샷을 생성할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Load3D 노드를 추가합니다.
1. GLTF 데이터 소스(파일 브라우저, URL 또는 다른 노드 출력)에 연결합니다.

### 파라미터 (Parameters)

- **gltf**: 로드할 GLTF 파일 또는 URL. 다른 노드의 출력에 연결하거나 파일 브라우저를 통해 선택할 수 있습니다.

### 출력 (Outputs)

- **gltf**: 워크플로의 다른 노드에서 사용할 수 있는 로드된 GLTF 아티팩트
- **image**: 로드된 GLTF 모델의 이미지 스냅샷 (모델이 로드되고 스냅샷이 저장된 후 사용 가능)

## 중요 참고 사항

- 노드는 파일 브라우저를 사용하여 컴퓨터에서 GLTF 파일을 로드할 수 있습니다.
- GLTF 모델이 로드되면 'Save Snapshot' 버튼(UI에서 제공되는 경우)을 사용하여 이미지로 스냅샷을 저장할 수 있습니다.
- 'image' 출력 파라미터는 스냅샷이 저장된 후에만 사용할 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **모델이 표시되지 않음**: GLTF 소스가 이 노드에 올바르게 연결되었거나 유효한 파일이 선택되었는지 확인하세요.
- **잘못된 파일 형식**: 올바른 GLTF 파일 또는 URL을 제공하고 있는지 확인하세요.
- **이미지 출력을 사용할 수 없음**: 이미지 출력은 UI에서 스냅샷 저장을 명시적으로 수행했을 때만 생성됩니다. 이 동작을 실행했는지 확인하세요.
