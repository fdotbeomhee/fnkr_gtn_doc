# DescribeImage

## 어떤 노드인가요?

DescribeImage 노드는 인공지능(AI)을 사용하여 제공된 이미지에 대한 텍스트 설명을 생성하는 노드입니다. 비전(Vision) 기능을 갖춘 모델을 활용하여 이미지 콘텐츠를 분석하고, 사용자가 입력한 구체적인 프롬프트 지침에 따라 상세한 설명을 작성합니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 이미지에 대한 텍스트 설명 생성
- 시각적 콘텐츠로부터 정보 추출
- 웹 접근성을 위한 대체 텍스트(Alt text) 생성
- 사진, 다이어그램 또는 기타 시각 매체의 내용 분석
- 후속 처리를 위해 시각 정보를 텍스트 형식으로 변환

## 사용 방법

### 기본 설정

1. 워크플로우에 DescribeImage 노드를 추가합니다.
1. 이미지 소스를 "image" 입력에 연결합니다.
1. (선택 사항) "prompt" 필드에 구체적인 지침을 입력합니다.
1. 노드를 실행하여 이미지에 대한 설명을 생성합니다.

!!! info "원하는 내용을 구체적으로 작성하세요"

    프롬프트를 작성할 때 관심 있는 요소를 명확히 명시하세요. 예를 들면 다음과 같습니다:

    - 색상 정보: "컬러 팔레트, 빛과 그림자의 색상, 채도 및 명도를 묘사해 주세요"
    - 인물 정보: "등장인물의 성별, 연령, 복장, 자세, 표정, 행동을 자세히 설명해 주세요"

    프롬프트가 구체적일수록 원하는 형태의 결과를 얻을 가능성이 높아집니다.

### 파라미터 (Parameters)

- **agent**: 이미지 설명에 사용할 기존 에이전트 구성 (선택 사항)
- **model**: 비전 지원 프롬프트 모델 선택 (또는 Prompt Model Config 연결). **agent**가 연결된 경우 무시됩니다.
- **image**: 설명을 생성할 대상 이미지 (필수)
- **prompt**: 이미지를 어떻게 설명할지에 대한 지침 (기본값: "Describe the image")
- **description_only**: 활성화된 경우 대화 형식 없이 설명만 반환합니다.
- **output_schema**: 구조화된 출력을 위한 선택적 JSON 스키마. JSON 스키마 객체 또는 JSON 문자열을 허용합니다. 연결 시 **output**이 JSON 형식으로 전환됩니다.

### 출력 (Outputs)

- **output**: 이미지 설명. 기본적으로 **text**를 반환하며, **output_schema**가 제공된 경우 **JSON**을 반환합니다.
- **agent**: 설명 생성에 사용된 에이전트 객체 (다른 노드에 연결 가능)

## 예시

풍경 사진에 대한 상세한 설명을 얻고자 하는 경우:

1. 워크플로우에 DescribeImage 노드를 추가합니다.
1. 다른 노드의 이미지 출력을 "image" 입력에 연결합니다.
1. "prompt" 필드에 다음과 같이 입력합니다: "Describe this landscape in detail, including colors, features, and mood" (색상, 지형적 특징, 분위기를 포함하여 이 풍경을 자세히 설명해 주세요)
1. 노드를 실행합니다.
1. "output"에 풍경 이미지에 대한 상세한 설명이 출력됩니다.

### 구조화된 출력 예시 (JSON)

특정 JSON 구조로 출력을 받고자 하는 경우:

1. `CreateAgentSchema` 노드를 추가하고 원하는 형식의 예시 JSON 객체를 제공합니다.
1. `CreateAgentSchema.schema`를 `DescribeImage.output_schema`에 연결합니다.
1. `DescribeImage` 노드를 실행합니다.
1. `output`에 스키마와 일치하는 JSON이 반환됩니다 (일치하지 않을 경우 유효성 검사 실패).

## 중요 참고 사항

- 환경 변수에 유효한 Griptape API 키(`GT_CLOUD_API_KEY`)가 설정되어 있어야 합니다.
- 기본적으로 Griptape Cloud API를 통해 `gpt-5.2` 모델을 사용합니다.
- 프롬프트가 제공되지 않으면 기본값인 "Describe the image"가 사용됩니다.
- 이미지가 제공되지 않으면 "No image provided"가 출력됩니다.
- 보다 정교한 동작 제어를 위해 직접 구성한 에이전트를 연결할 수 있습니다.
- 설명의 품질은 제공된 이미지의 선명도와 내용에 따라 달라집니다.

## 자주 묻는 질문 및 문제 해결

- **API 키 누락**: 환경 변수에 Griptape API 키가 올바르게 설정되어 있는지 확인하세요.
- **이미지 미제공**: "image" 입력에 유효한 이미지가 연결되어 있는지 확인하세요.
- **설명 품질 저하**: 묘사하고자 하는 이미지의 특정 측면을 프롬프트에 더 구체적으로 명시해 보세요.
- **처리 오류**: 지나치게 복잡한 이미지나 특이한 콘텐츠의 경우 설명의 정확도가 떨어질 수 있습니다.
