# ExtendCanvas

## 어떤 노드인가요?

ExtendCanvas 노드를 사용하면 대상 종횡비(가로세로 비율)나 사용자 지정 크기에 맞게 이미지 주변의 캔버스를 확장할 수 있습니다. 원본 콘텐츠를 자르지 않고 여백(패딩)을 추가하거나 특정 종횡비를 생성하고, 다양한 출력 형식에 맞게 이미지를 준비하는 데 적합합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지 주변에 여백이나 마진을 추가할 때
- 특정 종횡비(16:9, 4:3, 정사각형 등)를 생성할 때
- 다양한 소셜 미디어 형식에 맞게 이미지를 준비할 때
- 텍스트 오버레이나 그래픽을 위한 공간을 확보할 때
- 워크플로우 전반에 걸쳐 일관된 이미지 크기를 유지할 때
- 인쇄 레이아웃용 이미지를 준비할 때
- 이미지 주변에 테두리나 프레임을 추가할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 ExtendCanvas 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 대상 종횡비 또는 사용자 지정 크기를 설정합니다.
1. 확장된 이미지는 "output" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

#### 캔버스 설정 (Canvas Settings)

- **target_aspect_ratio**: 출력할 원하는 종횡비

    - **16:9**: 와이드스크린 포맷
    - **4:3**: 표준 포맷
    - **1:1**: 정사각형 포맷
    - **3:2**: 사진 포맷
    - **21:9**: 울트라와이드 포맷
    - **Custom**: 사용자 지정 크기 설정

- **custom_width** (픽셀): "Custom" 종횡비 사용 시 사용자 지정 너비

- **custom_height** (픽셀): "Custom" 종횡비 사용 시 사용자 지정 높이

#### 확장 설정 (Extension Settings)

- **extension_method**: 캔버스를 확장하는 방법

    - **center**: 새 캔버스의 중앙에 원본 이미지를 배치
    - **top_left**: 원본 이미지를 좌측 상단에 배치
    - **top_right**: 원본 이미지를 우측 상단에 배치
    - **bottom_left**: 원본 이미지를 좌측 하단에 배치
    - **bottom_right**: 원본 이미지를 우측 하단에 배치

- **background_color** (16진수 색상 코드, 기본값: #ffffff): 확장된 영역의 배경 색상

- **background_opacity** (0.0-1.0, 기본값: 1.0): 배경 색상의 불투명도

### 출력 (Outputs)

- **output**: 캔버스가 확장된 이미지

## 예시

일반적인 캔버스 확장 워크플로우:

1. LoadImage를 사용하여 이미지를 로드합니다.
1. 해당 이미지를 ExtendCanvas 노드의 "input_image" 파라미터에 연결합니다.
1. 캔버스 설정을 지정합니다:
    - 와이드스크린 포맷을 위해 target_aspect_ratio를 "16:9"로 선택
    - 이미지를 중앙에 배치하기 위해 extension_method를 "center"로 선택
    - 검은색 배경을 위해 background_color를 "#000000"으로 설정
1. "output"을 DisplayImage에 연결하여 결과를 확인합니다.

## 중요 참고 사항

- **비파괴 방식**: 원본 이미지 콘텐츠는 절대 잘리거나 수정되지 않습니다.
- **유연한 위치 지정**: 새 캔버스에서 원본 이미지를 배치할 위치를 자유롭게 선택할 수 있습니다.
- **종횡비 제어**: 모든 종횡비를 직접 생성하거나 사전 설정된 형식을 사용할 수 있습니다.
- **RGBA 지원**: 이 노드는 RGBA 이미지의 투명도를 보존합니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 중앙에 오지 않음**: extension_method 설정을 확인하세요.
- **잘못된 종횡비**: target_aspect_ratio 선택 항목을 확인하세요.
- **배경이 보이지 않음**: background_opacity가 0보다 큰지 확인하세요.

## 기술 세부사항

이 노드는 다음 작업을 수행합니다:

1. **캔버스 생성**: 대상 치수로 새 캔버스를 생성합니다.
1. **배경 채우기**: 지정된 배경 색상으로 캔버스를 채웁니다.
1. **이미지 배치**: 원본 이미지를 지정된 위치에 배치합니다.
1. **출력 생성**: 최종 확장된 이미지를 저장합니다.

이를 통해 원본 콘텐츠를 손실하지 않고 특정 출력 요구사항에 맞게 이미지를 준비할 수 있는 강력한 방법을 제공합니다.
