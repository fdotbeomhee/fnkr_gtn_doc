# RescaleImage

## 어떤 노드인가요?

RescaleImage 노드를 사용하면 치수, 스케일링 방식 및 품질을 정밀하게 제어하여 이미지 크기를 조정할 수 있습니다. 픽셀 기반 및 백분율 기반 크기 조정을 모두 지원하므로 특정 출력 요구사항에 맞게 이미지를 준비하거나 단일 소스에서 다양한 크기를 생성하는 데 적합합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 특정 치수로 이미지 크기를 조정할 때
- 백분율 비율로 이미지 크기를 확대/축소할 때
- 다양한 출력 형식에 맞게 이미지를 준비할 때
- 썸네일이나 미리보기 이미지를 생성할 때
- 웹 또는 인쇄용으로 이미지를 최적화할 때
- 여러 이미지의 크기를 일괄 조정할 때
- 크기를 조정하면서 종횡비(가로세로 비율)를 유지할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 RescaleImage 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 크기 조정 모드를 선택하고 대상 크기를 설정합니다.
1. 크기가 조정된 이미지는 "output" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

#### 크기 조정 설정 (Resize Settings)

- **resize_mode**: 새 크기를 결정하는 방식

    - **percentage**: 백분율로 크기 조정 (예: 50% = 절반 크기)
    - **pixels**: 정확한 픽셀 치수 설정

- **target_size** (픽셀, 기본값: 512): 픽셀 모드 사용 시 대상 크기

    - 너비 기준 스케일링: 너비를 설정하고 높이는 비례하여 조정
    - 높이 기준 스케일링: 높이를 설정하고 너비는 비례하여 조정

- **percentage_scale** (1-1000, 기본값: 100): 백분율 모드 사용 시 크기 비율

    - 50 = 절반 크기
    - 100 = 원본 크기
    - 200 = 2배 크기

#### 품질 설정 (Quality Settings)

- **resample_filter**: 리샘플링에 사용할 알고리즘
    - **lanczos**: 고품질, 느림 (대부분의 경우 권장)
    - **bicubic**: 우수한 품질, 중간 속도
    - **bilinear**: 낮은 품질, 빠름
    - **nearest**: 픽셀화 효과, 가장 빠름

### 출력 (Outputs)

- **output**: 크기가 조정된 결과 이미지

## 예시

일반적인 크기 조정 워크플로우:

1. LoadImage를 사용하여 이미지를 로드합니다.
1. 해당 이미지를 RescaleImage 노드의 "input_image" 파라미터에 연결합니다.
1. 크기 조정 설정을 지정합니다:
    - resize_mode를 "percentage"로 선택
    - 절반 크기 버전을 만들기 위해 percentage_scale을 50으로 설정
    - 고품질 처리를 위해 resample_filter를 "lanczos"로 선택
1. "output"을 DisplayImage에 연결하여 결과를 확인합니다.

## 중요 참고 사항

- **실시간 미리보기**: 파라미터를 조정하면 변경 사항이 실시간으로 적용됩니다.
- **종횡비 유지**: 이 노드는 원본의 종횡비를 유지합니다.
- **고품질 리샘플링**: Lanczos 리샘플링은 대부분의 사용 사례에서 최상의 품질을 제공합니다.
- **RGBA 지원**: 이 노드는 RGBA 이미지의 투명도를 보존합니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 너무 작음**: percentage_scale 또는 target_size를 늘리세요.
- **품질 저하**: 더 나은 품질을 위해 resample_filter를 "lanczos"로 설정하세요.
- **잘못된 치수**: resize_mode 및 대상 설정이 올바른지 확인하세요.

## 기술 세부사항

이 노드는 PIL의 리샘플링 알고리즘을 사용합니다:

- **Lanczos**: 고품질 리샘플링을 위해 Lanczos 커널 사용
- **Bicubic**: 우수한 품질을 위한 쌍입방(Bicubic) 보간법 사용
- **Bilinear**: 빠른 처리를 위한 쌍선형(Bilinear) 보간법 사용
- **Nearest**: 픽셀화된 결과를 위한 최근방 이웃(Nearest neighbor) 방식 사용

이를 통해 모든 워크플로우에 적합한 전문가급 이미지 크기 조정 기능을 제공합니다.
