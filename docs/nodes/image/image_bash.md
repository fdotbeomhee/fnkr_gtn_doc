# ImageBash

## 어떤 노드인가요?

ImageBash 노드를 사용하면 여러 이미지를 단일 캔버스에 결합하여 합성 이미지를 만들 수 있습니다. 사용자 지정 캔버스 크기와 배경 색상을 사용하여 콜라주, 이미지 그리드를 만들거나 여러 이미지를 하나의 응집력 있는 구도로 결합하는 데 적합합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지 콜라주 또는 그리드를 생성할 때
- 여러 이미지를 단일 구도로 결합할 때
- 이미지 모자이크 또는 패턴을 만들 때
- 이미지 갤러리 또는 포트폴리오를 구성할 때
- 비교를 위해 관련된 이미지들을 결합할 때
- 소셜 미디어용 이미지 레이아웃을 만들 때
- 이미지 기반 프레젠테이션을 제작할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 ImageBash 노드를 추가합니다.
1. 여러 이미지 소스를 "input_images" 입력에 연결합니다.
1. 캔버스 크기와 배경 색상을 설정합니다.
1. 합성된 이미지는 "output_image" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

#### 캔버스 설정 (Canvas Settings)

- **canvas_size**: 출력 캔버스의 크기

    - **Custom**: 사용자 지정 너비 및 높이 설정
    - **HD**: 1280x720
    - **Full HD**: 1920x1080
    - **4K**: 3840x2160
    - **Square**: 1024x1024
    - **Instagram Post**: 1080x1080
    - **Instagram Story**: 1080x1920

- **width** (픽셀, 기본값: 1920): 사용자 지정 캔버스 너비 (canvas_size가 "Custom"일 때)

- **height** (픽셀, 기본값: 1080): 사용자 지정 캔버스 높이 (canvas_size가 "Custom"일 때)

- **background_color** (16진수 색상 코드, 기본값: #ffffff): 빈 영역의 배경 색상

#### 이미지 입력 (Image Input)

- **input_images**: 결합할 이미지 목록 (여러 이미지 소스에서 연결 가능)

### 출력 (Outputs)

- **output_image**: 모든 입력 이미지가 결합된 합성 이미지

## 예시

일반적인 이미지 배싱(Image Bashing) 워크플로우:

1. LoadImage 노드를 사용하여 여러 이미지를 로드합니다.
1. 모든 이미지를 ImageBash 노드의 "input_images" 파라미터에 연결합니다.
1. 캔버스 설정을 지정합니다:
    - 1920x1080 캔버스를 위해 "Full HD"를 선택합니다.
    - 밝은 회색 배경을 위해 background_color를 "#f0f0f0"으로 설정합니다.
1. 노드가 캔버스에 이미지를 자동으로 정렬합니다.
1. "output_image"를 DisplayImage에 연결하여 결과를 확인합니다.

## 중요 참고 사항

- **자동 레이아웃**: 노드가 캔버스에 이미지를 자동으로 정렬합니다.
- **유연한 캔버스**: 사전 설정 크기 중에서 선택하거나 사용자 지정 치수를 설정할 수 있습니다.
- **배경 제어**: 빈 영역에 원하는 배경 색상을 자유롭게 지정할 수 있습니다.
- **다중 이미지 지원**: 개수에 상관없이 여러 입력 이미지를 처리할 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 표시되지 않음**: "input_images" 파라미터에 이미지를 제대로 연결했는지 확인하세요.
- **이미지가 너무 작음**: 캔버스 크기를 키우거나 원본 이미지 해상도를 확인하세요.
- **원치 않는 배경색**: background_color 파라미터를 원하는 값으로 조정하세요.

## 기술 세부사항

이 노드는 다음 작업을 수행합니다:

1. **캔버스 생성**: 지정된 크기와 배경 색상으로 새 캔버스를 생성합니다.
1. **이미지 정렬**: 캔버스에 입력 이미지를 자동으로 배치합니다.
1. **합성**: 모든 이미지를 단일 합성 이미지로 병합합니다.
1. **출력 생성**: 최종 합성본을 고품질 이미지로 저장합니다.

이를 통해 여러 소스로부터 복잡한 이미지 구도를 쉽게 생성할 수 있는 강력한 방법을 제공합니다.
