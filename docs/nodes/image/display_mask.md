# DisplayMask

## 어떤 노드인가요?

DisplayMask 노드는 입력 이미지에서 특정 채널(Red, Green, Blue 또는 Alpha)을 추출하여 마스크를 생성합니다. 마스크는 흰색 영역이 완전히 불투명한 영역을 나타내고 검은색 영역이 완전히 투명한 영역을 나타내는 그레이스케일(Grayscale) 이미지입니다. 이 노드는 이미지의 다양한 색상 채널을 시각화하고 작업하는 데 유용합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지의 투명도 정보를 시각적인 마스크로 추출할 때
- 특정 색상 채널(Red, Green, Blue)을 마스크로 추출할 때
- 이미지 편집 워크플로우를 위한 마스크를 생성할 때
- 이미지의 여러 채널을 시각적으로 확인할 때
- 다른 이미지 처리 노드에서 사용할 마스크를 생성할 때
- 이미지 파이프라인에서 투명도 또는 색상 채널 문제를 디버깅할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayMask 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. "channel" 드롭다운에서 원하는 채널을 선택합니다.
1. 생성된 마스크는 "output_mask" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

- **input_image**: 마스크를 생성할 원본 이미지 (다른 이미지 노드에서 연결 가능)
- **channel**: 마스크로 추출할 채널 (red, green, blue 또는 alpha)

### 출력 (Outputs)

- **output_mask**: 입력 이미지의 선택된 채널로부터 생성된 그레이스케일 마스크 이미지

## 예시

일반적인 워크플로우 패턴:

1. GenerateImage 또는 LoadImage와 같은 노드를 사용하여 이미지를 생성하거나 로드합니다.
1. 해당 이미지를 DisplayMask 노드의 "input_image" 파라미터에 연결합니다.
1. 원하는 채널을 선택합니다 (예: 투명도를 보려면 "alpha", 빨간색 채널을 보려면 "red").
1. DisplayMask 노드가 선택된 채널을 추출하여 시각적 마스크를 생성합니다.
1. "output_mask"를 DisplayImage에 연결하여 마스크를 보거나, 다른 마스크 처리 노드에 연결합니다.

## 채널 옵션

- **alpha**: 투명도 채널을 추출합니다 (기본값) - 이미지의 어느 부분이 투명한지 확인하는 데 유용합니다.
- **red**: 빨간색(Red) 채널을 추출합니다 - 이미지에서 빨간색 요소를 분리하는 데 유용합니다.
- **green**: 녹색(Green) 채널을 추출합니다 - 이미지에서 녹색 요소를 분리하는 데 유용합니다.
- **blue**: 파란색(Blue) 채널을 추출합니다 - 이미지에서 파란색 요소를 분리하는 데 유용합니다.

## 중요 참고 사항

- **채널 추출**: 노드는 입력 이미지에서 지정된 채널을 추출하여 마스크를 생성합니다.
- **그레이스케일 출력**: 결과 마스크는 선택된 채널에 대해 흰색이 높은 값, 검은색이 낮은 값을 나타내는 그레이스케일 이미지입니다.
- **실시간 처리**: 노드는 연결이 이루어지거나 입력 값 또는 채널 선택이 변경될 때 즉시 이미지를 처리합니다.
- **출력 형식**: 품질을 보존하기 위해 마스크는 PNG 파일로 저장됩니다.
- **이미지 모드 지원**: RGB, RGBA, 그레이스케일(L) 및 알파 포함 그레이스케일(LA) 이미지 모드를 지원합니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 없음**: 이미지 소스가 "input_image" 파라미터에 제대로 연결되어 있는지 확인하세요.
- **완전한 검은색 마스크**: 선택된 채널에 변화가 없거나 값이 낮음을 나타낼 수 있습니다.
- **완전한 흰색 마스크**: 선택된 채널의 값이 전체적으로 높음을 나타낼 수 있습니다.
- **지원되지 않는 모드 오류**: 이미지 형식이 선택된 채널을 지원하지 않을 수 있습니다 (예: RGB 이미지의 알파 채널).

## 기술 세부사항

이 노드는 채널 추출 로직을 사용하여 다음 작업을 수행합니다:

- URL에서 입력 이미지 로드
- 지정된 채널(red, green, blue 또는 alpha) 추출
- 이를 그레이스케일 마스크로 변환
- 결과를 새 이미지 아티팩트로 저장

RGB 이미지의 경우, RGB에는 알파 채널이 없으므로 알파 채널 선택 시 빨간색(Red) 채널로 대체(fallback)됩니다.
