# CombineMasks

## 어떤 노드인가요?

CombineMasks 노드는 **픽셀당 최대값**(합집합 연산, Union)을 취하여 여러 마스크 이미지 목록을 하나의 통합된 단일 마스크로 병합하는 노드입니다.

세그멘테이션(Segmentation) 노드에서 여러 개의 마스크가 생성되었을 때 후속 작업에서 사용할 단일 마스크가 필요한 경우 유용합니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 여러 세그멘테이션 마스크를 하나의 마스크로 결합
- 감지된 여러 객체로부터 단일 "피사체 마스크" 생성
- 하나의 마스크 입력만을 필요로 하는 후속 워크플로우 단순화

## 사용 방법

### 기본 설정

1. 워크플로우에 CombineMasks 노드를 추가합니다.
1. `masks` 입력에 하나 이상의 마스크를 리스트 형태로 제공합니다.
1. `output_mask` 출력을 통합 마스크로 사용합니다.

### 파라미터 (Parameters)

- **masks**: 결합할 마스크 이미지들의 리스트

### 출력 (Outputs)

- **output_mask**: 통합된 마스크 (PNG)

## 중요 참고 사항

- **합집합 연산(Union)**: 각 픽셀에 대해 모든 입력 마스크 중 최대값을 출력 마스크에 사용합니다.
- **크기 일치 필수**: 모든 입력 마스크는 **동일한 해상도/크기**여야 합니다. 크기가 다를 경우 유효성 검사에서 오류가 발생합니다.
- **알파 채널 처리**: 입력 마스크가 RGBA/LA 형식인 경우 노드는 **알파 채널**을 마스크로 사용하며, 그렇지 않은 경우 이미지를 그레이스케일로 변환하여 처리합니다.
