# MergeImages

## 어떤 노드인가요?

MergeImages 노드를 사용하면 다양한 레이아웃 옵션을 사용하여 여러 이미지를 단일 구도로 결합할 수 있습니다. 콜라주, 이미지 그리드를 만들거나 관련된 이미지들을 유연한 배치 옵션을 통해 하나의 조화로운 이미지로 결합하는 데 적합합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지 콜라주 또는 그리드를 생성할 때
- 관련된 여러 이미지를 하나로 결합할 때
- 이미지 모자이크 또는 패턴을 만들 때
- 이미지 갤러리 또는 포트폴리오를 구성할 때
- 비교를 위해 이미지를 병합할 때
- 소셜 미디어용 이미지 레이아웃을 만들 때
- 이미지 기반 프레젠테이션을 제작할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 MergeImages 노드를 추가합니다.
1. 여러 이미지 소스를 "input_images" 입력에 연결합니다.
1. 레이아웃 스타일과 배치를 선택합니다.
1. 병합된 이미지는 "output" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

#### 이미지 입력 (Image Input)

- **input_images**: 병합할 이미지 목록 (여러 이미지 소스에서 연결 가능)

#### 레이아웃 설정 (Layout Settings)

- **layout_style**: 이미지 배열 스타일

    - **grid**: 동일한 크기의 셀을 가진 규칙적인 그리드 레이아웃
    - **horizontal**: 가로 행으로 이미지 정렬
    - **vertical**: 세로 열로 이미지 정렬
    - **masonry**: 다양한 높이를 가진 핀터레스트 스타일 레이아웃

- **columns** (1-10, 기본값: 3): 그리드 레이아웃의 열 수

- **spacing** (0-50, 기본값: 10): 이미지 간의 간격(픽셀)

#### 스타일 옵션 (Styling Options)

- **background_color** (16진수 색상 코드, 기본값: #ffffff): 병합된 이미지의 배경 색상
- **border_radius** (0-20, 기본값: 0): 이미지 모서리의 둥근 반경
- **padding** (0-100, 기본값: 20): 전체 구도 주변의 안쪽 여백(패딩)

### 출력 (Outputs)

- **output**: 모든 입력 이미지가 결합된 병합 이미지

## 예시

일반적인 이미지 병합 워크플로우:

1. LoadImage 노드를 사용하여 여러 이미지를 로드합니다.
1. 모든 이미지를 MergeImages 노드의 "input_images" 파라미터에 연결합니다.
1. 레이아웃 설정을 지정합니다:
    - 규칙적인 그리드를 위해 layout_style을 "grid"로 선택
    - 2열 레이아웃을 위해 columns를 2로 설정
    - 이미지 사이에 알맞은 여백을 위해 spacing을 15로 설정
1. 디자인 맞춤 설정:
    - 밝은 회색 배경을 위해 background_color를 "#f0f0f0"으로 설정
    - 약간 둥근 모서리를 위해 border_radius를 5로 설정
    - 전체 구도 주변 여백을 위해 padding을 30으로 설정
1. 결과를 확인하기 위해 "output"을 DisplayImage에 연결합니다.

## 중요 참고 사항

- **유연한 레이아웃**: 다양한 레이아웃 스타일 중에서 선택할 수 있습니다.
- **자동 정렬**: 설정에 따라 이미지가 자동으로 정렬됩니다.
- **맞춤형 스타일링**: 색상, 간격 및 시각적 요소를 완벽하게 제어할 수 있습니다.
- **다중 이미지 지원**: 개수에 상관없이 여러 입력 이미지를 처리할 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 표시되지 않음**: "input_images" 파라미터에 이미지를 제대로 연결했는지 확인하세요.
- **레이아웃 어색함**: 더 나은 구도를 위해 columns 및 spacing 설정을 조정하세요.
- **이미지가 너무 작음**: 전체 구도 크기를 늘리거나 열(column) 수를 줄이세요.

## 기술 세부사항

이 노드는 다음을 수행하는 합성 이미지를 생성합니다:

- 지정된 레이아웃으로 입력 이미지를 자동 정렬
- 레이아웃에 이미지를 맞추면서 종횡비(가로세로 비율) 유지
- 일관된 간격 및 스타일 제공
- 다양한 사용 사례를 위한 여러 레이아웃 스타일 지원

이를 통해 여러 소스로부터 복잡한 이미지 구도를 쉽게 생성할 수 있는 강력한 방법을 제공합니다.
