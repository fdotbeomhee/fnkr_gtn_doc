# InvertImage

## 어떤 노드인가요?

InvertImage 노드는 모든 색상 값을 반전하여 입력 이미지의 네거티브(음화) 버전을 만듭니다. 필름 사진의 네거티브와 마찬가지로 어두운 영역은 밝아지고, 밝은 영역은 어두워지며, 색상은 보색으로 반전됩니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지 색상을 반전하여 예술적 효과를 만들 때
- 창의적인 목적을 위해 이미지의 네거티브 버전을 생성할 때
- 이미지 처리 워크플로우에서 고대비(High-contrast) 효과를 생성할 때
- 이미지 생성 파이프라인에서 다양한 시각적 스타일을 실험할 때
- 기존 이미지로부터 보색 배색을 구성할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 InvertImage 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 반전된 이미지는 "output" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

- **input_image**: 반전할 원본 이미지 (다른 이미지 노드에서 연결 가능)

### 출력 (Outputs)

- **output**: 입력 이미지의 반전된(네거티브) 버전

## 예시

일반적인 워크플로우 패턴:

1. GenerateImage 또는 LoadImage와 같은 노드를 사용하여 이미지를 생성하거나 로드합니다.
1. 해당 이미지를 InvertImage 노드의 "input_image" 파라미터에 연결합니다.
1. InvertImage 노드가 이미지의 네거티브 버전을 생성합니다.
1. "output"을 DisplayImage에 연결하여 결과를 확인하거나 다른 처리 노드에 연결합니다.

## 중요 참고 사항

- **RGBA 이미지**: 투명도가 있는 이미지(RGBA)의 경우, 노드는 원본 알파 채널을 보존하면서 RGB 색상 채널만 반전합니다.
- **기타 포맷**: 다른 포맷의 이미지는 반전 전에 RGB로 변환됩니다.
- **실시간 처리**: 노드는 연결이 이루어지거나 입력 값이 변경될 때 즉시 이미지를 처리합니다.
- **출력 형식**: 품질을 보존하기 위해 반전된 이미지는 PNG 파일로 저장됩니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 없음**: 이미지 소스가 "input_image" 파라미터에 제대로 연결되어 있는지 확인하세요.
- **예상치 못한 결과**: 반전은 네거티브를 생성하므로 어두운 영역이 밝아지고 밝은 영역이 어두워집니다.
- **투명도 문제**: 특정 투명도 효과를 보존해야 하는 경우, 이 노드는 RGBA 이미지의 원본 알파 채널을 유지합니다.

## 기술 세부사항

이 노드는 다양한 이미지 모드를 지능적으로 처리합니다:

- **RGBA**: RGB 채널을 반전하고 알파 채널을 유지
- **RGB**: 모든 색상 값의 직접 반전
- **기타 모드**: 먼저 RGB로 변환한 후 반전 적용
