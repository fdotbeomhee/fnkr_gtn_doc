# Image Grid Splitter

## 어떤 노드인가요?

Image Grid Splitter 노드는 **규칙적인 격자(Grid)** 형태로 배열된 여러 이미지가 포함된 단일 이미지를 개별 이미지로 분할합니다.

지원하는 기능:

- **Auto** 그리드 감지 (최선형 자동 추정)
- **Manual** 그리드 정의 (행/열 수동 설정)
- 노란색 점선 격자선으로 표시되는 **미리보기 오버레이**
- **목록(List)** 및 **셀별 개별 출력** (`r1c1`, `r1c2` 등) 지원

## 언제 사용하나요?

여러 이미지가 포함된 이미지(예: 2×2 또는 3×3 콜라주)가 있고 다음을 수행하려는 경우 이 노드를 사용하세요:

- 후속 처리를 위해 각 타일을 개별 이미지로 추출할 때
- 개별 그리드 셀을 다른 노드로 전달할 때
- 손쉬운 연결을 위해 리스트 출력과 셀별 명명된 출력을 동시에 유지할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 **Image Grid Splitter**를 추가합니다.
1. 그리드 이미지를 **Input Image**에 연결합니다.
1. **Grid Detection** 방식을 선택합니다:
    - **auto**: 노드가 행/열 수를 자동으로 추정합니다.
    - **manual**: **Rows** 및 **Columns**를 직접 지정합니다.
1. 분할 경계를 확인하기 위해 **Preview**를 검토합니다.
1. 노드를 실행하여 분할된 이미지를 생성합니다.

!!! info "자동 감지는 최선형(Best-effort) 추정입니다"

    Auto 모드는 **규칙적인 그리드**(동일한 크기의 셀)를 가정하며, 인접한 셀이 시각적으로 유사한 경우 정확도가 떨어질 수 있습니다.
    미리보기 점선이 실제 격자와 일치하지 않으면 **manual** 모드로 전환하세요.

### 파라미터 (Parameters)

- **Input Image**: 분할할 그리드 이미지. `ImageArtifact` 또는 `ImageUrlArtifact`를 허용합니다.
- **Grid Detection**:
    - **auto**: 규칙적인 그리드를 자동 감지
    - **manual**: 명시적인 Rows/Columns 사용
- **Rows / Columns** (수동 모드 전용): 1~12 범위의 슬라이더.
- **Preview** (출력): 노란색 점선 격자선이 표시된 원본 이미지.
- **Detections (auto)** (출력 그룹): 감지된 Rows/Columns/Count (수동 모드 선택 시 숨겨짐).

### 출력 (Outputs)

- **Images**: 행 우선 순서(좌에서 우, 상에서 하)로 정렬된 `ImageUrlArtifact` 목록.
- **Grid Cells**: 셀당 하나의 `ImageUrlArtifact` 출력이며 다음과 같이 명명됩니다:
    - `r1c1`, `r1c2`, ..., `r{row}c{col}`

!!! note "셀별 출력은 실행 시 생성됩니다"

    `r{row}c{col}` 출력은 선택되거나 감지된 그리드 크기에 따라 노드를 실행할 때 생성 및 업데이트됩니다.

## 예시

입력이 2×2 그리드인 경우:

- `r1c1`: 좌측 상단
- `r1c2`: 우측 상단
- `r2c1`: 좌측 하단
- `r2c2`: 우측 하단

그리고 `Images` 리스트에는 `[r1c1, r1c2, r2c1, r2c2]`가 포함됩니다.

## 자주 묻는 질문 및 문제 해결

- **미리보기 격자선이 맞지 않음**: **manual** 모드로 전환하여 정확한 Rows/Columns를 설정하세요.
- **예상과 다른 자동 감지**: 일부 이미지는 시각적 경계가 뚜렷하지 않을 수 있습니다. 이 경우 수동(manual) 모드를 사용하는 것이 안정적입니다.
