# DisplayImage

## 어떤 노드인가요?

DisplayImage 노드는 이미지를 화면에 표시하고 해당 이미지의 해상도 치수(너비 및 높이)를 제공하는 노드입니다. 워크플로우 내에서 이미지를 시각적으로 보여주는 동시에 너비와 높이 같은 유용한 정보를 추출하는 간편한 뷰어입니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 워크플로우에서 시각적 피드백을 위해 이미지 표시
- 이미지의 해상도 치수(가로 너비 및 세로 높이) 확인
- 이미지를 눈으로 확인하면서 워크플로우의 다음 노드로 그대로 전달
- 현재 처리 중인 이미지를 확인하여 워크플로우 디버깅

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayImage 노드를 추가합니다.
1. 이미지 소스를 "image" 입력에 연결합니다.
1. 이미지가 화면에 표시되며, 해상도 치수가 출력으로 제공됩니다 (참고: 치수 출력은 기본적으로 숨겨져 있습니다. 오른쪽 속성 패널에서 표시하도록 설정할 수 있습니다).

### 파라미터 (Parameters)

- **image**: 표시할 이미지

### 출력 (Outputs)

- **image**: 입력된 것과 동일한 이미지 (다른 노드에서 사용할 수 있도록 그대로 전달됨)
- **width**: 픽셀 단위의 이미지 너비 (정수)
- **height**: 픽셀 단위의 이미지 높이 (정수)

## 예시

일반적인 워크플로우 패턴:

1. 이미지 소스(GenerateImage 또는 LoadImage 등)를 DisplayImage 노드에 연결합니다.
1. DisplayImage 노드에서 이미지를 확인하여 의도한 결과가 맞는지 검토합니다.
1. 다른 노드에서 이미지 해상도 정보가 필요한 경우 width 및 height 출력을 활용합니다.
1. 해당 이미지를 필요로 하는 다른 노드에 image 출력을 연결합니다.

## 중요 참고 사항

- DisplayImage 노드는 이미지를 전혀 변경하지 않고 그대로 전달합니다. 순수하게 화면 표시 및 해상도 추출 목적으로 사용됩니다.
- ImageUrlArtifact 입력의 경우 치수를 계산하기 위해 URL에서 이미지를 가져옵니다.
- ImageArtifact 입력의 경우 아티팩트 속성에서 직접 치수를 읽어옵니다.
- width 및 height 출력은 UI에서 기본적으로 숨겨져 있지만, 속성 패널(Properties Panel)에서 활성화할 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 표시되지 않음**: 이미지 소스가 올바르게 연결되어 유효한 이미지 데이터를 출력하고 있는지 확인하세요.
- **치수가 0으로 표시됨**: 이미지 데이터 또는 연결에 문제가 있음을 나타낼 수 있습니다.
- **URL 이미지 처리 지연**: URL로 제공되는 대용량 이미지는 치수 계산 및 화면 렌더링에 다소 시간이 걸릴 수 있습니다.
