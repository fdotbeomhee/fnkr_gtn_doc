# ApplyMask

## 어떤 노드인가요?

ApplyMask 노드는 입력 이미지에 마스크를 적용하여 투명도 효과를 생성하는 노드입니다. 이미지와 마스크를 입력받아 마스크의 지정된 채널을 최종 이미지의 알파(투명도) 채널로 사용합니다. 마스크 데이터가 저장된 위치에 따라 사용할 채널(빨간색, 초록색, 파란색, 알파)을 선택할 수 있습니다. 이를 통해 마스크를 기반으로 이미지의 특정 부분을 선택적으로 투명하게 만들 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 마스크를 사용하여 이미지에 투명도 효과 적용
- 이미지 합성을 위한 선택적 투명도 생성
- 다른 노드(DisplayMask, PaintMask, InvertMask)에서 생성된 마스크를 활용하여 이미지 투명도 수정
- 누끼 따기(배경 제거) 또는 오려내기 효과 적용
- 이미지 처리 워크플로우에서 복합 투명도 효과 적용
- 마스크 이미지에서 투명도에 사용할 특정 채널 제어

## 사용 방법

### 기본 설정

1. 워크플로우에 ApplyMask 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 마스크 소스를 "input_mask" 입력에 연결합니다.
1. "channel" 파라미터에서 적절한 채널을 선택합니다.
1. 마스크가 적용된 이미지가 "output" 파라미터를 통해 출력됩니다.

### 파라미터 (Parameters)

- **input_image**: 마스크를 적용할 대상 이미지 (다른 이미지 노드에서 연결 가능)

- **input_mask**: 적용할 마스크 (DisplayMask, PaintMask 또는 InvertMask 등의 마스크 노드에서 연결 가능)

- **channel**: 마스크 이미지에서 사용할 채널:

    - **red**: 빨간색(Red) 채널 사용 (기본값, PaintMask 출력과 호환)
    - **green**: 초록색(Green) 채널 사용
    - **blue**: 파란색(Blue) 채널 사용
    - **alpha**: 알파(Alpha) 채널 사용 (사용 가능한 경우)

### 출력 (Outputs)

- **output**: 마스크가 적용된 최종 이미지 (마스크 기반 투명도 적용)

## 예시

일반적인 워크플로우 패턴:

1. GenerateImage 또는 LoadImage 등의 노드를 사용하여 이미지를 생성하거나 불러옵니다.
1. DisplayMask 또는 PaintMask 등의 노드를 사용하여 마스크를 생성합니다.
1. 이미지를 ApplyMask 노드의 "input_image" 파라미터에 연결합니다.
1. 마스크를 ApplyMask 노드의 "input_mask" 파라미터에 연결합니다.
1. 적절한 채널을 선택합니다 (일반적으로 PaintMask 출력의 경우 "red", RGBA 마스크의 경우 "alpha").
1. ApplyMask 노드가 마스크를 적용하여 투명도 효과를 생성합니다.
1. "output"을 DisplayImage에 연결하여 최종 결과를 확인합니다.

## 중요 참고 사항

- **채널 선택**: 마스크 데이터가 포함된 올바른 채널을 선택하세요:

    - **PaintMask 출력**: 일반적으로 "red" 채널 사용
    - **알파 데이터가 포함된 RGBA 마스크**: "alpha" 채널 사용
    - **커스텀 마스크**: 최적의 결과를 내는 채널을 다양하게 테스트해 보세요.

- **마스크 크기 조정**: 마스크는 입력 이미지의 크기에 맞게 자동으로 리사이즈됩니다.

- **RGBA 출력**: 최종 이미지는 투명도를 지원하기 위해 RGBA 형식으로 변환됩니다.

- **실시간 처리**: 두 입력이 모두 연결되면 즉시 처리가 이루어집니다.

- **출력 포맷**: 투명도를 보존하기 위해 마스크가 적용된 이미지는 PNG 파일로 저장됩니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 생성되지 않음**: "input_image"와 "input_mask"가 모두 올바르게 연결되어 있는지 확인하세요.
- **예상치 못한 투명도 발생**: 마스크에서 흰색 영역은 불투명해지고 검은색 영역은 투명해진다는 점을 기억하세요.
- **잘못된 채널 선택**: 마스크가 올바르게 적용되지 않으면 다른 채널(red, green, blue, alpha)을 선택해 보세요.
- **마스크 크기 불일치**: 마스크가 입력 이미지 크기에 맞춰 자동으로 조정되지만, 해상도 차이가 큰 경우 품질에 영향을 줄 수 있습니다.

## 기술 세부 정보

이 노드는 다음 단계를 거쳐 마스크와 이미지를 처리합니다:

- **이미지 로드**: URL로부터 입력 이미지와 마스크를 모두 로드합니다.

- **채널 추출**: 마스크 이미지에서 지정된 채널을 추출합니다:

    - RGB 이미지: red, green, blue 채널 추출 가능
    - RGBA 이미지: red, green, blue, alpha 채널 추출 가능
    - L (그레이스케일) 이미지: 그레이스케일 채널 직접 사용
    - LA 이미지: alpha 또는 그레이스케일 채널 추출 가능

- **크기 조정**: 추출된 채널을 입력 이미지 크기에 맞게 리사이즈합니다.

- **알파 적용**: `putalpha()`를 사용하여 추출된 채널을 입력 이미지의 알파 채널로 적용합니다.

- **출력 생성**: 결과를 새로운 RGBA 이미지 아티팩트로 저장합니다.

다양한 마스크 형식을 지원합니다:

- **RGB**: red, green, blue 채널 추출 가능 (alpha 선택 시 red로 대체)
- **RGBA**: red, green, blue, alpha 채널 추출 가능
- **L**: 그레이스케일 채널 직접 사용 (channel 파라미터 무시)
- **LA**: alpha 또는 그레이스케일 채널 추출 가능
- **기타 형식**: 지원되지 않는 모드의 경우 오류 발생
