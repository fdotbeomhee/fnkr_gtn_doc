# Webcam

## 어떤 노드인가요?

Webcam 노드를 사용하면 기기의 카메라에서 직접 이미지를 캡처할 수 있습니다. 실시간 이미지 캡처, 대화형 워크플로우 생성 또는 이미지 처리 파이프라인에 라이브 카메라 입력을 통합하는 데 적합합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 웹캠 또는 카메라에서 이미지를 캡처할 때
- 실시간 이미지 처리 워크플로우를 구축할 때
- 라이브 카메라 입력을 사용하는 대화형 애플리케이션을 만들 때
- 즉시 처리할 사진을 촬영할 때
- 실시간 이미지 분석 또는 인식 시스템을 구축할 때
- 카메라 기반 자동화 워크플로우를 만들 때

## 사용 방법

### 기본 설정

1. 워크플로우에 Webcam 노드를 추가합니다.
1. 사진을 찍으려면 "Capture" 버튼을 클릭합니다.
1. 캡처된 이미지는 "output" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

#### 카메라 설정 (Camera Settings)

- **camera_index** (0-10, 기본값: 0): 사용할 카메라 번호 (여러 대의 카메라를 사용할 수 있는 경우)

- **resolution**: 캡처 해상도

    - **640x480**: 표준 해상도
    - **1280x720**: HD 해상도
    - **1920x1080**: Full HD 해상도
    - **Custom**: 사용자 지정 너비 및 높이 설정

- **custom_width** (픽셀): "Custom" 해상도 사용 시 사용자 지정 너비

- **custom_height** (픽셀): "Custom" 해상도 사용 시 사용자 지정 높이

#### 캡처 설정 (Capture Settings)

- **auto_capture** (boolean, 기본값: false): 정해진 간격으로 이미지를 자동 캡처
- **capture_interval** (초, 기본값: 1): 자동 캡처 간격

### 출력 (Outputs)

- **output**: 카메라에서 캡처된 이미지

## 예시

일반적인 웹캠 워크플로우:

1. 워크플로우에 Webcam 노드를 추가합니다.
1. 카메라 설정을 지정합니다:
    - 기본 카메라를 사용하려면 camera_index를 0으로 설정
    - HD 품질을 위해 "1280x720" 해상도 선택
1. "Capture" 버튼을 클릭하여 사진을 촬영합니다.
1. 캡처된 이미지를 확인하기 위해 "output"을 DisplayImage에 연결합니다.
1. 실시간 이미지 처리를 위해 다른 처리 노드에 연결할 수도 있습니다.

## 중요 참고 사항

- **카메라 접근 권한**: 이 노드가 작동하려면 카메라 권한이 필요합니다.
- **실시간 캡처**: "Capture" 버튼을 클릭하면 실시간으로 이미지가 캡처됩니다.
- **다중 카메라**: 여러 대의 카메라가 있는 경우 camera_index를 사용하여 선택할 수 있습니다.
- **해상도 제어**: 필요에 맞는 적절한 해상도를 선택하세요.

## 자주 묻는 질문 및 문제 해결

- **카메라를 찾을 수 없음**: 카메라가 제대로 연결되어 있는지, 다른 애플리케이션에서 사용 중이지 않은지 확인하세요.
- **권한 거부됨**: 애플리케이션에 카메라 접근 권한을 부여하세요.
- **화질 저하**: 더 나은 화질을 위해 해상도(resolution) 설정을 높이세요.
- **카메라 사용 중**: 카메라를 사용하고 있을 수 있는 다른 애플리케이션을 종료하세요.

## 기술 세부사항

이 노드는 기기의 카메라 시스템을 사용하여 다음 작업을 수행합니다:

- 사용 가능한 카메라 접근
- 지정된 해상도로 이미지 캡처
- 실시간 이미지 캡처 기능 제공
- 다중 카메라 입력 지원

이를 통해 이미지 처리 워크플로우에 라이브 카메라 입력을 통합할 수 있는 강력한 방법을 제공합니다.
