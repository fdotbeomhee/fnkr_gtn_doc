# PaintMask

## 어떤 노드인가요?

PaintMask 노드는 입력 이미지로부터 편집 가능한 마스크를 생성하고 직접 페인팅하여 투명도를 수정할 수 있도록 해줍니다. 이미지의 알파 채널로부터 초기 마스크를 자동 생성한 후, 브러시로 마스크를 직접 편집할 수 있는 대화형 페인팅 인터페이스를 제공합니다. 또한 노드는 마스크를 입력 이미지에 적용하여 최종 결과를 표시합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 이미지 편집 및 합성을 위한 사용자 정의 마스크를 생성할 때
- 자동 생성된 마스크를 수동으로 정밀하게 다듬을 때
- 이미지에 투명도 효과를 직접 그려 넣을 때
- 이미지 오버레이를 위한 선택적 투명도를 만들 때
- 정밀한 이미지 편집을 위해 마스크 경계를 미세 조정할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 PaintMask 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 노드가 이미지의 알파 채널로부터 초기 마스크를 자동으로 생성합니다.
1. "output_mask" 파라미터의 페인팅 인터페이스를 사용하여 마스크를 편집합니다.
1. 마스크가 적용된 최종 이미지는 "output_image" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

- **input_image**: 마스크를 생성할 원본 이미지 (다른 이미지 노드에서 연결 가능)

### 출력 (Outputs)

- **output_mask**: 투명도를 수정하기 위해 직접 칠할 수 있는 편집 가능한 마스크 이미지
- **output_image**: 마스크가 적용된 최종 이미지 (마스크 기반의 투명도 적용)

## 예시

일반적인 워크플로우 패턴:

1. GenerateImage 또는 LoadImage와 같은 노드를 사용하여 이미지를 생성하거나 로드합니다.
1. 해당 이미지를 PaintMask 노드의 "input_image" 파라미터에 연결합니다.
1. 노드가 이미지의 알파 채널로부터 초기 마스크를 생성합니다.
1. "output_mask" 파라미터의 페인팅 도구를 사용하여 마스크를 다듬습니다.
1. "output_image"에 페인팅된 마스크가 적용된 결과가 표시됩니다.
1. "output_image"를 DisplayImage에 연결하여 최종 결과를 확인합니다.

## 중요 참고 사항

- **자동 마스크 생성**: 노드는 입력 이미지의 알파 채널로부터 초기 마스크를 자동으로 생성합니다.
- **대화형 페인팅**: 내장된 페인팅 인터페이스를 사용하여 마스크에 직접 칠할 수 있습니다.
- **마스크 유지**: 소스 이미지 URL이 변경되지 않는 한, 입력 이미지를 변경해도 마스크가 유지됩니다.
- **Red 채널 활용**: 마스크는 페인팅된 이미지의 빨간색(Red) 채널을 최종 결과의 알파 채널로 사용합니다.
- **실시간 업데이트**: 마스크의 변경 사항이 출력 이미지에 즉시 반영됩니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 없음**: 이미지 소스가 "input_image" 파라미터에 제대로 연결되어 있는지 확인하세요.
- **마스크가 업데이트되지 않음**: 입력 이미지를 완전히 교체한 경우 마스크를 다시 생성해야 할 수 있습니다.
- **페인팅이 작동하지 않음**: "output_mask" 파라미터 내부의 페인팅 인터페이스를 사용하고 있는지 확인하세요.
- **예상치 못한 투명도**: 마스크의 흰색 영역은 불투명해지고 검은색 영역은 투명해진다는 점을 기억하세요.

## 기술 세부사항

이 노드는 여러 주요 프로세스를 통해 마스크 생성 및 편집을 처리합니다:

- **초기 마스크 생성**: 입력 이미지에서 알파 채널을 추출하여 그레이스케일 마스크로 변환합니다.
- **마스크 편집**: 마스크 위에 페인팅할 수 있는 대화형 인터페이스를 제공합니다.
- **마스크 적용**: 페인팅된 마스크의 빨간색 채널을 최종 이미지의 알파 채널로 적용합니다.
- **지속성 유지**: 마스크가 수동으로 편집되었는지 여부를 추적하여 재생성할지 기존 편집 내용을 유지할지 결정합니다.
