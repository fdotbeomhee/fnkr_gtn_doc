# DisplayChannel

## 어떤 노드인가요?

DisplayChannel 노드는 입력 이미지에서 특정 색상 채널(빨간색, 초록색, 파란색, 알파)을 추출하여 마스크를 생성하는 노드입니다. 이 노드는 DisplayMask와 유사하지만 알파 채널 대신 기본적으로 빨간색(Red) 채널을 추출한다는 차이점이 있습니다. 마스크는 선택한 채널의 높은 값을 흰색으로, 낮은 값을 검은색으로 나타내는 그레이스케일 이미지입니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 특정 색상 채널(빨강, 초록, 파랑)을 이미지 형태로 추출
- 이미지 내 개별 색상 채널의 강도 분석
- 색상 정보를 기반으로 이미지 편집 워크플로우용 마스크 생성
- 각 색상 채널이 전체 이미지에 어떻게 기여하는지 시각화
- 다른 이미지 처리 노드에서 사용할 색상 기반 마스크 생성
- 이미지 파이프라인의 색상 채널 문제 디버깅
- 빨간색 채널 중심 분석 (기본값이 빨간색 채널임)

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayChannel 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. "channel" 드롭다운에서 원하는 채널을 선택합니다 (기본값: "red").
1. 생성된 채널 이미지가 "output" 파라미터를 통해 출력됩니다.

### 파라미터 (Parameters)

- **input_image**: 마스크를 추출할 원본 이미지 (다른 이미지 노드에서 연결 가능)
- **channel**: 마스크로 추출할 채널 (red, green, blue, alpha) - 기본값: "red"

### 출력 (Outputs)

- **output**: 입력 이미지의 선택된 채널로부터 생성된 그레이스케일 마스크 이미지

## 예시

일반적인 워크플로우 패턴:

1. GenerateImage 또는 LoadImage 등의 노드를 사용하여 이미지를 생성하거나 불러옵니다.
1. 해당 이미지를 DisplayChannel 노드의 "input_image" 파라미터에 연결합니다.
1. 노드는 기본적으로 빨간색 채널을 추출하며, 필요에 따라 다른 채널을 선택할 수 있습니다.
1. DisplayChannel 노드가 선택한 채널을 추출하여 시각적 마스크를 생성합니다.
1. "output"을 DisplayImage에 연결하여 마스크를 보거나 다른 마스크 처리 노드로 연결합니다.

## 채널 옵션

- **red**: 빨간색 채널 추출 (기본값) - 이미지에서 붉은색 요소를 분리할 때 유용
- **green**: 초록색 채널 추출 - 이미지에서 초록색 요소를 분리할 때 유용
- **blue**: 파란색 채널 추출 - 이미지에서 파란색 요소를 분리할 때 유용
- **alpha**: 투명도 채널 추출 - 이미지의 어느 부분이 투명한지 확인할 때 유용

## 중요 참고 사항

- **기본 채널**: DisplayMask와 달리 이 노드는 "alpha" 대신 "red" 채널을 기본값으로 사용합니다.
- **채널 추출**: 마스크 생성을 위해 입력 이미지에서 지정된 채널을 분리 추출합니다.
- **그레이스케일 출력**: 결과 마스크는 선택된 채널의 높은 값이 흰색, 낮은 값이 검은색으로 표현되는 그레이스케일 이미지입니다.
- **실시간 처리**: 연결이 설정되거나 입력 값/채널 선택이 변경되면 즉시 이미지를 처리합니다.
- **출력 포맷**: 품질 보존을 위해 마스크는 PNG 파일로 저장됩니다.
- **이미지 모드 지원**: RGB, RGBA, 그레이스케일(L), 그레이스케일+알파(LA) 이미지 모드를 지원합니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 나오지 않음**: 이미지 소스가 "input_image" 파라미터에 올바르게 연결되어 있는지 확인하세요.
- **완전한 검은색 마스크**: 선택한 채널의 변화가 없거나 값이 매우 낮음을 의미할 수 있습니다.
- **완전한 흰색 마스크**: 선택한 채널의 값이 전체적으로 높음을 의미할 수 있습니다.
- **지원되지 않는 모드 오류**: 이미지 형식이 선택한 채널을 지원하지 않을 수 있습니다 (예: RGB 이미지에서 알파 채널 선택 시).

## 기술 세부 정보

이 노드는 다음과 같은 채널 추출 로직을 사용합니다:

- URL로부터 입력 이미지 로드
- 지정된 채널(red, green, blue, alpha) 추출
- 추출된 채널을 그레이스케일 마스크로 변환
- 결과를 새로운 이미지 아티팩트로 저장

RGB 이미지에서 알파 채널을 선택하면 RGB에는 알파 채널이 없으므로 빨간색(red) 채널로 대체됩니다.

## DisplayMask와의 차이점

DisplayChannel과 DisplayMask의 주요 차이점은 기본 채널 선택입니다:

- **DisplayChannel**: 기본값이 "red" 채널
- **DisplayMask**: 기본값이 "alpha" 채널

따라서 DisplayChannel은 색상 분석 워크플로우에 더 적합하고, DisplayMask는 투명도 기반 워크플로우에 더 적합합니다.
