# Gaussian Edge Fade

## 어떤 노드인가요?

**Gaussian Edge Fade** 노드는 매끄러운 합성을 위해 이미지 가장자리에 가우시안 블러(Gaussian blur)가 적용된 알파 채널 페이드 효과를 적용합니다. 이를 통해 이미지 가장자리에 부드러운 전환을 생성하여 거친 경계선 없이 다른 이미지나 배경 위에 오버레이하기에 이상적인 상태로 만듭니다.

## 언제 사용하나요?

- **이미지 합성**: 부드러운 가장자리 전환을 통해 이미지를 매끄럽게 블렌딩할 때
- **비네트(Vignette) 효과**: 전문적인 비네트 스타일의 가장자리 페이드 효과를 생성할 때
- **오버레이 준비**: 다양한 배경 위에 오버레이할 수 있도록 이미지를 준비할 때
- **로고 처리**: 투명 배경을 가진 로고의 컷아웃을 유지하면서 가장자리 페이드를 추가할 때
- **사진 편집**: 모서리가 둥근 자연스럽고 유기적인 가장자리 페이드 효과를 만들 때

## 파라미터 (Parameters)

### 입력 파라미터 (Input Parameters)

| 파라미터 | 타입 | 설명 |
| ----------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **input_image**   | ImageArtifact / ImageUrlArtifact | 가장자리 페이드를 적용할 입력 이미지 |
| **fade_mode**     | String                           | 페이드 거리 측정 방식: "percentage" (이미지 크기에 상대적) 또는 "pixels" (절대 거리). 기본값: "percentage" |
| **fade_distance** | Integer                          | 가장자리에서 페이드되는 거리. 백분율 모드: 5 = 이미지 크기의 5%. 픽셀 모드: 5 = 5픽셀. 기본값: 5 |
| **blur_radius**   | Integer                          | 매끄러운 가장자리 전환을 위한 가우시안 블러 반경 (0-100). 값이 클수록 더 부드러운 페이드가 생성됩니다. 기본값: 10 |
| **fade_curve**    | Float                            | 투명도 전환 모양을 제어합니다 (0.5-4.0). 1.0 = 선형, >1.0 = 가장자리 근처가 더 투명해짐(강함), <1.0 = 가장자리 근처가 덜 투명해짐(부드러움). 기본값: 2.0 |
| **edge_shape**    | String                           | 페이드의 형태: "square" (직선 가장자리) 또는 "rounded" (곡선 모서리). 기본값: "square" |
| **replace_mask**  | Boolean                          | False인 경우 가장자리 페이드를 기존 알파 채널과 결합합니다. True인 경우 기존 알파 채널을 완전히 대체합니다. 기본값: False |
| **apply_top**     | Boolean                          | 상단 가장자리에 페이드 적용. 기본값: True |
| **apply_bottom**  | Boolean                          | 하단 가장자리에 페이드 적용. 기본값: True |
| **apply_left**    | Boolean                          | 좌측 가장자리에 페이드 적용. 기본값: True |
| **apply_right**   | Boolean                          | 우측 가장자리에 페이드 적용. 기본값: True |

### 출력 파라미터 (Output Parameters)

| 파라미터 | 타입 | 설명 |
| ---------------- | ---------------- | ------------------------------------------------ |
| **output_image** | ImageUrlArtifact | 알파 채널 가장자리 페이드가 적용된 처리된 이미지 |

## 주요 기능

### 페이드 모드 (Fade Modes)

**Percentage 모드**: 이미지 크기에 비례하여 조정되는 해상도 독립적 페이드입니다. 5% 페이드는 어떤 크기의 이미지에서도 일관된 비율로 표시됩니다.

**Pixels 모드**: 정밀한 픽셀 제어가 가능한 고정 크기 페이드입니다. 50픽셀 페이드는 이미지 크기와 상관없이 동일한 절대 거리를 유지합니다.

### 페이드 곡선 (Fade Curve)

페이드 곡선 파라미터는 거듭제곱 함수(power function)를 사용하여 투명도가 가장자리에서 중앙으로 어떻게 전환되는지 제어합니다:

- **0.5-0.9**: 완만한 곡선 - 가장자리가 더 불투명하게 유지되며 완전 불투명 상태로 빠르게 전환됩니다.
- **1.0**: 선형 - 투명에서 불투명으로 균등하게 전환됩니다.
- **2.0 (기본값)**: 적극적 곡선 - 가장자리가 더 투명하게 유지되며 점진적으로 전환됩니다.
- **3.0-4.0**: 매우 적극적 곡선 - 가장자리의 극단적인 투명도 및 매우 완만한 페이드가 적용됩니다.

### 가장자리 형태 (Edge Shapes)

**Square**: 각 가장자리가 독립적으로 페이드되어 직선 전환을 생성합니다. 전통적인 비네트 및 레터박스 효과에 가장 적합합니다.

**Rounded**: 거리 필드 계산을 사용하여 페이드가 곡선 윤곽을 따르며 부드럽고 자연스러운 모서리 전환을 만듭니다. 최신 UI 디자인과 자연스러운 사진 합성에 가장 적합합니다.

### 알파 채널 처리

**Replace Mask = False (기본값)**: 기존 투명도를 유지하고 곱셈 블렌딩(multiplicative blending)을 사용하여 가장자리 페이드와 결합합니다. 투명 배경을 가진 로고에 적합합니다.

**Replace Mask = True**: 기존 알파 채널을 무시하고 새로운 가장자리 페이드만 적용합니다. 원치 않는 투명도가 있는 이미지에 유용합니다.

## 사용 예시

### 기본 비네트 효과

1. **input_image**에 이미지를 연결합니다.
1. **fade_mode**를 "percentage"로 설정합니다.
1. **fade_distance**를 10 (10%)으로 설정합니다.
1. **blur_radius**를 15로 설정합니다.
1. **fade_curve**를 2.0으로 설정합니다.
1. 모든 **apply\_**\* 가장자리 설정을 True로 유지합니다.
1. 노드를 실행합니다.

결과: 모든 가장자리에 부드럽고 균일한 페이드가 적용된 이미지.

### 레터박스 효과

1. **input_image**에 이미지를 연결합니다.
1. **fade_mode**를 "pixels"로 설정합니다.
1. **fade_distance**를 50으로 설정합니다.
1. **blur_radius**를 20으로 설정합니다.
1. **apply_top**과 **apply_bottom**을 True로 설정합니다.
1. **apply_left**와 **apply_right**를 False로 설정합니다.
1. 노드를 실행합니다.

결과: 가로 페이드만 적용되어 와이드스크린 오버레이에 적합합니다.

### 둥근 모서리 합성

1. **input_image**에 이미지를 연결합니다.
1. **edge_shape**를 "rounded"로 설정합니다.
1. **fade_mode**를 "percentage"로 설정합니다.
1. **fade_distance**를 8로 설정합니다.
1. **blur_radius**를 12로 설정합니다.
1. **fade_curve**를 2.5 (적극적)로 설정합니다.
1. 노드를 실행합니다.

결과: 최신 UI 합성에 적합한 부드러운 둥근 모서리를 가진 이미지.

### 로고 투명도 유지

1. 투명 배경을 가진 로고 PNG를 **input_image**에 연결합니다.
1. **replace_mask**를 False로 설정합니다.
1. **fade_distance**를 5로 설정합니다.
1. **blur_radius**를 10으로 설정합니다.
1. 노드를 실행합니다.

결과: 로고의 투명 컷아웃을 유지하면서 부드러운 가장자리 페이드가 추가됩니다.

## 팁

- **자연스러운 합성**: 가장자리에서 더 많은 투명도를 얻으려면 fade_curve 값을 2.0-3.0 사이로 설정하세요.
- **해상도 독립적 효과**: 다양한 이미지 크기에서 일관된 비율을 유지하려면 percentage 모드를 사용하세요.
- **둥근 모서리**: 자연스러운 타원형 모양을 만들려면 edge_shape "rounded"와 모든 가장자리 활성화를 조합하세요.
- **선택적 페이딩**: 방향성 있는 페이드를 만들려면 특정 가장자리를 비활성화하세요.
- **텍스트 오버레이**: 가장자리를 더 눈에 띄게 유지하려면 완만한 fade_curve(0.7-0.9)를 사용하세요.

## 기술 참고 사항

- 출력 포맷은 알파 채널이 보존된 RGBA PNG입니다.
- PIL이 처리할 수 있는 모든 입력 이미지 형식을 지원합니다.
- 효율적인 그래디언트 계산을 위해 NumPy를 사용합니다.
- 부드러운 전환을 위해 PIL의 ImageFilter를 사용한 가우시안 블러를 적용합니다.
- 기존 알파 채널과 결합할 때 승산(곱셈) 알파 블렌딩을 적용합니다.
- 이미지 크기를 초과할 때 아티팩트가 발생하는 것을 방지하기 위해 페이드 거리를 자동으로 제한(clamp)합니다.
