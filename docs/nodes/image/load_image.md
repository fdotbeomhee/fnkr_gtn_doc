# LoadImage

## 어떤 노드인가요?

LoadImage는 이미지를 워크플로우로 가져올 수 있게 해주는 기본 구성 요소 노드입니다. 프로젝트에서 사용할 사진을 불러오는 노드라고 생각하시면 됩니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 다른 노드(예: CreateImage)에서 생성된 이미지를 사용할 때
- 워크플로우의 다른 노드로 이미지를 전달할 때
- 프로젝트의 일부로 이미지를 표시할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 LoadImage 노드를 추가합니다.
1. 이미지 소스(예: CreateImage)에 연결합니다.

### 파라미터 (Parameters)

- **image**: 로드할 이미지 (다른 노드의 출력에 연결 가능)

### 출력 (Outputs)

- **image**: 워크플로우의 다른 노드에서 사용할 수 있도록 로드된 이미지

## 예시

CreateImage로 이미지를 생성한 후 다른 곳에서 사용하려는 경우:

1. CreateImage의 "output"을 LoadImage의 "image" 입력에 연결합니다.
1. LoadImage가 해당 이미지를 워크플로우의 나머지 부분에서 사용할 수 있도록 제공합니다.

## 중요 참고 사항

- LoadImage는 단순히 이미지를 전달하는 역할을 하며, 이미지 자체를 수정하지 않습니다.
- 파일 브라우저 아이콘을 클릭하여 컴퓨터에서 이미지를 직접 선택할 수 있습니다.
- 확장(expander) 아이콘을 클릭하여 이미지 미리보기를 확대할 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 표시되지 않음**: 이미지 소스가 이 노드에 올바르게 연결되어 있는지 확인하세요.
- **잘못된 이미지 형식**: ImageUrlArtifact, ImageArtifact 또는 문자열 경로/URL을 이 노드에 연결하고 있는지 확인하세요.
