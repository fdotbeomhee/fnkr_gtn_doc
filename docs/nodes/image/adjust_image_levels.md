# AdjustImageLevels

## 어떤 노드인가요?

AdjustImageLevels 노드는 포토샵의 레벨(Levels) 도구와 유사한 전문가 수준의 이미지 조정 기능을 제공합니다. 입력 레벨(섀도우, 미드톤, 하이라이트)과 출력 레벨을 세밀하게 제어하여 이미지의 톤 범위와 대비를 정밀하게 조절할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 이미지의 톤 범위 미세 조정
- 섀도우(어두운 영역)와 하이라이트(밝은 영역)를 독립적으로 조절
- 감마 보정을 통한 중간 톤(미드톤) 밝기 제어
- 고대비 또는 저대비 효과 연출
- 이미지의 노출 불균형 문제 해결
- 여러 이미지 간의 톤 특성 일치
- 특정 출력 사양에 맞는 이미지 준비

## 사용 방법

### 기본 설정

1. 워크플로우에 AdjustImageLevels 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 입력 및 출력 레벨 슬라이더를 조정합니다.
1. 처리된 이미지가 "output" 파라미터를 통해 출력됩니다.

### 파라미터 (Parameters)

#### 입력 레벨 (Input Levels)

- **shadows** (0-255, 기본값: 0): 입력 섀도우 레벨

    - 이 값보다 낮은 픽셀은 출력 섀도우로 매핑됩니다.
    - 값이 높을수록 어두운 영역의 디테일이 더 많이 잘려나갑니다(클리핑).

- **midtones** (0.1-10.0, 기본값: 1.0): 중간 톤 조정 (감마)

    - 1.0 미만: 중간 톤이 밝아짐
    - 1.0 초과: 중간 톤이 어두워짐
    - 1.0 = 변경 없음

- **highlights** (0-255, 기본값: 255): 입력 하이라이트 레벨

    - 이 값보다 높은 픽셀은 출력 하이라이트로 매핑됩니다.
    - 값이 낮을수록 밝은 영역의 디테일이 더 많이 잘려나갑니다.

#### 출력 레벨 (Output Levels)

- **output_shadows** (0-255, 기본값: 0): 출력 섀도우 레벨

    - 입력 섀도우가 이 값으로 매핑됩니다.
    - 값이 높을수록 전체 이미지가 밝아집니다.

- **output_highlights** (0-255, 기본값: 255): 출력 하이라이트 레벨

    - 입력 하이라이트가 이 값으로 매핑됩니다.
    - 값이 낮을수록 전체 이미지가 어두워집니다.

### 출력 (Outputs)

- **output**: 레벨 설정이 적용되어 조정된 이미지

## 예시

일반적인 레벨 조정 워크플로우:

1. LoadImage를 사용하여 이미지를 불러옵니다.
1. 해당 이미지를 AdjustImageLevels 노드의 "input_image" 파라미터에 연결합니다.
1. 이미지를 개선하기 위해 레벨을 조정합니다:
    - 섀도우 디테일을 보존하기 위해 shadows를 20으로 설정
    - 중간 톤을 밝게 하기 위해 midtones를 0.8로 설정
    - 하이라이트 디테일을 보존하기 위해 highlights를 240으로 설정
    - 섀도우를 약간 밝게 만들기 위해 output_shadows를 10으로 설정
    - 하이라이트를 약간 어둡게 만들기 위해 output_highlights를 245로 설정
1. "output"을 DisplayImage에 연결하여 결과를 확인합니다.

## 중요 참고 사항

- **실시간 미리보기**: 슬라이더를 이동하면 변경 사항이 실시간으로 적용됩니다.
- **RGBA 지원**: 이 노드는 RGBA 이미지의 투명도를 그대로 유지합니다.
- **전문가급 품질**: 정밀한 레벨 조정을 위해 룩업 테이블(LUT)을 사용합니다.
- **유효성 검사**: 노드가 정상적으로 작동하도록 항상 shadows < highlights 상태를 유지합니다.

## 자주 묻는 질문 및 문제 해결

- **변경 사항이 보이지 않음**: 슬라이더를 기본값에서 다른 값으로 조정했는지 확인하세요.
- **과도하게 처리된 느낌**: 극단적인 값에 주의하세요. 미세한 조정이 대개 가장 자연스럽습니다.
- **클리핑(디테일 손실)**: shadows를 너무 높게 설정하거나 highlights를 너무 낮게 설정하면 이미지의 디테일이 손실될 수 있습니다.

## 기술 세부 정보

이 노드는 3단계 프로세스를 적용합니다:

1. **입력 레벨**: shadows 및 highlights를 기준으로 입력 범위를 클리핑하고 매핑합니다.
1. **감마 보정**: 멱법칙 변환(power-law transformation)을 사용하여 중간 톤 조정을 적용합니다.
1. **출력 레벨**: 처리된 값을 지정된 출력 범위로 매핑합니다.

이를 통해 전문 사진 편집 소프트웨어의 레벨 조정 도구와 동일한 기능을 제공합니다.
