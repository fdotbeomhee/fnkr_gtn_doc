# AdjustImageEQ

## 어떤 노드인가요?

AdjustImageEQ 노드는 밝기(Brightness), 대비(Contrast), 채도(Saturation), 감마 보정(Gamma Correction)을 정밀하게 제어하여 이미지를 미세 조정할 수 있는 노드입니다. 워크플로우 내에 전문 사진 편집 도구가 내장되어 있는 것과 같아 이미지의 시각적 완성도를 완벽하게 제어할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 가시성을 높이기 위해 이미지 밝기 및 대비 향상
- 색상을 더 생생하게 만들거나 차분하게 만들기 위한 채도 조절
- 노출 문제를 해결하기 위한 감마 보정 적용
- 다른 처리 노드로 전달하기 전 이미지 미세 조정
- 여러 이미지 전반에 걸쳐 일관된 조명/색감 조성
- 특정 출력 요구 사항에 맞게 이미지 준비

## 사용 방법

### 기본 설정

1. 워크플로우에 AdjustImageEQ 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 슬라이더를 조절하여 이미지를 미세 조정합니다.
1. 처리된 이미지가 "output" 파라미터를 통해 출력됩니다.

### 파라미터 (Parameters)

#### 조정 설정

- **brightness** (0.0-3.0, 기본값: 1.0): 전반적인 이미지 밝기 제어

    - 1.0 미만: 이미지가 어두워짐
    - 1.0 초과: 이미지가 밝아짐
    - 1.0 = 변경 없음

- **contrast** (0.0-3.0, 기본값: 1.0): 밝은 영역과 어두운 영역 간의 대비 제어

    - 1.0 미만: 대비 감소 (회색 톤 증가)
    - 1.0 초과: 대비 증가 (더 극적인 명암비)
    - 1.0 = 변경 없음

- **saturation** (0.0-3.0, 기본값: 1.0): 색상 강도(채도) 제어

    - 1.0 미만: 채도 감소 (흑백에 가까워짐)
    - 1.0 초과: 채도 증가 (색상이 더 생생해짐)
    - 1.0 = 변경 없음

- **gamma** (0.1-10.0, 기본값: 1.0): 중간 톤(Midtone) 밝기 제어

    - 1.0 미만: 중간 톤이 밝아짐
    - 1.0 초과: 중간 톤이 어두워짐
    - 1.0 = 변경 없음

### 출력 (Outputs)

- **output**: EQ 설정이 적용되어 조정된 이미지

## 예시

일반적인 이미지 보정 워크플로우:

1. LoadImage 또는 GenerateImage를 사용하여 이미지를 불러오거나 생성합니다.
1. 해당 이미지를 AdjustImageEQ 노드의 "input_image" 파라미터에 연결합니다.
1. 원하는 분위기를 얻기 위해 슬라이더를 조정합니다:
    - 더 밝은 이미지를 위해 밝기를 1.2로 증가
    - 더 뚜렷한 그림자를 위해 대비를 1.1로 증가
    - 더 생생한 색감을 위해 채도를 1.3으로 증가
    - 중간 톤을 밝게 하기 위해 감마를 0.9로 조정
1. "output"을 DisplayImage에 연결하여 결과를 확인합니다.

## 중요 참고 사항

- **실시간 미리보기**: 슬라이더를 움직이면 변경 사항이 실시간으로 적용됩니다.
- **RGBA 지원**: 이 노드는 RGBA 이미지의 투명도를 그대로 유지합니다.
- **고품질**: 전문적인 수준의 품질 조정을 위해 PIL의 ImageEnhance를 사용합니다.
- **비파괴적 처리**: 워크플로우 내에서 원본 이미지 데이터는 손상되지 않고 유지됩니다.

## 자주 묻는 질문 및 문제 해결

- **변경 사항이 보이지 않음**: 슬라이더를 기본값(1.0)에서 다른 값으로 이동했는지 확인하세요.
- **과도하게 처리된 느낌**: 극단적인 값 사용에 주의하세요. 대개의 경우 미세한 조정이 가장 좋은 결과를 제공합니다.
- **색상 왜곡 현상**: 감마 조정은 색상 밸런스에 영향을 미칠 수 있으므로 전체적인 결과를 주의 깊게 관찰하세요.

## 기술 세부 정보

이 노드는 고품질 이미지 조정을 위해 PIL의 ImageEnhance 모듈을 사용합니다:

- **밝기**: 픽셀 값에 밝기 팩터를 곱합니다.
- **대비**: PIL의 대비 알고리즘을 사용하여 대비 향상을 적용합니다.
- **채도**: 채도 제어를 위해 PIL의 색상 향상 기능을 사용합니다.
- **감마**: 정밀한 제어를 위해 룩업 테이블(LUT)을 사용하여 감마 보정을 적용합니다.
