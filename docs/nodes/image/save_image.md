# SaveImage

## 어떤 노드인가요?

SaveImage 노드를 사용하면 이미지를 로컬 파일 시스템에 저장할 수 있습니다. 이미지 처리 워크플로우의 결과를 보존하는 데 필수적인 노드로, 다양한 형식과 품질 설정으로 이미지를 내보낼 수 있습니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 처리된 이미지를 컴퓨터에 저장할 때
- 특정 포맷(PNG, JPEG 등)으로 이미지를 내보낼 때
- 이미지 품질 및 압축 설정을 제어할 때
- 이미지 처리 워크플로우의 결과를 영구 보존할 때
- 중요한 이미지의 백업을 생성할 때
- 다른 애플리케이션에서 사용할 수 있도록 이미지를 내보낼 때

## 사용 방법

### 기본 설정

1. 워크플로우에 SaveImage 노드를 추가합니다.
1. 이미지 소스를 "input_image" 입력에 연결합니다.
1. 출력 파일 경로와 형식을 설정합니다.
1. 이미지가 지정된 위치에 저장됩니다.

### 파라미터 (Parameters)

#### 이미지 입력 (Image Input)

- **input_image**: 저장할 이미지 (모든 이미지 처리 노드에서 연결 가능)

#### 출력 설정 (Output Settings)

- **output_path**: 이미지가 저장될 파일 경로

    - 상대 경로 가능 (예: "output/image.png")
    - 절대 경로 가능 (예: "/Users/username/Desktop/image.png")
    - 파일 확장자에 따라 형식이 결정됩니다.

- **image_format**: 이미지를 저장할 포맷

    - **PNG**: 무손실 포맷, 투명도 지원
    - **JPEG**: 압축 포맷, 더 작은 파일 크기
    - **BMP**: 비압축 비트맵 포맷
    - **TIFF**: 전문가용 고품질 포맷

#### 품질 설정 (JPEG 전용)

- **quality** (1-100, 기본값: 95): JPEG 압축 품질
    - 높은 값 = 더 우수한 품질, 더 큰 파일 크기
    - 낮은 값 = 낮은 품질, 더 작은 파일 크기

### 출력 (Outputs)

- **saved_path**: 이미지가 저장된 파일 경로
- **file_size**: 저장된 파일의 크기(바이트 단위)

## 예시

일반적인 이미지 저장 워크플로우:

1. AdjustImageEQ 또는 다른 처리 노드를 사용하여 이미지를 처리합니다.
1. 처리된 이미지를 SaveImage 노드의 "input_image" 파라미터에 연결합니다.
1. 출력 설정을 지정합니다:
    - output_path를 "processed_image.png"로 설정
    - 무손실 품질을 위해 image_format을 "PNG"로 선택
1. 이미지가 지정된 위치에 저장됩니다.
1. saved_path 출력에서 파일이 저장된 위치를 확인할 수 있습니다.

## 중요 참고 사항

- **파일 경로**: 출력 디렉터리가 존재하는지 확인하세요. 존재하지 않으면 노드가 디렉터리를 생성합니다.
- **포맷 지원**: 포맷마다 지원하는 기능(투명도, 압축 등)이 다릅니다.
- **품질 제어**: JPEG quality 설정은 JPEG 포맷에만 적용됩니다.
- **덮어쓰기**: 노드는 동일한 이름의 기존 파일이 있으면 덮어씁니다.

## 자주 묻는 질문 및 문제 해결

- **파일이 저장되지 않음**: output_path가 유효하고 해당 경로에 쓰기 권한이 있는지 확인하세요.
- **잘못된 포맷**: 파일 확장자가 image_format 설정과 일치하는지 확인하세요.
- **품질 저하**: JPEG 포맷의 경우 quality 설정을 높이세요.

## 기술 세부사항

이 노드는 PIL의 이미지 저장 기능을 활용합니다:

- **PNG**: 투명도를 지원하는 무손실 압축
- **JPEG**: 품질 제어가 가능한 손실 압축
- **BMP**: 비압축 비트맵 포맷
- **TIFF**: 다양한 압축 옵션을 제공하는 고품질 포맷

이를 통해 작업 결과를 보존해야 하는 모든 워크플로우에 안정적인 이미지 저장 기능을 제공합니다.
