# CompareImages

## 어떤 노드인가요?

CompareImages 노드는 두 개의 이미지를 나란히(Side by side) 비교하여 차이점을 쉽게 확인하고, 변경 사항을 평가하거나 동일한 이미지의 여러 버전을 비교할 수 있도록 지원하는 노드입니다. A/B 테스트, 품질 관리(QC), 다양한 이미지 처리 작업의 효과 분석에 적합합니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 처리 전/후(Before & After) 이미지 비교
- 서로 다른 프롬프트로 생성된 이미지의 A/B 테스트
- 이미지 처리 설정에 따른 품질 평가
- 동일한 이미지의 다양한 버전 비교
- 이미지 조정 및 보정 효과 분석
- 이미지 처리 파이프라인의 품질 검수(QC)
- 검토를 위한 여러 이미지 옵션 나란히 제시

## 사용 방법

### 기본 설정

1. 워크플로우에 CompareImages 노드를 추가합니다.
1. 두 이미지 소스를 "image1"과 "image2" 입력에 각각 연결합니다.
1. 두 이미지가 나란히 배치된 비교 뷰가 표시됩니다.

### 파라미터 (Parameters)

- **image1**: 비교할 첫 번째 이미지 (좌측)
- **image2**: 비교할 두 번째 이미지 (우측)

### 출력 (Outputs)

- **comparison**: 두 이미지를 나란히 배치한 비교 이미지

## 예시

일반적인 이미지 비교 워크플로우:

1. LoadImage를 사용하여 원본 이미지를 불러옵니다.
1. AdjustImageEQ 또는 다른 처리 노드를 사용하여 이미지를 수정합니다.
1. 원본 이미지를 CompareImages의 "image1" 입력에 연결합니다.
1. 처리된 이미지를 CompareImages의 "image2" 입력에 연결합니다.
1. 노드에 두 이미지가 나란히 표시되어 차이점을 쉽게 비교할 수 있습니다.

## 중요 참고 사항

- **나란히 표시(Side-by-Side)**: 편리한 비교를 위해 이미지가 좌우로 배치됩니다.
- **자동 스케일링**: 비교 뷰 크기에 맞게 이미지가 자동으로 조정됩니다.
- **실시간 업데이트**: 두 입력 이미지 중 하나라도 변경되면 비교 결과가 즉시 갱신됩니다.
- **고품질 유지**: 정확한 비교를 위해 원본 품질을 최대한 보존합니다.

## 자주 묻는 질문 및 문제 해결

- **이미지가 표시되지 않음**: image1과 image2 입력이 모두 올바르게 연결되었는지 확인하세요.
- **이미지가 너무 작게 보임**: 노드가 디스플레이 영역에 맞게 이미지를 자동으로 조정합니다.
- **레이아웃 문제**: 좌우 나란히 배치되는 레이아웃은 비교에 최적화되어 자동으로 구성됩니다.

## 기술 세부 정보

이 노드는 두 입력 이미지를 나란히 결합한 합성 이미지를 생성하여 다음과 같은 작업을 쉽게 수행할 수 있도록 합니다:

- 이미지 품질 비교
- 프로세싱 효과 시각화
- 다양한 버전 평가
- 이미지 처리에 대한 정확한 판단 및 의사결정

결과 평가가 필요한 모든 이미지 처리 및 생성 워크플로우에 필수적인 노드입니다.
