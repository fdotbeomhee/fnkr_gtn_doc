# InvertMask

## 어떤 노드인가요?

InvertMask 노드는 입력 마스크의 반전 버전을 만듭니다. 투명도 값을 뒤집어 불투명했던 영역은 투명해지고 투명했던 영역은 불투명해집니다. 이는 보색 마스크를 생성하거나 포지티브/네거티브 선택 영역 간을 전환할 때 유용합니다.

## 언제 사용하나요?

다음과 같은 작업에 이 노드를 사용하세요:

- 기존 마스크의 반대 마스크를 생성할 때
- 포지티브 선택 영역과 네거티브 선택 영역 간을 전환할 때
- 투명도 효과를 반전할 때
- 이미지 합성을 위한 보색 마스크를 생성할 때
- 워크플로우에서 마스크의 적용 영역을 뒤집을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 InvertMask 노드를 추가합니다.
1. 마스크 소스를 "input_mask" 입력에 연결합니다.
1. 반전된 마스크는 "output_mask" 파라미터에서 확인할 수 있습니다.

### 파라미터 (Parameters)

- **input_mask**: 반전할 마스크 (DisplayMask 또는 PaintMask와 같은 다른 마스크 노드에서 연결 가능)

### 출력 (Outputs)

- **output_mask**: 입력 마스크의 반전된 버전

## 예시

일반적인 워크플로우 패턴:

1. DisplayMask 또는 PaintMask와 같은 노드를 사용하여 마스크를 생성합니다.
1. 해당 마스크를 InvertMask 노드의 "input_mask" 파라미터에 연결합니다.
1. InvertMask 노드가 마스크의 반전 버전을 생성합니다.
1. "output_mask"를 DisplayImage에 연결하여 반전된 마스크를 확인하거나 다른 마스크 처리 노드에 연결합니다.

## 중요 참고 사항

- **반전 로직**: 입력 마스크의 흰색 영역은 출력에서 검은색이 되고, 검은색 영역은 흰색이 됩니다.
- **알파 채널 처리**: RGBA 이미지의 경우 노드는 알파 채널을 특정하여 반전합니다.
- **그레이스케일 변환**: 그레이스케일이 아닌 이미지는 반전 전에 그레이스케일로 변환됩니다.
- **실시간 처리**: 노드는 연결이 이루어지거나 입력 값이 변경될 때 즉시 마스크를 처리합니다.
- **출력 형식**: 품질을 보존하기 위해 반전된 마스크는 PNG 파일로 저장됩니다.

## 자주 묻는 질문 및 문제 해결

- **출력이 없음**: 마스크 소스가 "input_mask" 파라미터에 제대로 연결되어 있는지 확인하세요.
- **예상치 못한 결과**: 반전은 마스크 값을 뒤집어 불투명했던 부분이 투명해집니다.
- **컬러 이미지 입력**: 컬러 이미지를 입력하면 반전 전에 그레이스케일로 변환됩니다.

## 기술 세부사항

이 노드는 다양한 이미지 모드를 지능적으로 처리합니다:

- **RGBA**: RGB 채널을 보존하면서 알파 채널을 반전
- **그레이스케일 (L)**: 그레이스케일 값의 직접 반전
- **기타 모드**: 먼저 그레이스케일로 변환한 후 반전 적용

반전은 밝기 값을 뒤집는 `255 - original_value` 공식을 사용하여 수행됩니다.
