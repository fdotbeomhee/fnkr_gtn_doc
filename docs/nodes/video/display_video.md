# DisplayVideo

## 어떤 노드인가요?

DisplayVideo 노드는 워크플로우 내에서 비디오 콘텐츠를 간편하게 확인하고 화면에 표시하는 노드입니다.

## 언제 사용하나요?

다음과 같은 상황에서 DisplayVideo 노드를 사용합니다:

- 워크플로우 내에서 비디오 결과나 정보를 확인해야 할 때
- 이전 처리 단계에서 생성된 비디오 출력을 표시하고 싶을 때
- 워크플로우 실행 중에 업데이트될 비디오 콘텐츠의 플레이스홀더가 필요할 때
- 워크플로우 내에서 알아보기 쉬운 레이블이나 설명을 만들고 싶을 때
- 프로세스의 특정 단계에서 비디오 데이터를 시각적으로 확인해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayVideo 노드를 추가합니다.
1. 필요에 따라 초기 비디오 값을 설정합니다.
1. 비디오 파라미터에 입력을 연결하거나 비디오를 직접 선택합니다.
1. 비디오 입력이 필요한 다른 노드에 비디오 출력을 연결합니다.

### 파라미터 (Parameters)

- **video**: 화면에 표시할 비디오 콘텐츠입니다. (VideoArtifact 및 VideoUrlArtifact 지원)

### 출력 (Outputs)

- **video**: 동일한 비디오 콘텐츠이며, 다른 노드에 연결할 수 있는 출력으로 그대로 제공됩니다.

## 예시

비디오 정보를 처리하고 표시하는 워크플로우를 구성하려는 경우:

1. 워크플로우에 DisplayVideo 노드를 추가합니다.
1. LoadVideo 노드의 출력을 DisplayVideo 노드의 video 파라미터에 연결합니다.
1. 워크플로우가 실행되면 노드 내에 비디오 콘텐츠가 표시됩니다.

## 중요 참고 사항

- DisplayVideo 노드는 시각적 확인용 노드이며 비디오 콘텐츠를 변형하거나 수정하지 않습니다.
- 어떤 처리나 포맷 변환 없이 전달받은 비디오를 있는 그대로 통과시킵니다.
- 일반적인 비디오 포맷(mp4, avi, mov 등)을 지원합니다.
- 비디오 플레이어 컨트롤을 사용하여 재생, 일시정지, 탐색(스크러빙)이 가능합니다.

## 자주 묻는 질문 및 문제 해결

- **비디오가 표시되지 않음**: 이 노드에 비디오 소스가 올바르게 연결되어 있는지 확인하세요.
- **비디오가 재생되지 않음**: 비디오 파일이 지원되는 포맷인지, 파일이 손상되지 않았는지 확인하세요.
