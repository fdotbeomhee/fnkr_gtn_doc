# AdjustVideoEQ

## 어떤 노드인가요?

AdjustVideoEQ 노드를 사용하면 비디오의 밝기(Brightness), 대비(Contrast), 채도(Saturation), 감마(Gamma) 설정을 조절할 수 있습니다. FFmpeg의 고품질 이퀄라이제이션 필터를 활용하여 비디오 콘텐츠의 시각적 외관을 정밀하게 제어합니다.

## 언제 사용하나요?

다음과 같은 상황에서 AdjustVideoEQ 노드를 사용합니다:

- 비디오의 노출(Exposure) 문제를 보정해야 할 때
- 조명이 부족하거나 어두운 영상의 시각적 품질을 개선하고 싶을 때
- 예술적 또는 기술적 이유로 색상 채도를 조절해야 할 때
- 여러 비디오 클립의 톤과 느낌을 일치시키고 싶을 때
- 특정 시각적 조정이 필요한 콘텐츠를 제작할 때
- 비디오의 전반적인 시각적 매력을 향상시키고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 AdjustVideoEQ 노드를 추가합니다.
1. "video" 입력에 비디오 소스를 연결합니다.
1. 밝기, 대비, 채도, 감마 파라미터를 조절합니다.
1. 워크플로우를 실행하여 EQ 조정을 적용합니다.

### 파라미터 (Parameters)

- **video**: 조정할 비디오 콘텐츠입니다. (VideoArtifact 및 VideoUrlArtifact 지원)

- **brightness**: 밝기 조정 값입니다. (-1.0 ~ 1.0, 기본값: 0.0)

    - -1.0 = 매우 어두움
    - 0.0 = 일반 밝기 (기본값)
    - 1.0 = 매우 밝음

- **contrast**: 대비 조정 값입니다. (0.0 ~ 3.0, 기본값: 1.0)

    - 0.0 = 대비 없음 (평면적인 이미지)
    - 1.0 = 일반 대비 (기본값)
    - 3.0 = 매우 높은 대비

- **saturation**: 채도 조정 값입니다. (0.0 ~ 3.0, 기본값: 1.0)

    - 0.0 = 흑백
    - 1.0 = 일반 채도 (기본값)
    - 3.0 = 매우 강렬한 색상

- **gamma**: 감마 조정 값입니다. (0.1 ~ 10.0, 기본값: 1.0)

    - 0.1 = 매우 밝은 중간 톤
    - 1.0 = 일반 감마 (기본값)
    - 10.0 = 매우 어두운 중간 톤

- **processing_speed**: 처리 속도와 출력 품질 간의 균형을 조절합니다. (기본값: "balanced")

    - **fast**: 가장 빠른 처리 속도, 낮은 품질 (ultrafast 프리셋, CRF 30)
    - **balanced**: 속도와 품질의 균형 잡힌 설정 (medium 프리셋, CRF 23)
    - **quality**: 최고 품질, 느린 처리 속도 (slow 프리셋, CRF 18)

### 출력 (Outputs)

- **video**: EQ 조정이 적용된 비디오이며, 다른 노드에 연결할 수 있는 출력으로 제공됩니다.

## 예시

어두운 비디오를 밝게 만들고 채도를 높이려는 경우:

1. 워크플로우에 AdjustVideoEQ 노드를 추가합니다.
1. LoadVideo 노드의 비디오 출력을 AdjustVideoEQ의 "video" 입력에 연결합니다.
1. 비디오를 밝게 하기 위해 "brightness"를 0.3으로 설정합니다.
1. 선명도를 높이기 위해 "contrast"를 1.2로 설정합니다.
1. 색상을 더 생동감 있게 만들기 위해 "saturation"을 1.5로 설정합니다.
1. 자연스러운 중간 톤을 위해 "gamma"를 1.0으로 유지합니다.
1. 워크플로우를 실행합니다. 비디오가 더 밝아지고 생생한 색감으로 변합니다.
1. 출력 파일명은 `{original_filename}_eq_b0.30_c1.20_s1.50_g1.00.{format}` 형태가 됩니다.

## 중요 참고 사항

- AdjustVideoEQ 노드는 고품질 이퀄라이제이션 알고리즘을 갖춘 FFmpeg를 사용합니다.
- 모든 파라미터가 상호작용하여 최종 시각 효과를 생성합니다.
- 원본 오디오 트랙은 그대로 유지됩니다.
- 처리 시간은 비디오의 길이와 해상도에 따라 달라집니다.
- 문제 해결을 위한 로그 정보가 제공됩니다.

## 파라미터 권장 사항

- **어두운 영상**: brightness 0.2-0.5, contrast 1.1-1.3 사용
- **과다 노출된 영상**: brightness -0.2 ~ -0.5, contrast 0.8-0.9 사용
- **밋밋하고 평면적인 영상**: contrast 1.2-1.5, saturation 1.1-1.3 사용
- **생동감 넘치는 색상**: saturation 1.3-1.8, gamma 0.9-1.1 사용
- **시네마틱 룩**: contrast 1.1-1.2, saturation 0.8-0.9, gamma 1.1-1.2 사용
- **빈티지 효과**: saturation 0.7-0.8, gamma 1.2-1.4 사용

## 자주 묻는 질문 및 문제 해결

- **처리 시간 초과 (Timeout)**: 고용량 비디오는 처리에 더 오랜 시간이 걸릴 수 있으며, 노드의 기본 제한 시간은 5분입니다.
- **너무 밝거나 어두움**: brightness 값을 조절하세요. (어둡게 하려면 음수, 밝게 하려면 양수 사용)
- **색상이 너무 과함**: saturation 값을 1.0 미만으로 줄이세요.
- **비디오 입력 없음**: "video" 입력에 유효한 비디오 소스가 연결되었는지 확인하세요.
- **FFmpeg 오류**: 처리 실패 시 자세한 오류 정보를 확인하려면 logs 파라미터를 참조하세요.
