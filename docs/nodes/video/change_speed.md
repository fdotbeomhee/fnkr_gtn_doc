# ChangeSpeed

## 어떤 노드인가요?

ChangeSpeed 노드는 비디오의 재생 속도를 변경합니다. FFmpeg의 `setpts` 필터를 사용하여 비디오 타이밍을 조정하고 오디오 속도도 이에 맞추어 자동으로 변경하므로, 오디오와 비디오의 싱크를 유지하면서 부드러운 속도 전환 효과를 만들어냅니다.

## 언제 사용하나요?

다음과 같은 상황에서 ChangeSpeed 노드를 사용합니다:

- 배속/패스트 모션(Fast-motion) 효과를 제작하고 싶을 때 (예: 2배속, 3배속 등)
- 슬로 모션(Slow-motion) 효과를 제작해야 할 때 (예: 0.5배속, 0.25배속 등)
- 긴 비디오를 빠르게 검토하기 위해 속도를 높일 때
- 빠른 움직임을 정밀 분석하기 위해 느리게 재생할 때
- 타임랩스(Time-lapse) 또는 슬로 모션 콘텐츠를 제작할 때
- 시청 대상에 맞춰 비디오의 호흡과 템포를 조절하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 ChangeSpeed 노드를 추가합니다.
1. "video" 입력에 비디오 소스를 연결합니다.
1. 원하는 재생 속도 배율을 설정합니다.
1. 워크플로우를 실행하여 비디오의 재생 속도를 변경합니다.

### 파라미터 (Parameters)

- **video**: 속도를 변경할 비디오 콘텐츠입니다. (VideoArtifact 및 VideoUrlArtifact 지원)

- **speed**: 재생 속도 배율입니다. (0.1-10.0x, 기본값: 1.0)

    - 0.1 = 10배 느림 (극도의 슬로 모션)
    - 0.5 = 2배 느림 (슬로 모션)
    - 1.0 = 정상 속도 (기본값)
    - 2.0 = 2배 빠름 (배속 재생)
    - 5.0 = 5배 빠름 (매우 빠른 배속)
    - 10.0 = 10배 빠름 (최대 속도)

- **include_audio**: 활성화 시 출력 파일에 오디오를 포함합니다. (기본값: true)

    - 활성화: 오디오가 비디오 속도에 맞춰 자동으로 조절됩니다.
    - 비활성화: 오디오 트랙이 없는 무음 비디오를 생성합니다.

- **processing_speed**: 처리 속도와 출력 품질 간의 균형을 조절합니다. (기본값: "balanced")

    - **fast**: 가장 빠른 처리 속도, 낮은 품질 (ultrafast 프리셋, CRF 30)
    - **balanced**: 속도와 품질의 균형 잡힌 설정 (medium 프리셋, CRF 23)
    - **quality**: 최고 품질, 느린 처리 속도 (slow 프리셋, CRF 18)

### 출력 (Outputs)

- **video**: 재생 속도가 변경된 비디오이며, 다른 노드에 연결할 수 있는 출력으로 제공됩니다.

## 예시

비디오를 3배속으로 빠르게 재생하여 패스트 모션 효과를 연출하려는 경우:

1. 워크플로우에 ChangeSpeed 노드를 추가합니다.
1. LoadVideo 노드의 비디오 출력을 ChangeSpeed의 "video" 입력에 연결합니다.
1. 3배속 재생을 위해 "speed"를 3.0으로 설정합니다.
1. 속도에 맞춘 오디오를 포함하기 위해 "include_audio"를 활성화(기본값) 상태로 유지합니다.
1. 워크플로우를 실행합니다. 비디오가 오디오 싱크에 맞춰 3배 빠르게 재생됩니다.
1. 출력 파일명은 `{original_filename}_speed3.0.{format}` 형태가 됩니다.

## 중요 참고 사항

- ChangeSpeed 노드는 고품질 속도 조절을 위해 FFmpeg의 `setpts` 필터를 사용합니다.
- 싱크를 유지하기 위해 `atempo` 필터를 사용하여 오디오 속도도 자동으로 조절됩니다 (include_audio가 활성화된 경우).
- 속도 변경은 비디오와 오디오에 동시에 적용됩니다.
- 처리 시간은 비디오의 길이와 해상도에 따라 달라집니다.
- 극단적인 속도 변경(매우 빠르거나 매우 느림)은 오디오 품질에 영향을 줄 수 있습니다.
- include_audio가 비활성화되면 출력 비디오는 무음으로 생성됩니다.

## 파라미터 권장 사항

- **패스트 모션**: 빠른 배속 효과를 위해 2.0-5.0 사용
- **슬로 모션**: 슬로 모션 효과를 위해 0.25-0.75 사용
- **타임랩스**: 초고속 재생을 위해 5.0-10.0 사용
- **동작 분석**: 빠른 동작을 면밀히 관찰하기 위해 0.5-0.75 사용
- **빠른 검토**: 긴 콘텐츠를 빠르게 확인할 때 2.0-3.0 사용

## 자주 묻는 질문 및 문제 해결

- **처리 시간 초과 (Timeout)**: 대용량 비디오는 처리에 더 많은 시간이 걸릴 수 있으며, 노드의 기본 제한 시간은 5분입니다.
- **오디오 품질 저하**: 극단적인 속도 변경은 오디오 선명도에 영향을 줄 수 있습니다.
- **비디오 입력 없음**: "video" 입력에 유효한 비디오 소스가 연결되었는지 확인하세요.
- **FFmpeg 오류**: 처리 실패 시 자세한 오류 정보를 확인하려면 logs 파라미터를 참조하세요.

## 속도 설정 예시

- **0.25x**: 4배 느림 - 빠른 동작 분석에 적합
- **0.5x**: 2배 느림 - 전형적인 슬로 모션
- **1.0x**: 정상 속도 - 변경 없음
- **2.0x**: 2배 빠름 - 빠른 배속
- **3.0x**: 3배 빠름 - 매우 빠른 배속
- **5.0x**: 5배 빠름 - 타임랩스 효과
