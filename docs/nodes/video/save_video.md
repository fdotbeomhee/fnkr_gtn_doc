# SaveVideo

## 어떤 노드인가요?

SaveVideo 노드는 워크플로우의 비디오 콘텐츠를 컴퓨터의 파일로 저장할 수 있게 해줍니다.

## 언제 사용하나요?

다음과 같은 상황에서 SaveVideo 노드를 사용합니다:

- 워크플로우의 비디오 결과물을 내보내고자 할 때
- 처리된 비디오 콘텐츠를 디스크에 저장해야 할 때
- 워크플로우 외부에서 사용할 수 있는 비디오 파일을 만들고 싶을 때
- 나중에 사용하기 위해 비디오 출력물을 아카이빙(보관)해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 SaveVideo 노드를 추가합니다.
1. "video" 입력에 비디오 소스를 연결합니다.
1. 필요한 경우 출력 파일 이름과 경로를 지정합니다.
1. 워크플로우를 실행하여 비디오 파일을 저장합니다.

### 파라미터 (Parameters)

- **video**: 저장할 비디오 콘텐츠 (VideoArtifact, VideoUrlArtifact 및 dict 지원)
- **output_path**: 비디오가 저장될 파일 이름 및 경로 (기본값: "griptape_nodes.mp4")

### 출력 (Outputs)

- **output_path**: 비디오가 저장된 경로

## 예시

워크플로우에서 처리된 비디오를 저장하고자 하는 경우:

1. 워크플로우에 SaveVideo 노드를 추가합니다.
1. 다른 노드의 비디오 출력을 SaveVideo의 "video" 입력에 연결합니다.
1. "output_path"를 원하는 파일 이름(예: "my_video.mp4")으로 설정합니다.
1. 워크플로우를 실행하면 비디오가 지정된 위치에 저장됩니다.

## 중요 참고 사항

- SaveVideo 노드는 일반적인 비디오 형식(.mp4, .avi, .mov 등)을 지원합니다.
- 출력 경로에 디렉토리 구조를 포함할 수 있습니다(예: "videos/output.mp4").
- 확장자를 제공하지 않으면 기본적으로 .mp4가 사용됩니다.
- 디렉토리가 존재하지 않는 경우 노드가 자동으로 디렉토리를 생성합니다.
- UI의 저장 버튼을 사용하여 저장 위치를 직접 찾아볼 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **권한 거부(Permission Denied)**: 지정된 디렉토리에 대한 쓰기 권한이 있는지 확인하세요.
- **잘못된 경로(Invalid Path)**: 출력 경로가 유효하고 디렉토리가 존재하는지 확인하세요.
- **지원되지 않는 형식**: 지원되는 비디오 파일 확장자를 사용하고 있는지 확인하세요.
- **비디오 입력 없음**: "video" 입력에 비디오 소스가 올바르게 연결되어 있는지 확인하세요.
