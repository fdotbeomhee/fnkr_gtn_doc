# LoadVideo

## 어떤 노드인가요?

LoadVideo는 워크플로우로 비디오를 가져올 수 있게 해주는 기본 구성 요소 노드입니다. 프로젝트에서 비디오를 사용할 수 있도록 비디오 파일을 불러오는 역할을 합니다.

## 언제 사용하나요?

다음과 같은 상황에서 이 노드를 사용합니다:

- 다른 노드에서 생성된 비디오를 사용하고자 할 때
- 워크플로우 내의 다른 노드로 비디오를 전달할 때
- 프로젝트의 일부로 비디오를 표시할 때
- 디스크의 비디오 파일을 워크플로우로 불러올 때

## 사용 방법

### 기본 설정

1. 워크플로우에 LoadVideo 노드를 추가합니다.
1. 비디오 소스에 연결하거나 파일 브라우저를 사용하여 비디오 파일을 선택합니다.

### 파라미터 (Parameters)

- **video**: 불러올 비디오 (다른 노드의 출력에 연결하거나 파일에서 직접 불러올 수 있음)

### 출력 (Outputs)

- **video**: 흐름 내 다른 노드에서 사용할 수 있는 로드된 비디오

## 예시

컴퓨터에서 비디오 파일을 불러오고자 하는 경우:

1. 워크플로우에 LoadVideo 노드를 추가합니다.
1. 파일 브라우저 아이콘을 클릭하여 컴퓨터에서 비디오 파일을 선택합니다.
1. LoadVideo 노드가 해당 비디오를 워크플로우의 나머지 부분에서 사용할 수 있도록 제공합니다.

## 중요 참고 사항

- LoadVideo는 비디오를 단순히 전달할 뿐 비디오 자체를 변경하지 않습니다.
- 파일 브라우저 아이콘을 클릭하여 컴퓨터에서 비디오를 선택할 수 있습니다.
- 비디오 미리보기는 확장(expander) 아이콘을 클릭하여 확대할 수 있습니다.
- 일반적인 비디오 형식(mp4, avi, mov 등)을 지원합니다.

## 자주 묻는 질문 및 문제 해결

- **비디오가 표시되지 않음**: 이 노드에 비디오 소스가 제대로 연결되어 있거나 파일이 선택되었는지 확인하세요.
- **지원되지 않는 형식**: 비디오 파일이 지원되는 형식인지 확인하세요.
