# AddFilmGrain

## 어떤 노드인가요?

AddFilmGrain 노드는 정교한 노이즈 생성 및 휘도(Luminance) 마스킹 기술을 활용하여 비디오에 사실적인 필름 그레인(Film grain) 질감을 추가합니다. 비디오 내 밝기가 다른 영역에 맞추어 강도가 다르게 적용되는 진정한 필름 스타일의 질감을 만들어냅니다.

## 언제 사용하나요?

다음과 같은 상황에서 AddFilmGrain 노드를 사용합니다:

- 디지털 비디오에 영화 같은 필름 느낌을 더하고 싶을 때
- 빈티지 또는 레트로 비디오 효과를 제작해야 할 때
- 깔끔한 디지털 영상에 텍스처와 개성을 불어넣고 싶을 때
- 실제 필름으로 촬영한 것처럼 보이는 콘텐츠를 제작할 때
- 비디오의 시각적 깊이감과 분위기를 강화하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 AddFilmGrain 노드를 추가합니다.
1. "video" 입력에 비디오 소스를 연결합니다.
1. 그레인 강도(grain_intensity), 휘도 임계값(luminance_threshold), 그레인 스케일(grain_scale) 파라미터를 조절합니다.
1. 워크플로우를 실행하여 비디오에 필름 그레인을 추가합니다.

### 파라미터 (Parameters)

- **video**: 필름 그레인을 추가할 비디오 콘텐츠입니다. (VideoArtifact 및 VideoUrlArtifact 지원)

- **grain_intensity**: 필름 그레인 강도입니다. (0.05-1.0, 기본값: 0.15)

    - 0.05 = 매우 은은한 그레인
    - 0.15 = 적당한 그레인 (기본값)
    - 0.5 = 강한 그레인
    - 1.0 = 최대 그레인 강도

- **luminance_threshold**: 그레인이 가장 뚜렷하게 보일 휘도 수준입니다. (50-100, 기본값: 75)

    - 50 = 어두운 영역에서 그레인이 더 잘 보임
    - 75 = 중간 톤(Mid-tone)에서 그레인이 잘 보임 (기본값, 밝은 영역에 적합)
    - 100 = 밝은 영역에서 그레인이 더 잘 보임

- **grain_scale**: 그레인 입자 크기 배율입니다. (1.0-4.0, 기본값: 2.0)

    - 1.0 = 고운 미세 입자
    - 2.0 = 중간 크기 입자 (기본값)
    - 4.0 = 굵은 입자

- **processing_speed**: 처리 속도와 출력 품질 간의 균형을 조절합니다. (기본값: "balanced")

    - **fast**: 가장 빠른 처리 속도, 낮은 품질 (ultrafast 프리셋, CRF 30)
    - **balanced**: 속도와 품질의 균형 잡힌 설정 (medium 프리셋, CRF 23)
    - **quality**: 최고 품질, 느린 처리 속도 (slow 프리셋, CRF 18)

### 출력 (Outputs)

- **video**: 필름 그레인이 추가된 비디오이며, 다른 노드에 연결할 수 있는 출력으로 제공됩니다.

## 예시

디지털 비디오에 은은한 필름 그레인을 추가하여 영화 같은 느낌을 연출하려는 경우:

1. 워크플로우에 AddFilmGrain 노드를 추가합니다.
1. LoadVideo 노드의 비디오 출력을 AddFilmGrain의 "video" 입력에 연결합니다.
1. 은은한 그레인을 위해 "grain_intensity"를 0.12로 설정합니다.
1. 밝은 영역에서 그레인이 가장 자연스럽게 보이도록 "luminance_threshold"를 75로 설정합니다.
1. 중간 크기 그레인 입자를 위해 "grain_scale"을 2.0으로 설정합니다.
1. 워크플로우를 실행합니다. 비디오에 사실적인 필름 그레인이 적용됩니다.
1. 출력 파일명은 `{original_filename}_grain_0.12.{format}` 형태가 됩니다.

## 중요 참고 사항

- AddFilmGrain 노드는 정교한 노이즈 생성 알고리즘이 적용된 FFmpeg를 사용합니다.
- 각 픽셀의 휘도에 따라 그레인 강도가 자동으로 조절됩니다.
- 사실감을 더하기 위해 프레임마다 형태가 달라지는 시계열(Temporal) 그레인을 생성합니다.
- 처리 시간은 비디오의 길이와 해상도에 따라 달라집니다.
- 원본 오디오 트랙은 그대로 유지됩니다.
- 처리 중 발생한 문제를 디버깅할 수 있도록 로그가 제공됩니다.

## 파라미터 권장 사항

- **은은한 필름 룩**: grain_intensity 0.08-0.15, luminance_threshold 75 사용
- **빈티지/레트로 효과**: grain_intensity 0.3-0.6, grain_scale 2.5-3.0 사용
- **강한 필름 그레인**: grain_intensity 0.7-1.0, grain_scale 3.0-4.0 사용
- **인물 영상 (Portrait)**: 밝은 영역에 최적화되도록 luminance_threshold 70-80 사용
- **풍경 영상 (Landscape)**: 중간 톤에 그레인이 잘 묻어나도록 luminance_threshold 60-70 사용

## 자주 묻는 질문 및 문제 해결

- **처리 시간 초과 (Timeout)**: 용량이 큰 비디오는 처리에 더 오랜 시간이 걸릴 수 있으며, 노드의 기본 제한 시간은 5분입니다.
- **그레인이 너무 강함**: 효과가 너무 과하면 grain_intensity 값을 낮추세요.
- **그레인이 보이지 않음**: grain_intensity 값을 높이거나 luminance_threshold를 조절해 보세요.
- **비디오 입력 없음**: "video" 입력에 유효한 비디오 소스가 연결되었는지 확인하세요.
- **FFmpeg 오류**: 처리 실패 시 자세한 오류 정보를 확인하려면 logs 파라미터를 참조하세요.
