# SplitVideo

## 어떤 노드인가요?

SplitVideo 노드는 타임코드(timecode)를 사용하여 비디오를 여러 세그먼트로 분할할 수 있게 해줍니다. AI 기반 파싱을 사용하여 다양한 타임코드 형식을 인식하며 높은 품질을 유지하면서 각 세그먼트별로 별도의 비디오 파일을 생성합니다.

## 언제 사용하나요?

다음과 같은 상황에서 SplitVideo 노드를 사용합니다:

- 긴 비디오를 관리하기 쉬운 작은 세그먼트로 나누어야 할 때
- 비디오에서 특정 장면이나 섹션을 추출하고 싶을 때
- 소셜 미디어나 다양한 플랫폼을 위한 비디오 클립을 제작할 때
- 녹화 영상의 여러 부분(인트로, 본문 내용, 아웃트로)을 분리해야 할 때
- 긴 푸티지에서 하이라이트 영상을 만들고 싶을 때
- 다양한 대상이나 목적에 맞게 비디오 콘텐츠를 준비할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 SplitVideo 노드를 추가합니다.
1. "video" 입력에 비디오 소스를 연결합니다.
1. "timecodes" 파라미터에 타임코드를 입력합니다.
1. 워크플로우를 실행하여 비디오를 여러 세그먼트로 분할합니다.

### 파라미터 (Parameters)

- **video**: 분할할 비디오 (VideoArtifact 및 VideoUrlArtifact 지원)

- **timecodes**: 비디오를 분할할 타임코드 (필수)

    다양한 형식을 지원합니다:

    **단순 타임코드 범위:**

    ```
    00:00:00:00-00:01:00:00
    00:01:00:00-00:02:30:00
    ```

    **제목이 포함된 타임코드:**

    ```
    00:00:00:00-00:00:04:07|세그먼트 1: 소개
    00:00:04:08-00:00:08:15|세그먼트 2: 본문 내용
    ```

    **JSON 형식:**

    ```json
    [
      {"start": "00:00:00:00", "end": "00:01:00:00", "title": "Intro"},
      {"start": "00:01:00:00", "end": "00:02:30:00", "title": "Main Content"}
    ]
    ```

### 출력 (Outputs)

- **split_videos**: 분할된 비디오 세그먼트 목록 (VideoUrlArtifact 배열)
- **logs**: 처리 로그 및 상세 이벤트

## 예시

10분짜리 비디오를 세 개의 세그먼트로 분할하고자 하는 경우:

1. 워크플로우에 SplitVideo 노드를 추가합니다.
1. LoadVideo 노드의 비디오 출력을 SplitVideo의 "video" 입력에 연결합니다.
1. "timecodes" 파라미터에 타임코드를 입력합니다:
    ```
    00:00:00:00-00:02:30:00|세그먼트 1: 소개
    00:02:30:00-00:07:30:00|세그먼트 2: 본문 내용
    00:07:30:00-00:10:00:00|세그먼트 3: 마무리
    ```
1. 워크플로우를 실행하면 비디오가 세 개의 별도 파일로 분할됩니다.
1. 각 세그먼트는 split_videos 목록의 개별 출력으로 사용할 수 있습니다.

## 중요 참고 사항

- SplitVideo 노드는 다양한 타임코드 형식을 인식하기 위해 AI 기반 파싱을 사용합니다.
- 타임코드는 SMPTE 형식(HH:MM:SS:FF, 여기서 FF는 프레임)이어야 합니다.
- 이 노드는 비디오 프레임 레이트와 드롭 프레임 설정을 자동으로 감지합니다.
- 각 세그먼트는 원본 비디오 품질과 오디오를 그대로 유지합니다.
- 처리 시간은 비디오 길이와 세그먼트 수에 따라 달라집니다.
- 이 노드는 고품질 비디오 처리를 위해 FFmpeg을 사용합니다.
- 로그를 통해 분할 프로세스에 대한 상세 정보를 확인할 수 있습니다.

## 타임코드 형식 가이드라인

- **프레임 레이트**: 24fps, 25fps, 29.97fps, 30fps, 50fps, 59.94fps, 60fps를 자동으로 감지합니다.
- **드롭 프레임**: 29.97fps 및 59.94fps 비디오에 대해 자동으로 감지됩니다.
- **프레임 번호**: 24fps는 00-23, 25fps는 00-24, 30fps는 00-29 등을 사용합니다.
- **구분자**: 시작 및 종료 시간 사이에는 하이픈(-)을, 제목에는 파이프(|)를 사용합니다.
- **제목**: 선택 사항이지만 효과적인 관리를 위해 권장됩니다.

## 자주 묻는 질문 및 문제 해결

- **유효하지 않은 타임코드**: 타임코드가 올바른 SMPTE 형식(HH:MM:SS:FF)인지 확인하세요.
- **중복 세그먼트**: 세그먼트 시간이 서로 겹치지 않는지 확인하세요.
- **처리 시간 초과(Timeout)**: 대용량 비디오는 처리하는 데 시간이 더 걸릴 수 있습니다. 이 노드의 제한 시간은 5분입니다.
- **비디오 입력 없음**: "video" 입력에 비디오 소스가 올바르게 연결되어 있는지 확인하세요.
- **빈 세그먼트**: 각 세그먼트의 시작 시간이 종료 시간보다 앞서 있는지 확인하세요.
- **FFmpeg 오류**: 처리에 실패하면 로그 파라미터에서 상세 오류 정보를 확인하세요.
