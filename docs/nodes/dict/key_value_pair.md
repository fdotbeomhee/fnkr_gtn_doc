# KeyValuePair Node

## 어떤 노드인가요?

`KeyValuePair` 노드는 단일 키-값 쌍을 포함하는 간단한 딕셔너리를 생성합니다. 키와 값을 입력받아 해당 단일 매핑을 가진 딕셔너리를 출력합니다.

## 언제 사용하나요?

다음과 같은 경우에 KeyValuePair 노드를 사용합니다:

- 단일 키-값 연관 관계를 가진 간단한 딕셔너리를 생성해야 할 때
- 구성 파라미터를 동적으로 생성하고자 할 때
- 데이터 구조를 하나씩 단계별로 빌드할 때
- 두 개의 개별 값을 딕셔너리 형식으로 변환해야 할 때
- 딕셔너리 입력을 요구하는 노드를 위해 데이터를 준비할 때

## 사용 방법

### 기본 설정

1. 워크플로에 KeyValuePair 노드를 추가합니다.
1. "key" 파라미터에 원하는 딕셔너리 키를 설정합니다.
1. "value" 파라미터에 해당 키와 연결할 값을 설정합니다.
1. 딕셔너리 입력을 필요로 하는 다른 노드에 "dictionary" 출력을 연결합니다.

### 파라미터 (Parameters)

- **key**: 딕셔너리 키로 사용될 문자열 (string)
- **value**: 키와 연결될 문자열 (string, 여러 줄 텍스트 지원)

### 출력 (Outputs)

- **dictionary**: 단일 키-값 쌍을 포함하는 딕셔너리

## 예시

구성 옵션을 설정해야 하는 워크플로를 만드는 경우:

1. 워크플로에 KeyValuePair 노드를 추가합니다.
1. "key" 파라미터를 "max_tokens"로 설정합니다.
1. "value" 파라미터를 "1024"로 설정합니다.
1. 구성 파라미터를 필요로 하는 노드에 "dictionary" 출력을 연결합니다.

출력은 다음과 같은 딕셔너리가 됩니다: `{"max_tokens": "1024"}`

이 딕셔너리는 워크플로 내에서 해당 구성 파라미터를 필요로 하는 다른 노드에서 사용할 수 있습니다.

## 중요 참고 사항

- 이 노드에서 키와 값은 모두 문자열로 처리됩니다.
- value 파라미터는 긴 내용을 입력할 수 있도록 여러 줄 텍스트(Multiline text)를 지원합니다.
- 여러 개의 키-값 쌍이 있는 딕셔너리를 만들어야 하는 경우 여러 KeyValuePair 노드를 사용하고 병합 노드(MergeKeyValuePair)로 출력을 결합할 수 있습니다.
