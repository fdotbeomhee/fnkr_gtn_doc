# MergeKeyValuePair Node

## 어떤 노드인가요?

`MergeKeyValuePair` 노드는 여러 딕셔너리를 하나의 딕셔너리로 병합합니다. 최대 4개의 입력 딕셔너리를 받아 하나의 통합된 출력 딕셔너리로 결합합니다.

## 언제 사용하나요?

다음과 같은 경우에 MergeKeyValuePair 노드를 사용합니다:

- 여러 딕셔너리를 단일 딕셔너리로 결합해야 할 때
- 통합해야 하는 개별 구성 설정들을 다룰 때
- 서로 다른 소스의 데이터를 하나의 구조로 취합하고자 할 때
- 개별 컴포넌트로부터 복잡한 파라미터 세트를 빌드할 때
- 워크플로의 서로 다른 부분에서 생성된 관련 키-값 쌍을 통합해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로에 MergeKeyValuePair 노드를 추가합니다.
1. 다른 노드의 딕셔너리 출력을 이 노드의 입력에 최대 4개까지 연결합니다.
1. 노드가 모든 입력 딕셔너리를 하나의 출력 딕셔너리로 결합합니다.

### 파라미터 (Parameters)

- **key_value_pair_1**: 병합할 첫 번째 딕셔너리 (딕셔너리 입력)
- **key_value_pair_2**: 병합할 두 번째 딕셔너리 (딕셔너리 입력)
- **key_value_pair_3**: 병합할 세 번째 딕셔너리 (딕셔너리 입력)
- **key_value_pair_4**: 병합할 네 번째 딕셔너리 (딕셔너리 입력)

### 출력 (Outputs)

- **output**: 입력 딕셔너리들의 모든 키-값 쌍을 포함하는 단일 딕셔너리

## 예시

서로 다른 소스의 구성 설정을 결합해야 하는 워크플로를 구축하는 경우:

1. 워크플로에 MergeKeyValuePair 노드를 추가합니다.
1. 데이터베이스 설정이 포함된 딕셔너리를 "key_value_pair_1"에 연결합니다(예: {"host": "localhost", "port": 5432}).
1. 인증 설정이 포함된 딕셔너리를 "key_value_pair_2"에 연결합니다(예: {"username": "admin", "password": "secure123"}).
1. 애플리케이션 설정이 포함된 딕셔너리를 "key_value_pair_3"에 연결합니다(예: {"app_name": "MyApp", "debug": true}).
1. 출력은 이 모든 설정이 포함된 단일 딕셔너리가 됩니다: `{"host": "localhost", "port": 5432, "username": "admin", "password": "secure123", "app_name": "MyApp", "debug": true}`

## 중요 참고 사항

- 여러 입력 딕셔너리에 동일한 키가 나타나는 경우 나중에 연결된 딕셔너리의 값이 이전 값을 덮어씁니다.
- 노드는 딕셔너리가 아니거나 None인 입력을 무시합니다.
- 4개의 입력을 모두 연결할 필요는 없으며, 1개부터 4개까지 원하는 수만큼 연결하여 동작할 수 있습니다.
- 키 충돌이 발생하는 경우 입력의 순서가 중요합니다.
