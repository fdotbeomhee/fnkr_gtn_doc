# DisplayDictionary Node

## 어떤 노드인가요?

`DisplayDictionary` 노드는 워크플로에서 딕셔너리의 내용을 시각적으로 표시해 주는 유틸리티 노드입니다. 딕셔너리 데이터의 시각적 표현을 제공하여 워크플로 실행 중에 딕셔너리 값을 쉽게 검사하고 디버깅할 수 있도록 돕습니다.

## 언제 사용하나요?

다음과 같은 경우에 DisplayDictionary 노드를 사용합니다:

- 워크플로 내에서 딕셔너리의 내용을 검사해야 할 때
- 디버깅 목적으로 복잡한 데이터 구조를 시각화하고자 할 때
- 워크플로 진행에 따라 딕셔너리 값이 어떻게 변하는지 모니터링해야 할 때
- JSON과 유사한 데이터를 다루며 그 구조를 명확히 확인해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로에 DisplayDictionary 노드를 추가합니다.
1. 딕셔너리를 출력하는 노드를 이 노드의 "dictionary" 입력에 연결합니다.
1. 딕셔너리 내용이 노드의 인터페이스에 표시됩니다.

### 파라미터 (Parameters)

- **dictionary**: 표시할 딕셔너리 (입력/출력 파라미터)
- **dictionary_display**: 딕셔너리 내용의 문자열 표현 (UI에 표시되는 속성 파라미터)

### 출력 (Outputs)

- **dictionary**: 입력으로 제공된 것과 동일한 딕셔너리 (그대로 전달됨)

## 예시

사용자 데이터를 처리하는 워크플로를 다루는 경우:

1. 워크플로에 DisplayDictionary 노드를 추가합니다.
1. 사용자 데이터를 생성하는 노드(데이터베이스 쿼리 또는 API 응답 등)의 출력을 "dictionary" 입력에 연결합니다.
1. DisplayDictionary 노드가 사용자 데이터 구조를 읽기 쉬운 형식으로 보여줍니다.
1. 이 데이터가 필요한 다른 노드에 "dictionary" 출력을 연결하여 워크플로를 계속 진행할 수 있습니다.

## 중요 참고 사항

- DisplayDictionary 노드는 딕셔너리 데이터를 수정하지 않고 단순히 표시만 합니다.
- 노드 UI의 여러 줄 텍스트 영역(Multiline text area) 덕분에 복잡한 중첩 딕셔너리도 쉽게 읽을 수 있습니다.
- 이 노드는 워크플로의 데이터 흐름을 디버깅하고 이해하는 데 특히 유용합니다.
