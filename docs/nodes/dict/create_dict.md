# Dictionary

## 어떤 노드인가요?

Dictionary 노드는 별도의 키(Key) 목록과 값(Value) 목록을 제공하여 딕셔너리(키-값 쌍의 모음)를 생성할 수 있게 해줍니다. 워크플로 전반에서 사용할 수 있도록 이름이 지정된 값으로 관련 데이터를 정리하는 간단한 방법입니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 관련 데이터를 이름이 있는 값으로 정리할 때
- 다른 노드로 전달할 구조화된 데이터를 생성할 때
- 다른 컴포넌트를 위한 구성 설정을 빌드할 때
- 키를 통해 쉽게 접근할 수 있는 형식으로 데이터를 준비할 때
- 여러 값을 하나의 정리된 구조로 결합할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Dictionary 노드를 추가합니다.
1. 키와 값 목록을 설정합니다.
1. 구조화된 데이터가 필요한 다른 노드에 dictionary 출력을 연결합니다.

### 파라미터 (Parameters)

- **keys**: 딕셔너리 키로 사용될 문자열 목록
- **values**: 각 키에 해당하는 값 목록 (문자열, 숫자, 불리언 등)

### 출력 (Outputs)

- **dict**: 모든 키-값 쌍이 포함된 생성된 딕셔너리

## 예시

사용자 프로필을 위한 구성 딕셔너리를 생성하려는 경우:

1. 워크플로에 Dictionary 노드를 추가합니다.
1. "keys" 파라미터를 다음과 같이 설정합니다:
    ```
    ["name", "age", "premium_member", "interests"]
    ```
1. "values" 파라미터를 다음과 같이 설정합니다:
    ```
    ["Jane Smith", 32, true, ["hiking", "photography", "coding"]]
    ```
1. 출력 딕셔너리는 다음과 같습니다:
    ```
    {"name": "Jane Smith", "age": 32, "premium_member": true, "interests": ["hiking", "photography", "coding"]}
    ```
1. 이 딕셔너리를 사용자 프로필 정보가 필요한 다른 노드에 연결합니다.

## 중요 참고 사항

- 키는 자동으로 문자열로 변환됩니다.
- 값보다 키를 더 많이 제공하면 초과된 키에는 `None` 값이 할당됩니다.
- 빈 키 또는 `None` 키는 단독 키이면서 값을 가진 경우를 제외하고 건너뜁니다.
- 목록 대신 단일 값을 제공할 수 있으며, 이 경우 단일 항목 목록으로 변환됩니다.
- 이 노드는 문자열, 숫자, 불리언, 중첩 목록 등 다양한 값 타입을 지원합니다.
- 생성된 딕셔너리 형식은 딕셔너리 입력을 허용하는 모든 노드와 호환됩니다.

## 자주 묻는 질문 및 문제 해결

- **목록 길이 불일치**: 키 목록과 값 목록의 길이가 다르면 일부 키의 값이 `None`이 되거나 일부 값이 무시될 수 있습니다.
- **키 변환**: 모든 키가 문자열로 변환되므로 복합 객체를 키로 사용하는 경우 예상치 못한 동작이 발생할 수 있습니다.
- **빈 키**: 키로 사용된 빈 문자열이나 `None` 값은 값에 따라 건너뛸 수 있습니다.
