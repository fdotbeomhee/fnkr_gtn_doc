# Summarize Text

## 어떤 노드인가요?

Summarize Text Task 도구는 텍스트를 요약해 주는 유틸리티입니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 텍스트 콘텐츠 요약을 위한 작업을 생성할 때
- 요약 요구사항 및 파라미터를 정의할 때
- 구조화된 요약 워크플로우를 설정할 때
- 텍스트 요약 프로세스를 관리할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 Summarize Text Task 도구를 추가합니다.
1. 요약 파라미터를 구성합니다.
1. 출력을 요약 작업이 필요한 노드에 연결합니다.

### 파라미터 (Parameters)

- **text**: 요약할 텍스트 콘텐츠

### 출력 (Outputs)

- **output**: 텍스트의 요약본

## 예시

긴 텍스트에 대한 요약 작업을 생성하려는 경우:

1. 워크플로우에 Summarize Text Task 도구를 추가합니다.
1. 텍스트 입력을 원본 텍스트에 연결합니다.
1. "output"을 요약 작업을 처리할 수 있는 노드에 연결합니다.

## 구현 세부 사항

Summarize Text Task 도구는 방대한 양의 텍스트를 요약할 수 있도록 지원합니다.
