# LoadText

## 어떤 노드인가요?

LoadText 노드는 로컬 시스템의 파일에서 텍스트 콘텐츠를 읽어오는 유틸리티 노드입니다. 기존 텍스트 문서를 워크플로우로 가져와 처리할 수 있습니다.

## 언제 사용하나요?

다음과 같은 경우에 LoadText 노드를 사용하세요:

- 기존 텍스트 파일의 콘텐츠를 가져와야 할 때
- AI 에이전트로 로컬 문서를 처리하고 싶을 때
- 로그, 메모, 보고서 등 저장된 텍스트 데이터로 작업할 때
- 외부 콘텐츠를 워크플로우에 전달해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 LoadText 노드를 추가합니다.
1. "path" 파라미터에 텍스트 파일의 위치를 설정합니다.
1. 출력을 텍스트 콘텐츠를 처리할 수 있는 노드에 연결합니다.

### 파라미터 (Parameters)

- **path**: 로드하려는 텍스트 파일의 파일 경로 (문자열)

### 출력 (Outputs)

- **output**: 텍스트 문자열 형태의 파일 콘텐츠
- **path**: 로드된 파일의 경로 (입력값과 동일)

## 예시

로컬 텍스트 파일의 내용을 분석하는 워크플로우:

1. 워크플로우에 LoadText 노드를 추가합니다.
1. "path" 파라미터를 "C:/Users/username/Documents/project_notes.txt"와 같이 설정합니다.
1. "output"을 Agent 노드에 연결합니다.
