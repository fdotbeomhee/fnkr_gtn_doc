# TextInput

## 어떤 노드인가요?

TextInput 노드는 워크플로우에서 사용할 텍스트를 손쉽게 입력할 수 있는 노드입니다.

## 언제 사용하나요?

다음과 같은 경우에 TextInput 노드를 사용하세요:

- 텍스트 콘텐츠를 생성해야 할 때
- 워크플로우 내 다른 노드에 전달할 텍스트 입력을 준비할 때
- 프롬프트, 지침 또는 여러 단락으로 구성된 콘텐츠를 정의해야 할 때
- 구조화된 텍스트 입력이 필요한 워크플로우를 구축할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 TextInput 노드를 추가합니다.
1. "text" 파라미터에 원하는 여러 줄(multiline) 콘텐츠를 입력합니다.
1. 출력을 텍스트 입력을 받는 다른 노드에 연결합니다.

### 파라미터 (Parameters)

- **text**: 여러 줄 텍스트 콘텐츠 (문자열, 기본값은 빈 문자열)

### 출력 (Outputs)

- **text**: 여러 줄 텍스트 콘텐츠 (문자열)

## 예시

AI 어시스턴트를 위한 프롬프트를 작성하는 워크플로우:

1. 워크플로우에 TextInput 노드를 추가합니다.

1. "text" 파라미터를 다음과 같이 설정합니다:

    ```
    You are a helpful tour guide assistant.
    Please provide information about the following location:
    - History of the place
    - Main attractions
    - Best time to visit
    - Local cuisine
    ```

1. 출력을 Agent 노드의 prompt 파라미터에 연결합니다.

## 중요 참고 사항

- 출력에서 줄바꿈이 유지됩니다.
- 유효한 모든 문자열 콘텐츠를 지원합니다.
- 빈 문자열도 유효한 입력이며, 이 경우 빈 문자열이 출력됩니다.
- 글자 수 제한은 없으나 텍스트 블록이 매우 클 경우 성능에 영향을 줄 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- 서로 다른 소스에서 복사할 때 텍스트 서식 문제가 발생할 수 있습니다 (예기치 않은 문자가 있는지 확인하세요).
- 환경에 따라 줄바꿈이 다르게 렌더링될 수 있습니다.
