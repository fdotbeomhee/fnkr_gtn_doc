# MergeTexts

## 어떤 노드인가요?

MergeTexts 노드는 여러 텍스트 문자열을 하나의 통일된 텍스트 출력으로 결합하는 유틸리티 노드입니다. 각 텍스트 조각 사이에 구분자(separator)를 설정하여 하나로 병합할 수 있습니다.

## 언제 사용하나요?

다음과 같은 경우에 MergeTexts 노드를 사용하세요:

- 여러 소스 또는 노드의 텍스트를 결합해야 할 때
- 일관된 서식을 적용하여 개별 텍스트 조각을 이어 붙이고 싶을 때
- 여러 구성 요소로부터 콘텐츠를 생성하는 워크플로우를 구축할 때
- 개별 섹션들을 모아 완성된 문서를 만들어야 할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 MergeTexts 노드를 추가합니다.
1. 다른 노드의 여러 텍스트 출력을 이 노드의 입력에 연결합니다.
1. 필요한 경우 구분자 문자열을 설정합니다.
1. 출력을 결합된 텍스트가 필요한 노드에 연결합니다.

### 파라미터 (Parameters)

- **input_1 through input_4**: 결합할 고정된 수의 텍스트 입력들
- **merge_string**: 텍스트 세그먼트 사이에 넣을 구분자 (trim_whitespace가 False일 때 기본값은 "\n\n")
- **whitespace**: 각 입력 및 최종 결과에서 공백을 잘라낼지(trim) 여부를 설정하는 부울(Boolean) 옵션

### 출력 (Outputs)

- **output**: 단일 문자열로 결합된 텍스트 결과

## 예시

개별 섹션들로부터 완성된 문서를 생성하는 워크플로우:

1. 워크플로우에 MergeTexts 노드를 추가합니다.
1. 세 개의 서로 다른 텍스트 노드(예: 제목, 본문, 결론)의 출력을 연결합니다.
1. 단락 구분을 위해 merge_string 파라미터를 "\n\n"으로 설정합니다.
1. 출력에는 지정된 구분자로 결합된 모든 텍스트 세그먼트가 포함됩니다.

## 중요 참고 사항

- `whitespace`가 활성화되면(트림 모드), 결합하기 전에 각 입력의 앞뒤 공백이 제거됩니다.
- `whitespace`가 활성화되어 있고 구분자가 비어 있는 경우, 입력들이 구분자 없이 그대로 이어 붙여집니다.
- `whitespace`가 비활성화되어 있으면 빈 입력은 필터링되어 제외되며, 구분자가 지정되지 않은 경우 기본값은 "\n\n"이 됩니다.
- 구분자는 입력들 사이에만 추가되며, 맨 앞이나 맨 뒤에는 추가되지 않습니다.
- **권장 사항**: 보다 유연한 입력 처리가 필요한 경우 **JoinText** 노드 사용을 고려해 보세요.

## 자주 묻는 질문 및 문제 해결

- **예기치 않은 서식 발생**: merge_string에 적절한 공백이나 줄바꿈이 포함되어 있는지 확인하세요.
- **콘텐츠 누락**: 모든 입력 연결이 올바르게 설정되었는지 확인하세요.
