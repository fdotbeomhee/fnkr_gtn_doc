# SaveText

## 어떤 노드인가요?

SaveText는 텍스트 콘텐츠를 로컬 시스템의 파일에 저장할 수 있는 유틸리티 노드입니다. 이 노드는 사용자 정의 출력 경로를 통해 텍스트 데이터를 디스크에 작성할 수 있는 간단한 인터페이스를 제공합니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 생성된 텍스트 콘텐츠를 파일로 저장할 때
- 워크플로우의 결과를 텍스트 파일로 내보낼 때
- 나중에 참조할 수 있도록 대화 로그나 출력을 저장할 때
- 자동화된 워크플로우의 일부로 텍스트 파일을 생성할 때
- 워크플로우 실행 간 데이터를 유지(영속화)할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 SaveText 노드를 추가합니다.
1. 텍스트 소스를 "text" 입력에 연결하거나 텍스트를 직접 입력합니다.
1. 출력 경로를 지정하거나 기본값을 사용합니다.
1. 워크플로우를 실행하여 지정된 파일에 텍스트를 저장합니다.

### 파라미터 (Parameters)

- **text**: 파일로 저장할 텍스트 콘텐츠 (여러 줄 텍스트 지원)
- **output_path**: 텍스트가 저장될 파일 경로 (기본값: "griptape_output.txt")

### 출력 (Outputs)

- **output_path**: 저장된 파일의 경로 (저장 작업 성공 확인용)

## 예시

AI 에이전트의 출력을 텍스트 파일로 저장하려는 경우:

1. 워크플로우에 Agent 노드를 추가합니다.
1. 텍스트를 생성하도록 프롬프트를 사용하여 에이전트를 설정합니다.
1. SaveText 노드를 추가합니다.
1. Agent의 "output"을 SaveText의 "text" 입력에 연결합니다.
1. "output_path"를 "my_agent_response.txt"로 설정합니다.
1. 워크플로우를 실행합니다.
1. 에이전트의 응답이 로컬 시스템의 "my_agent_response.txt"에 저장됩니다.

## 중요 참고 사항

- 파일이 존재하지 않으면 새로 생성하고, 이미 존재하는 경우 덮어씁니다.
- UI의 output_path 파라미터에는 파일을 쉽게 선택할 수 있는 저장 버튼이 포함되어 있습니다.
- 출력 파일에는 상대 경로 또는 절대 경로를 모두 사용할 수 있습니다.
- 상위 디렉터리가 존재하지 않는 경우 필요한 상위 디렉터리를 자동으로 생성합니다.
- 텍스트는 UTF-8 인코딩으로 저장됩니다.

## 자주 묻는 질문 및 문제 해결

- **권한 오류 (Permission Errors)**: 지정한 디렉터리에 대한 쓰기 권한이 있는지 확인하세요.
- **잘못된 경로 (Invalid Path)**: 운영체제에 맞는 올바른 경로인지 확인하세요.
- **파일 이미 존재 (File Already Exists)**: 기존 파일이 확인 절차 없이 덮어써지므로 주의하세요.
