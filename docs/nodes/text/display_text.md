# DisplayText

## 어떤 노드인가요?

DisplayText 노드는 워크플로우에서 텍스트 콘텐츠를 화면에 표시해 주는 노드입니다.

## 언제 사용하나요?

다음과 같은 경우에 DisplayText 노드를 사용하세요:

- 워크플로우에서 결과나 정보를 화면에 표시해야 할 때
- 이전 처리 단계에서 생성된 텍스트 출력을 확인하고 싶을 때
- 워크플로우 실행 중에 업데이트될 텍스트 콘텐츠의 플레이스홀더가 필요할 때
- 워크플로우 내에서 알아보기 쉬운 레이블이나 설명을 만들고 싶을 때
- 프로세스의 특정 지점에서 문자열 데이터를 시각화해야 할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayText 노드를 추가합니다.
1. 필요한 경우 초기 텍스트 값을 설정합니다.
1. 입력을 text 파라미터에 연결하거나 텍스트를 직접 입력합니다.
1. text 출력을 텍스트 입력이 필요한 다른 노드에 연결합니다.

### 파라미터 (Parameters)

- **text**: 표시할 텍스트 콘텐츠 (문자열 입력, 여러 줄 텍스트 지원)

### 출력 (Outputs)

- **text**: 다른 노드에 연결할 수 있도록 제공되는 동일한 텍스트 콘텐츠

## 예시

정보를 처리하고 표시하는 워크플로우를 구축하는 경우:

1. 워크플로우에 DisplayText 노드를 추가합니다.
1. RunAgent 노드의 출력을 DisplayText 노드의 text 파라미터에 연결합니다.
1. 워크플로우가 실행되면 AI가 생성한 콘텐츠가 초기 텍스트를 대체하여 표시됩니다.

## 중요 참고 사항

- DisplayText 노드는 시각화용 노드이며 텍스트 콘텐츠를 수정하지 않습니다.
- 별도의 처리나 서식 변경 없이 전달받은 텍스트를 그대로 통과시킵니다.
