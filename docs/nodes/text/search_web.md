# Search Web

## 어떤 노드인가요?

Search Web 도구는 웹을 검색하고 검색 결과에서 텍스트 콘텐츠를 가져올 수 있는 유틸리티입니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 특정 정보를 찾기 위해 웹을 검색할 때
- 검색 결과에서 텍스트 콘텐츠를 가져올 때
- 여러 웹 소스에서 정보를 수집할 때
- 온라인으로 주제를 조사/연구할 때

## 사용 방법

### 기본 설정

1. 워크플로우에 Search Web 도구를 추가합니다.
1. 출력을 웹 검색 결과가 필요한 노드에 연결합니다.

### 파라미터 (Parameters)

- **prompt**: 사용할 검색 쿼리
- **summarize**: LLM이 텍스트를 요약하도록 할지 여부
- **search_engine**: 사용할 검색 엔진. 참고: 일부 검색 엔진은 API 키가 필요합니다.

### 출력 (Outputs)

- **output**: 검색 결과에서 가져온 텍스트 콘텐츠

## 예시

특정 주제에 대한 정보를 검색하려는 경우:

1. 워크플로우에 Search Web 도구를 추가합니다.
1. 검색 쿼리를 설정합니다.
1. "output"을 검색 결과가 필요한 다른 노드에 연결합니다.
1. 도구가 검색 결과로부터 텍스트 콘텐츠를 반환합니다.

## 구현 세부 사항

Search Web 도구는 웹 검색 기능을 사용하여 관련 정보를 찾고 검색 결과에서 텍스트 콘텐츠를 추출합니다. 웹에서 구조화된 방식으로 정보를 수집할 수 있도록 설계되었습니다.
