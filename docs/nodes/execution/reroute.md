# Reroute

## 어떤 노드인가요?

Reroute 노드는 워크플로의 서로 다른 부분 간에 데이터를 재라우팅하기 위한 연결점 역할을 하는 유틸리티 노드입니다. 설정된 연결에 따라 파라미터의 허용 타입을 동적으로 조정하여 복잡한 워크플로를 더 쉽게 정리할 수 있도록 도와줍니다.

간단히 말해, 노드 간의 연결 선을 깔끔하게 정리하는 방법입니다.

## 언제 사용하나요?

다음과 같은 경우에 Reroute 노드를 사용합니다:

- 연결선이 서로 교차하는 복잡한 워크플로를 정리해야 할 때
- 워크플로의 시각적 명확성을 개선하고자 할 때
- 워크플로에서 멀리 떨어진 영역 간에 연결을 이어줄 때
- 여러 연결선을 하나로 묶어 정리할 때
- 더 깔끔하고 유지 관리가 쉬운 워크플로 레이아웃을 만들고자 할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Reroute 노드를 추가합니다.
1. 소스 노드의 출력을 Reroute 노드의 입력에 연결합니다.
1. Reroute 노드의 출력을 대상 노드의 입력에 연결합니다.
1. 노드가 올바른 데이터 타입을 전달하도록 자동으로 조정됩니다.

### 파라미터 (Parameters)

- **passThru**: 입력과 출력 역할을 모두 수행할 수 있는 파라미터로, 연결에 따라 허용되는 타입을 동적으로 조정합니다.

### 출력 (Outputs)

- **passThru**: 수정 없이 노드를 그대로 통과한 데이터

## 예시

조직화를 개선하기 위해 워크플로에서 멀리 떨어진 두 노드 사이에 Reroute 노드를 추가합니다. 예를 들어, 워크플로 상단에 있는 노드의 이미지 출력을 Reroute 노드에 연결한 다음, 해당 Reroute 노드의 출력을 워크플로 하단에 있는 이미지 처리 노드에 연결합니다.

## 중요 참고 사항

- Reroute 노드는 통과하는 데이터를 전혀 수정하지 않습니다.
- 연결된 데이터에 따라 파라미터 타입을 자동으로 조정합니다.
- 워크플로의 구성과 가독성을 향상시키는 데 도움이 됩니다.
- 복잡한 라우팅 요구 사항에 맞춰 여러 개의 Reroute 노드를 연속으로 연결할 수 있습니다.
