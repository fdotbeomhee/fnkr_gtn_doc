# StartFlow

## 어떤 노드인가요?

StartFlow는 워크플로의 시작을 나타내는 특별한 기본 구성 요소입니다. 시스템에 흐름 실행을 시작할 위치를 알려주는 "출발(Go)" 신호로 생각하면 됩니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 워크플로의 명확한 시작점을 만들 때
- 연결된 노드들의 시퀀스를 시작할 때
- 흐름의 진입점(Entry point)을 정의할 때

## 사용 방법

### 기본 설정

1. 워크플로에 StartFlow를 추가합니다.
1. 흐름의 첫 번째 동작 노드에 연결합니다.

### 파라미터 (Parameters)

### 출력 (Outputs)

- **exec_out** - 흐름의 다음 노드로 제어를 전달하기 위해 이 핀을 사용합니다.

## 예시

텍스트를 생성하고 저장하는 워크플로를 생성하는 경우:

1. StartFlow 노드를 생성합니다.
1. 상단의 흰색 "실행 체인(exec chain)" 핀을 텍스트를 생성할 Agent에 연결합니다.
1. 이를 생성된 텍스트를 저장하는 SaveText에 연결합니다.
1. 이를 EndFlowNode에 연결하여 흐름을 완료합니다.

StartFlow는 시스템에 "여기서 시작하여 실행 체인을 순서대로 따르라"고 지시합니다.

## 중요 참고 사항

- 모든 워크플로에는 정확히 하나의 StartFlow가 필요합니다.
- StartFlow는 입력을 받지 않으며 단순한 시작점입니다.
- 연속된 워크플로 하나당 오직 하나의 StartFlow만 둘 수 있습니다.

## 자주 묻는 질문 및 문제 해결

- **흐름이 실행되지 않음**: StartFlow가 다음 노드에 올바르게 연결되어 있는지 확인하세요.
- **여러 개의 시작점 존재**: 워크플로에 StartFlow가 하나만 있는지 확인하세요.
