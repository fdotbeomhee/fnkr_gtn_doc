# Note

## 어떤 노드인가요?

Note 노드를 사용하면 워크플로 전체에 걸쳐 설명 메모를 작성할 수 있습니다. 실행 동작을 수행하지는 않으며, 주로 흐름 내에서 표시 및 문서화 용도로 사용됩니다.

## 언제 사용하나요?

다음과 같은 경우에 Note 노드를 사용합니다:

- 워크플로의 특정 섹션이 어떤 역할을 하는지 설명해야 할 때
- 특정 노드의 사용 방법에 대한 힌트를 남겨두고 싶을 때
- 다른 사람에게 워크플로 사용 지침을 전달하고자 할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Note 노드를 추가합니다.
1. "note" 파라미터에 원하는 여러 줄 내용을 설정합니다.

### 파라미터 (Parameters)

- **note**: 텍스트 내용 (string, 기본값은 빈 문자열)

## 예시

Agent에서 `prompt_context`를 사용하는 방법에 대한 메모를 작성하는 워크플로:

1. 워크플로에 Note 노드를 추가합니다.

1. Note 노드를 Agent 노드 근처로 이동합니다.

1. 다음 텍스트를 입력합니다:

    ```
    prompt_context를 사용하려면 새 KeyValuePair 노드를 생성하세요.
    키를 "style", 값을 "haiku"와 같이 지정합니다.
    그런 다음 dictionary 출력을 Agent의 prompt_context에 연결하세요.
    Agent 프롬프트에서 {{ }} 문자를 사용하여 "style"을 "haiku"로
    대체할 위치를 지정합니다. 예시:

    Tell me about skateboards in the style of a {{style}}
    ```

1. 워크플로를 쉽게 이해할 수 있도록 읽기 편한 위치에 Note를 배치합니다.

## 중요 참고 사항

- 줄 바꿈(Line break)이 유지됩니다.
- 노드는 모든 유효한 문자열 내용을 지원합니다.
- 빈 문자열도 유효합니다.
- 글자 수 제한이 없습니다.

## 자주 묻는 질문 및 문제 해결

- 아직 폰트 크기를 조절하는 기능은 제공되지 않습니다.
- 아직 노드의 색상을 변경하는 기능은 제공되지 않습니다.
