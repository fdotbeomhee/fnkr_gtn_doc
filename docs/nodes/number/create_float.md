# FloatInput

## 어떤 노드인가요?

FloatInput 노드는 부동 소수점(실수) 숫자 값을 간편하게 입력할 수 있는 노드입니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 소수점 정밀도를 가진 숫자 값 정의
- 워크플로우에 구성 가능한 숫자 파라미터 생성
- 수학적 연산을 위한 값 설정
- 임계값, 비율 또는 기타 소수점 값 지정

## 사용 방법

### 기본 설정

1. 워크플로우에 FloatInput 노드를 추가합니다.
1. 원하는 부동 소수점(float) 값을 설정합니다.

### 파라미터 (Parameters)

- **float**: 부동 소수점 숫자 값 (기본값은 0.0)

### 출력 (Outputs)

- **float**: 다른 노드에서 사용할 수 있는 부동 소수점 값

## 예시

AI 모델의 temperature(온도) 값을 설정하려는 경우:

1. 워크플로우에 FloatInput 노드를 추가합니다.
1. "float" 값을 0.7로 설정합니다.
1. 출력을 모델의 temperature 파라미터에 연결합니다.
1. 이제 AI 모델이 temperature 설정으로 0.7을 사용합니다.

## 중요 참고 사항

- 이 노드는 단일 부동 소수점 값을 생성합니다.
- 지정하지 않은 경우 기본값은 0.0입니다.
- 노드의 속성(Properties) 패널을 통해 값을 업데이트할 수 있습니다.
- 부동 소수점 숫자는 0.5, 3.14159, -2.75와 같은 소수점 값을 나타낼 수 있습니다.
