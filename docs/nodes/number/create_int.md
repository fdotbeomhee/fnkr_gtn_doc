# IntegerInput

## 어떤 노드인가요?

IntegerInput 노드는 정수(정수형) 숫자 값을 간편하게 입력할 수 있는 노드입니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 소수점이 없는 정수 값 정의
- 워크플로우에 구성 가능한 정수 파라미터 생성
- 카운터, 인덱스 또는 수량 값 설정
- 제한값, 임계값 또는 기타 정수 값 지정

## 사용 방법

### 기본 설정

1. 워크플로우에 IntegerInput 노드를 추가합니다.
1. 원하는 정수(integer) 값을 설정합니다.

### 파라미터 (Parameters)

- **integer**: 정수 값 (기본값은 0)

### 출력 (Outputs)

- **integer**: 다른 노드에서 사용할 수 있는 정수 값

## 예시

AI 응답의 최대 토큰 제한(max_tokens)을 설정하려는 경우:

1. 워크플로우에 IntegerInput 노드를 추가합니다.
1. "integer" 값을 500으로 설정합니다.
1. 출력을 모델의 max_tokens 파라미터에 연결합니다.
1. 이제 AI 모델이 응답을 500개 토큰으로 제한합니다.

## 중요 참고 사항

- 이 노드는 단일 정수 값을 생성합니다.
- 지정하지 않은 경우 기본값은 0입니다.
- 노드의 속성(Properties) 패널을 통해 값을 업데이트할 수 있습니다.
- 정수는 1, 42, -7, 0과 같은 정수 값을 나타냅니다.
