# Askulator

## 어떤 노드인가요?

Askulator는 일반 자연어로 표현된 수학 문제를 이해하고 해결할 수 있는 자연어 계산기 노드입니다. AI 모델을 사용하여 질문을 해석하고 필요한 계산을 수행한 다음 추론 과정과 최종 답변을 모두 제공합니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드를 사용하세요:

- 자연어로 표현된 수학 문제 풀기
- 계산에 대한 단계별 추론 과정 확인
- 복잡하거나 모호한 수학 질문 처리
- 해석이나 추정이 필요한 계산 수행
- 정확한 숫자가 없을 때 창의적이거나 근사치 계산 답변 얻기

## 사용 방법

### 기본 설정

1. 워크플로우에 Askulator 노드를 추가합니다.
1. "instruction" 파라미터에 수학 질문을 입력합니다.
1. 노드가 질문을 처리하여 다음을 제공합니다:
    - 문제를 해결한 방법에 대한 상세한 추론 과정
    - "result" 출력에 최종 답변 제공

### 파라미터 (Parameters)

- **instruction**: 해결할 수학 질문 또는 문제 (자연어 지원)
- **model**: 처리에 사용할 AI 모델 (기본값: gpt-4.1-mini)
- **result**: 계산된 최종 답변
- **output**: 문제를 해결하기 위해 거친 상세한 추론 과정 및 단계

### 출력 (Outputs)

- **result**: 계산된 최종 답변
- **output**: 문제를 해결하기 위해 거친 상세한 추론 과정 및 단계

## 예시

"계란 3다스가 있는데 그중 3분의 1을 나누어 주었다면 몇 개가 남을까요?"와 같은 복잡한 계산을 수행하려는 경우:

1. 워크플로우에 Askulator 노드를 추가합니다.
1. "instruction" 파라미터에 질문을 입력합니다.
1. 노드가 다음과 같이 처리합니다:
    - 3다스 = 36개의 계란으로 해석
    - 36의 3분의 1이 12임을 계산
    - 36에서 12를 뺌
    - "output"에 추론 과정 제공
    - "result"에 최종 답변(24) 제공

## 구현 세부사항 (Implementation Details)

Askulator는 다음을 사용합니다:

- 질문을 이해하기 위한 자연어 처리 모델
- 정밀한 계산을 수행하기 위한 Calculator 도구
- 추론 과정과 최종 답변을 분리하기 위한 JSON 출력 형식
- 실시간 진행 상황을 보여주기 위한 스트리밍 업데이트

이 노드는 창의적이고 유용하게 동작하도록 설계되어, 정확한 숫자가 주어지지 않았을 때도 합리적인 추정을 내리고 명확한 이유를 설명합니다.
