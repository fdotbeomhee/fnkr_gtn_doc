# BoolInput

BoolInput 노드를 사용하면 불리언(Boolean) 값을 생성할 수 있습니다.

## 입력 (Inputs)

- **Value** (bool): 생성할 불리언 값
    - 기본값: False

## 출력 (Outputs)

- **Output** (bool): 생성된 불리언 값

## 예시

```python
# Value: True
# Output: True

# Value: False
# Output: False
```

## 참고 사항 (Notes)

- 이 노드는 value 파라미터에 대해 입력 모드와 속성(Property) 모드를 모두 지원합니다.
- 지정하지 않은 경우 기본값은 False입니다.
- 값이 변경되면 즉시 출력으로 전달됩니다.
