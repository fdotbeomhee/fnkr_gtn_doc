# DisplayFloat

## 어떤 노드인가요?

DisplayFloat 노드는 부동 소수점(float) 파라미터를 화면에 표시해 주는 노드입니다.

## 언제 사용하나요?

그래프 내에서 부동 소수점 숫자 값을 확인하고 검사하고 싶을 때 사용합니다.

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayFloat 노드를 추가합니다.
1. 다른 노드의 float 출력을 이 노드의 입력에 연결합니다.

### 파라미터 (Parameters)

- **float**: 이 노드에 표시되는 단일 부동 소수점 숫자 (기본값은 0.0)

### 출력 (Outputs)

- **없음 (None)**

## 예시

워크플로우에서 사용되는 temperature 설정을 시각적으로 확인하려는 경우:

1. 워크플로우에 DisplayFloat 노드를 추가합니다.
1. 다른 노드의 "temperature" 출력을 DisplayFloat의 입력에 연결합니다.
1. 이제 DisplayFloat 노드가 그래프에서 현재 temperature 값을 보여줍니다.

## 중요 참고 사항

- 이 노드는 시각화 목적으로만 사용됩니다.
- 값을 수정하지 않고 단순히 표시하기만 합니다.
- 워크플로우 디버깅 및 모니터링에 유용합니다.
