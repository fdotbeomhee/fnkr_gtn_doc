# DisplayInteger

## 어떤 노드인가요?

DisplayInteger 노드는 정수(integer) 파라미터를 화면에 표시해 주는 노드입니다.

## 언제 사용하나요?

다음과 같은 작업을 원할 때 이 노드/클래스를 사용하세요:

- 그래프 내에서 정수 값을 확인하고 검사하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayInteger 노드를 추가합니다.
1. 다른 노드의 integer 출력을 이 노드의 입력에 연결합니다.

### 파라미터 (Parameters)

- **integer**: 이 노드에 표시되는 단일 정수 값 (기본값은 0)

### 출력 (Outputs)

- **없음 (None)**

## 예시

워크플로우에서 사용되는 토큰 수(token count)를 시각적으로 확인하려는 경우:

1. 워크플로우에 DisplayInteger 노드를 추가합니다.
1. 다른 노드의 "token_count" 출력을 DisplayInteger의 입력에 연결합니다.
1. 이제 DisplayInteger 노드가 그래프에서 현재 토큰 수를 보여줍니다.

## 중요 참고 사항

- 이 노드는 시각화 목적으로만 사용됩니다.
- 값을 수정하지 않고 단순히 표시하기만 합니다.
- 워크플로우 디버깅 및 모니터링에 유용합니다.
