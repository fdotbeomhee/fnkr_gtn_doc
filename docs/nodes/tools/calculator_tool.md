# Calculator

## 어떤 노드인가요?

Calculator 도구는 에이전트에게 제공하여 정확한 수학적 계산을 수행할 수 있도록 돕는 연산 도구입니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 에이전트가 정밀한 수학 연산을 수행할 수 있도록 기능을 부여할 때
- 워크플로 내에서 복잡한 수학 문제를 해결할 때
- 별도의 커스텀 계산 코드 작성 없이 수치 데이터를 처리할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Calculator를 추가합니다.
1. 출력을 계산 기능이 필요한 노드(예: Agent)에 연결합니다.

### 출력 (Outputs)

- **tool**: 다른 노드에서 사용할 수 있도록 구성된 계산기 도구

## 예시

계산을 수행할 수 있는 에이전트를 생성하려는 경우:

1. 워크플로에 Calculator를 추가합니다.
1. "tool" 출력을 Agent의 "tools" 입력에 연결합니다.
1. 이제 해당 에이전트는 대화 중 필요할 때 계산을 수행할 수 있습니다.

## 구현 세부사항

Calculator 도구는 Griptape의 `CalculatorTool` 클래스를 사용하여 구현되었으며, 수학 연산을 수행하기 위한 간단한 인터페이스를 제공합니다. 이 도구는 에이전트가 수치 작업을 정확하고 효율적으로 처리할 수 있도록 설계되었습니다.
