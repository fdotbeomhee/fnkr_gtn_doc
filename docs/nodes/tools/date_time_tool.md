# Date Time

## 어떤 노드인가요?

Date Time 도구는 에이전트에게 날짜 및 시간 관련 연산을 수행할 수 있도록 기능을 부여하는 유틸리티 도구입니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 에이전트가 날짜와 시간을 다룰 수 있도록 지원할 때
- 날짜/시간 계산 및 조작을 수행할 때
- 현재 시간 정보를 가져올 때
- 날짜와 시간을 다양한 형식으로 포맷팅할 때

## 사용 방법

### 기본 설정

1. 워크플로에 Date Time 도구를 추가합니다.
1. 출력을 날짜/시간 기능이 필요한 노드(예: Agent)에 연결합니다.

### 출력 (Outputs)

- **tool**: 다른 노드에서 사용할 수 있도록 구성된 날짜/시간 도구

## 예시

날짜와 시간을 다룰 수 있는 에이전트를 생성하려는 경우:

1. 워크플로에 Date Time 도구를 추가합니다.
1. "tool" 출력을 Agent의 "tools" 입력에 연결합니다.
1. 이제 해당 에이전트는 대화 중 필요할 때 날짜 및 시간 관련 작업을 수행할 수 있습니다.

## 구현 세부사항

Date Time 도구는 Griptape의 `DateTimeTool` 클래스를 사용하여 구현되었으며, 날짜 및 시간 작업을 처리하기 위한 포괄적인 인터페이스를 제공합니다. 이 도구는 에이전트가 시간 데이터를 관리하고 시간 기반 계산을 수행할 수 있도록 설계되었습니다.
