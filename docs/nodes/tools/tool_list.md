# ToolList

## 어떤 노드인가요?

ToolList 노드는 여러 도구를 단일 목록(List)으로 결합합니다. 이를 통해 "tools" 입력 파라미터에 직접 연결할 수 있습니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 여러 도구를 하나의 목록으로 묶을 때
- 서로 다른 도구들의 장점을 활용하는 복합 워크플로를 구성할 때
- Griptape 워크플로에서 다양한 소스의 도구들을 통합할 때

## 사용 방법

### 기본 설정

1. 워크플로에 ToolList를 추가합니다.
1. 필요한 입력 파라미터(예: tools)를 제공하는 다른 노드에 연결합니다.
1. 흐름을 실행하여 결합된 도구 목록을 확인합니다.

### 파라미터 (Parameters)

- **tools**: 단일 목록으로 결합할 도구들의 목록.

### 출력 (Outputs)

- **tool_list**: 결합된 도구 목록.

## 예시

텍스트를 생성하고 저장하는 워크플로를 구성하는 예시:

1. 여러 노드로 흐름을 구성합니다 (예: 텍스트를 생성하는 에이전트 및 저장하는 노드).
1. ToolList를 추가하고, tools 파라미터를 제공하는 노드들을 연결합니다.
1. 흐름을 실행하여 결합된 도구 목록이 작동하는 것을 확인합니다.

## 중요 참고 사항

- ToolList는 흐름 실행 시 입력 도구들이 제공되어야 합니다.
- 도구 입력에 중첩된 목록(Nested list)을 사용할 경우 평탄화(Flattened)된 단일 목록으로 출력됩니다.

## 자주 묻는 질문 및 문제 해결

- **유효하지 않은 입력 도구 (Invalid Input Tools)**: 이 노드를 워크플로의 다른 노드에 연결할 때 유효한 도구 목록을 제공하고 있는지 확인하세요.
- **중첩된 목록 (Nested Lists)**: 입력된 중첩 목록은 단일 목록으로 평탄화되어 처리됩니다.
