# File Manager

## 어떤 노드인가요?

File Manager 도구는 에이전트가 작업 공간(Workspace) 디렉터리 내에서 파일 작업을 수행할 수 있도록 지원하는 유틸리티 도구입니다.

## 언제 사용하나요?

다음과 같은 경우에 이 노드를 사용합니다:

- 에이전트가 파일을 읽고 쓸 수 있도록 지원할 때
- 작업 공간 디렉터리 내의 파일을 관리할 때
- 파일 복사, 이동, 삭제와 같은 파일 작업을 수행할 때

## 사용 방법

### 기본 설정

1. 워크플로에 File Manager 도구를 추가합니다.
1. 출력을 파일 작업 기능이 필요한 노드(예: Agent)에 연결합니다.

### 출력 (Outputs)

- **tool**: 다른 노드에서 사용할 수 있도록 구성된 파일 관리자 도구

## 예시

파일을 관리할 수 있는 에이전트를 생성하려는 경우:

1. 워크플로에 File Manager 도구를 추가합니다.
1. "tool" 출력을 Agent의 "tools" 입력에 연결합니다.
1. 이제 해당 에이전트는 대화 중 필요할 때 파일 작업을 수행할 수 있습니다.

## 구현 세부사항

File Manager 도구는 `LocalFileManagerDriver`를 사용하는 Griptape의 `FileManagerTool` 클래스로 구현되었습니다. 이 도구는 작업 공간 디렉터리 내의 파일을 관리하기 위한 간편한 인터페이스를 제공합니다.

참고: 클라우드 스토리지 기능은 현재 비활성화되어 있으며 향후 업데이트에서 제공될 예정입니다.
