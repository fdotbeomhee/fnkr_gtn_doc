# GetListLength

## 어떤 노드인가요?

GetListLength 노드는 리스트의 항목 수를 계산하여 출력하는 유틸리티 노드입니다. 워크플로우 내 모든 리스트의 크기를 간편하게 확인할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 GetListLength 노드를 사용하세요:

- 리스트에 몇 개의 항목이 있는지 알아야 할 때
- 리스트가 비어 있는지 또는 특정 개수의 항목을 가지고 있는지 확인하고 싶을 때
- 리스트 크기에 의존하는 워크플로우를 구축할 때
- 처리 전에 리스트 길이를 검증해야 할 때
- 동적 리스트의 크기를 모니터링하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 GetListLength 노드를 추가합니다.
1. 아무 리스트나 "items" 입력에 연결합니다.
1. 노드가 리스트의 길이를 자동으로 계산하여 출력합니다.

### 파라미터 (Parameters)

- **items**: 측정할 대상 리스트 (리스트 입력)
- **length**: 리스트의 항목 수 (정수형 출력)

### 출력 (Outputs)

- **length**: 입력 리스트의 항목 수를 나타내는 정수

## 예시

작업 리스트에 몇 개의 작업이 있는지 확인하려는 경우:

1. 워크플로우에 GetListLength 노드를 추가합니다.
1. 작업 리스트를 "items" 입력에 연결합니다.
1. "length" 출력에 리스트의 총 작업 수가 표시됩니다.

## 중요 참고 사항

- 입력 리스트가 변경되면 노드가 자동으로 길이를 업데이트합니다.
- 입력 리스트가 비어 있거나 제공되지 않으면 길이는 0이 됩니다.
- 길이는 항상 0 이상의 정수(음수가 아닌 정수)입니다.
- 모든 타입의 항목을 가진 리스트에서 동작합니다.

## 자주 묻는 질문 및 문제 해결

- **빈 리스트 (Empty List)**: 리스트가 연결되지 않으면 길이가 0이 됩니다.
- **잘못된 입력 (Invalid Input)**: 입력이 리스트가 아니면 길이가 0이 됩니다.
- **타입 불일치 (Type Mismatch)**: 이 노드는 리스트 입력에서만 작동하며, 다른 타입의 경우 길이가 0이 됩니다.
