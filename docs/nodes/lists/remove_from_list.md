# RemoveFromList

## 어떤 노드인가요?

RemoveFromList 노드는 다양한 기준에 따라 기존 리스트에서 항목을 제거하는 유틸리티 노드입니다. 위치(첫 번째, 마지막, 특정 인덱스)를 기준으로 하거나 특정 항목 값과 일치하는 항목을 제거할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 RemoveFromList 노드를 사용하세요:

- 기존 리스트에서 항목을 제거해야 할 때
- 컬렉션에서 특정 항목을 필터링하여 제외하고 싶을 때
- 워크플로우 실행 중 항목 제거가 필요한 동적 리스트를 관리할 때
- 불필요한 요소를 제거하여 리스트를 정리하거나 수정해야 할 때
- 리스트의 특정 위치에서 항목을 추출/제거하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 RemoveFromList 노드를 추가합니다.
1. 기존 리스트를 "items" 입력에 연결합니다.
1. "remove_item_by" 파라미터를 사용하여 항목을 제거할 방식을 선택합니다.
1. 제거 방식에 따라 인덱스 또는 항목 값을 제공합니다.
1. 출력은 지정된 항목이 제거된 리스트가 됩니다.

### 파라미터 (Parameters)

- **items**: 항목을 제거할 대상 리스트 (리스트 입력)
- **remove_item_by**: 항목 제거 방식 (선택 옵션: "first", "last", "index", "item")
- **item**: 제거할 특정 항목 (remove_item_by가 "item"일 때만 표시됨)
- **index**: 제거할 위치 (remove_item_by가 "index"일 때만 표시됨)
- **output**: 항목이 제거되어 수정된 리스트

### 출력 (Outputs)

- **output**: 원래 항목들에서 지정된 항목이 제외된 리스트

## 예시

작업 리스트에서 특정 작업을 제거하려는 경우:

1. 워크플로우에 RemoveFromList 노드를 추가합니다.
1. 작업 리스트를 "items" 입력에 연결합니다.
1. "remove_item_by"를 "item"으로 설정합니다.
1. 제거하려는 작업을 "item" 입력에 연결합니다.
1. 출력은 지정된 작업이 제거된 리스트가 됩니다.

## 중요 참고 사항

- 이 노드는 원본을 직접 수정하지 않고 새 리스트를 생성합니다.
- "index" 방식으로 제거할 때 인덱스는 리스트 범위 내에 있어야 합니다.
- "item" 방식으로 제거할 때 해당 항목이 리스트에 존재해야 합니다.
- "index" 및 "item" 파라미터는 해당 제거 방식이 선택되었을 때만 표시됩니다.

## 자주 묻는 질문 및 문제 해결

- **잘못된 인덱스 (Invalid Index)**: "index" 제거 방식을 사용하는 경우 인덱스가 리스트 범위 내에 있는지 확인하세요.
- **항목을 찾을 수 없음 (Item Not Found)**: "item" 제거 방식을 사용할 때 항목이 리스트에 존재해야 합니다.
- **빈 리스트 (Empty List)**: 입력 리스트가 비어 있으면 어떤 항목도 제거할 수 없습니다.
- **타입 불일치 (Type Mismatch)**: "item" 제거 방식을 사용할 때 항목 타입이 리스트 항목들의 타입과 일치하는지 확인하세요.
