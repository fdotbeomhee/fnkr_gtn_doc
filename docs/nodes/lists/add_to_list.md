# AddToList

## 어떤 노드인가요?

AddToList 노드는 기존 리스트의 지정된 위치에 항목을 추가하는 유틸리티 노드입니다. 리스트의 맨 앞, 맨 뒤 또는 특정 인덱스 위치에 새 항목을 삽입할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 AddToList 노드를 사용하세요:

- 기존 리스트에 새 항목을 추가해야 할 때
- 리스트의 특정 위치에 항목을 삽입하고 싶을 때
- 워크플로우 실행 중에 업데이트되어야 하는 동적 리스트를 구축할 때
- 순서가 지정된 항목 컬렉션을 유지해야 할 때
- 새 리스트를 만들지 않고 리스트를 수정하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 AddToList 노드를 추가합니다.
1. 기존 리스트를 "items" 입력에 연결합니다.
1. 추가하려는 항목을 "item" 입력에 연결합니다.
1. "position" 파라미터를 사용하여 항목을 추가할 위치를 선택합니다.
1. "index" 위치를 사용하는 경우 인덱스 값을 지정합니다.

### 파라미터 (Parameters)

- **items**: 항목을 추가할 대상 리스트 (리스트 입력)
- **item**: 리스트에 추가할 항목 (모든 타입)
- **position**: 항목을 추가할 위치 (선택 옵션: "start", "end", "index")
- **index**: 항목을 추가할 특정 위치 (position이 "index"일 때만 표시됨)
- **output**: 새 항목이 추가되어 수정된 리스트

### 출력 (Outputs)

- **output**: 원래 항목들과 새로 추가된 항목이 포함된 리스트

## 예시

작업(task) 리스트에 새 작업을 추가하려는 경우:

1. 워크플로우에 AddToList 노드를 추가합니다.
1. 기존 작업 리스트를 "items" 입력에 연결합니다.
1. 새 작업을 "item" 입력에 연결합니다.
1. 리스트 맨 뒤에 추가하려면 "position"을 "end"로 설정합니다.
1. 출력은 새 작업이 끝에 추가된 리스트가 됩니다.

## 중요 참고 사항

- 이 노드는 원본을 직접 수정하지 않고 새 리스트를 생성합니다.
- "index" 위치를 사용할 때는 인덱스가 리스트 범위 내에 있어야 합니다.
- "index" 파라미터는 "position"이 "index"로 설정된 경우에만 표시됩니다.
- 모든 타입의 항목을 추가할 수 있지만, 출력을 받는 다음 노드와의 타입 호환성에 유의하세요.

## 자주 묻는 질문 및 문제 해결

- **잘못된 인덱스 (Invalid Index)**: "index" 위치를 사용할 경우 인덱스가 리스트 범위 내에 있는지 확인하세요.
- **빈 리스트 (Empty List)**: 입력 리스트가 비어 있으면 해당 항목이 첫 번째 요소로 추가됩니다.
- **타입 불일치 (Type Mismatch)**: 리스트의 다양한 데이터 타입을 수신 노드가 어떻게 처리하는지 확인하세요.
