# GetListContainsItem

## 어떤 노드인가요?

GetListContainsItem 노드는 특정 항목이 리스트에 존재하는지 여부를 확인하는 유틸리티 노드입니다. 입력 리스트에서 항목이 발견되었는지를 나타내는 불리언(boolean) 출력을 제공합니다.

## 언제 사용하나요?

다음과 같은 상황에서 GetListContainsItem 노드를 사용하세요:

- 특정 항목이 리스트에 존재하는지 확인해야 할 때
- 컬렉션에 필요한 데이터가 포함되어 있는지 검증하고 싶을 때
- 항목 존재 여부에 따른 조건부 워크플로우를 구축할 때
- 항목 존재 여부를 기준으로 리스트를 필터링하거나 처리해야 할 때
- 동적 리스트에서 특정 항목이 있는지 모니터링하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 GetListContainsItem 노드를 추가합니다.
1. 리스트를 "items" 입력에 연결합니다.
1. 확인하려는 항목을 "item" 입력에 연결합니다.
1. 노드가 항목의 리스트 존재 여부를 자동으로 확인하여 출력합니다.

### 파라미터 (Parameters)

- **items**: 확인할 대상 리스트 (리스트 입력)
- **item**: 리스트에서 찾을 항목 (모든 타입)
- **contains_item**: 항목이 발견되었는지(true) 여부(false)를 나타내는 불리언

### 출력 (Outputs)

- **contains_item**: 불리언 값 (항목이 발견되면 true, 그렇지 않으면 false)

## 예시

작업 리스트에 특정 작업이 존재하는지 확인하려는 경우:

1. 워크플로우에 GetListContainsItem 노드를 추가합니다.
1. 작업 리스트를 "items" 입력에 연결합니다.
1. 확인하려는 작업을 "item" 입력에 연결합니다.
1. 작업이 발견되면 "contains_item" 출력이 true가 되고, 없으면 false가 됩니다.

## 중요 참고 사항

- 리스트나 항목이 변경되면 노드가 자동으로 업데이트됩니다.
- 리스트나 항목이 제공되지 않으면 출력은 false가 됩니다.
- 노드는 정확한 일치(exact matching)를 사용하여 항목을 찾습니다.
- 출력은 항상 불리언 값입니다.

## 자주 묻는 질문 및 문제 해결

- **입력 없음 (No Input)**: 리스트나 항목이 연결되지 않으면 출력이 false가 됩니다.
- **잘못된 입력 (Invalid Input)**: 입력이 리스트가 아니면 출력이 false가 됩니다.
- **타입 불일치 (Type Mismatch)**: 올바른 비교를 위해 항목 타입이 리스트 항목들의 타입과 일치해야 합니다.
- **대소문자 구분 (Case Sensitivity)**: 문자열 비교는 대소문자를 구분합니다.
