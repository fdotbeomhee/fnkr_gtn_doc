# DisplayList

## 어떤 노드인가요?

DisplayList 노드는 리스트를 입력받아 리스트의 각 항목에 대한 개별 출력 파라미터를 생성하는 유틸리티 노드입니다. 각 항목의 타입을 자동으로 감지하고 적절한 타입의 출력 파라미터를 생성합니다.

## 언제 사용하나요?

다음과 같은 상황에서 DisplayList 노드를 사용하세요:

- 리스트의 개별 항목에 별도로 접근해야 할 때
- 리스트 항목을 개별적으로 표시하거나 처리하고 싶을 때
- 혼합된 타입의 리스트를 작업하면서 타입별 처리가 필요할 때
- 리스트 항목들을 서로 다른 노드에 연결해야 할 때
- 리스트의 내용을 더 자세하게 시각화하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 DisplayList 노드를 추가합니다.
1. 리스트를 "items" 입력에 연결합니다.
1. 노드가 각 항목에 대한 출력 파라미터를 자동으로 생성합니다.
1. 필요한 경우 개별 항목 출력을 다른 노드에 연결합니다.

### 파라미터 (Parameters)

- **items**: 표시할 리스트 (리스트 입력)
- **item_0, item_1, etc.**: 리스트의 각 항목에 대한 동적 출력 파라미터

### 출력 (Outputs)

- **item_0, item_1, etc.**: 리스트의 각 항목에 대한 개별 출력으로, 항목과 일치하는 타입을 가집니다.

## 예시

개별적으로 처리하고 싶은 혼합 데이터 타입의 리스트가 있는 경우:

1. 워크플로우에 DisplayList 노드를 추가합니다.
1. 리스트를 "items" 입력에 연결합니다.
1. 노드가 각 항목에 대해 별도의 출력을 생성합니다.
1. 타입에 따라 각 출력을 적절한 처리 노드에 연결합니다.

## 중요 참고 사항

- 노드가 각 항목의 타입을 자동으로 판별합니다.
- 출력 파라미터는 리스트 내용에 따라 동적으로 생성됩니다.
- 지원되는 타입: string, boolean, integer, float, 이미지 아티팩트(image artifacts)
- 입력 리스트가 변경될 때마다 출력이 업데이트됩니다.
- 출력 파라미터는 순서대로 명명됩니다 (item_0, item_1 등).

## 자주 묻는 질문 및 문제 해결

- **빈 리스트 (Empty List)**: 입력 리스트가 비어 있으면 출력 파라미터가 생성되지 않습니다.
- **잘못된 입력 (Invalid Input)**: 입력이 리스트가 아니면 출력 파라미터가 생성되지 않습니다.
- **타입 제한 (Type Limitations)**: 일부 복잡한 타입은 "any" 타입으로 처리될 수 있습니다.
- **동적 업데이트 (Dynamic Updates)**: 출력 파라미터의 개수는 리스트 길이에 따라 변경됩니다.
