# GetListIsEmpty

## 어떤 노드인가요?

GetListIsEmpty 노드는 리스트가 비어 있는지 여부를 확인하는 유틸리티 노드입니다. 입력 리스트에 항목이 포함되어 있는지 여부를 나타내는 불리언 출력을 제공합니다.

## 언제 사용하나요?

다음과 같은 상황에서 GetListIsEmpty 노드를 사용하세요:

- 리스트에 항목이 있는지 확인해야 할 때
- 처리 전에 리스트가 비어 있지 않은지 검증하고 싶을 때
- 리스트 내용에 따른 조건부 워크플로우를 구축할 때
- 다음 단계로 진행하기 전에 데이터가 준비되었는지 확인해야 할 때
- 동적 리스트의 상태를 모니터링하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 GetListIsEmpty 노드를 추가합니다.
1. 아무 리스트나 "items" 입력에 연결합니다.
1. 노드가 리스트가 비어 있는지 자동으로 확인하여 출력합니다.

### 파라미터 (Parameters)

- **items**: 확인할 대상 리스트 (리스트 입력)
- **is_empty**: 리스트가 비어 있는지(true) 아닌지(false)를 나타내는 불리언

### 출력 (Outputs)

- **is_empty**: 불리언 값 (리스트가 비어 있으면 true, 항목이 포함되어 있으면 false)

## 예시

작업 리스트에 보류 중인 작업이 있는지 확인하려는 경우:

1. 워크플로우에 GetListIsEmpty 노드를 추가합니다.
1. 작업 리스트를 "items" 입력에 연결합니다.
1. 작업이 없으면 "is_empty" 출력이 true가 되고, 작업이 있으면 false가 됩니다.

## 중요 참고 사항

- 입력 리스트가 변경되면 노드가 자동으로 업데이트됩니다.
- 연결된 리스트가 없으면 출력은 true(비어 있음)가 됩니다.
- 모든 타입의 항목을 가진 리스트에서 동작합니다.
- 출력은 항상 불리언 값입니다.

## 자주 묻는 질문 및 문제 해결

- **입력 없음 (No Input)**: 리스트가 연결되지 않으면 출력이 true(비어 있음)가 됩니다.
- **잘못된 입력 (Invalid Input)**: 입력이 리스트가 아니면 출력이 true(비어 있음)가 됩니다.
- **타입 불일치 (Type Mismatch)**: 이 노드는 리스트 입력에서만 작동하며, 다른 타입은 true(비어 있음) 결과를 냅니다.
