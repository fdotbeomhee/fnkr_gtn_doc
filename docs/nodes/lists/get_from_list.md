# Get From List

Get From List 노드는 리스트와 인덱스를 입력받아 해당 인덱스 위치의 항목을 반환합니다.

## 입력 (Inputs)

- **items** (list): 항목을 가져올 대상 리스트
- **index** (int): 항목을 가져올 인덱스 위치

## 출력 (Outputs)

- **item** (any): 리스트의 지정된 인덱스에 있는 항목. 인덱스가 유효하지 않거나 입력이 누락된 경우 None을 반환합니다.

## 예시

```python
# Input list: [1, 2, 3, 4, 5]
# Input index: 2
# Output: 3
```

## 참고 사항 (Notes)

- 인덱스가 범위를 벗어나거나 유효하지 않은 경우 노드는 None을 반환합니다.
- 리스트 또는 인덱스 입력이 누락된 경우 노드는 None을 반환합니다.
- 리스트에는 모든 타입의 항목이 포함될 수 있으므로 출력 타입은 "any"입니다.
- index 파라미터는 입력 연결 또는 속성(Property) 값으로 설정할 수 있습니다.
