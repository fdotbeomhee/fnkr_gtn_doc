# CreateList

## 어떤 노드인가요?

CreateList 노드는 제공된 항목들로부터 리스트를 생성하는 유틸리티 노드입니다. 여러 입력을 하나의 리스트 출력으로 결합하여 워크플로우에서 동적으로 리스트를 구성할 수 있습니다.

## 언제 사용하나요?

다음과 같은 상황에서 CreateList 노드를 사용하세요:

- 여러 항목을 하나의 리스트로 결합해야 할 때
- 워크플로우의 다양한 입력으로부터 리스트를 생성하고 싶을 때
- 리스트 형식이 필요한 데이터 구조를 구축할 때
- 리스트 입력을 요구하는 노드를 위해 데이터를 준비해야 할 때
- 여러 값을 단일 리스트 구조로 통합하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 CreateList 노드를 추가합니다.
1. 개별 항목을 "items" 입력에 연결하거나 노드의 속성 패널에서 직접 추가합니다.
1. 노드가 모든 입력을 결합하여 단일 리스트 출력으로 생성합니다.

### 파라미터 (Parameters)

- **items**: 결합할 항목들의 리스트 (어떤 타입이든 다중 입력 지원)
- **output**: 모든 입력 항목이 포함된 결합 리스트

### 출력 (Outputs)

- **output**: 입력으로 제공된 모든 항목을 포함하는 리스트

## 예시

서로 다른 데이터 타입의 리스트를 생성하려는 경우:

1. 워크플로우에 CreateList 노드를 추가합니다.
1. "items" 파라미터에 다양한 입력(예: 텍스트, 숫자 또는 기타 데이터 타입)을 연결합니다.
1. 출력은 연결된 순서대로 모든 항목이 포함된 리스트가 됩니다.

## 중요 참고 사항

- CreateList 노드는 모든 타입의 항목을 처리할 수 있습니다.
- 항목은 연결된 순서대로 리스트에 추가됩니다.
- 입력 항목이 변경될 때마다 노드가 자동으로 출력을 업데이트합니다.
- 연결을 통해서도 추가할 수 있고 노드의 속성 패널에서 직접 항목을 추가할 수도 있습니다.

## 자주 묻는 질문 및 문제 해결

- **빈 리스트 (Empty List)**: 제공된 항목이 없으면 출력이 빈 리스트가 됩니다.
- **타입 불일치 (Type Mismatch)**: 노드는 모든 타입의 항목을 허용하지만, 수신 노드가 다양한 데이터 타입을 어떻게 처리하는지 확인하세요.
