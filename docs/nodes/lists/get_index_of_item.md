# GetIndexOfItem

## 어떤 노드인가요?

GetIndexOfItem 노드는 리스트에서 특정 항목의 위치(인덱스)를 찾는 유틸리티 노드입니다. 리스트에서 해당 항목이 처음 나타나는 0 기반(zero-based) 인덱스를 반환합니다.

## 언제 사용하나요?

다음과 같은 상황에서 GetIndexOfItem 노드를 사용하세요:

- 리스트 내 특정 항목의 위치를 찾아야 할 때
- 컬렉션에서 특정 항목의 위치를 확인하고 싶을 때
- 항목의 위치를 기준으로 참조해야 하는 워크플로우를 구축할 때
- 리스트 내 항목 위치를 검증해야 할 때
- 동적 리스트에서 항목의 위치를 추적하고 싶을 때

## 사용 방법

### 기본 설정

1. 워크플로우에 GetIndexOfItem 노드를 추가합니다.
1. 리스트를 "items" 입력에 연결합니다.
1. 찾고자 하는 항목을 "item" 입력에 연결합니다.
1. 노드가 리스트에서 해당 항목의 인덱스를 출력합니다.

### 파라미터 (Parameters)

- **items**: 검색할 대상 리스트 (리스트 입력)
- **item**: 리스트에서 찾을 항목 (모든 타입)
- **index**: 리스트 내 항목의 위치 (정수형 출력)

### 출력 (Outputs)

- **index**: 항목의 위치를 나타내는 정수 (항목이 없으면 -1)

## 예시

작업 리스트에서 특정 작업의 위치를 찾으려는 경우:

1. 워크플로우에 GetIndexOfItem 노드를 추가합니다.
1. 작업 리스트를 "items" 입력에 연결합니다.
1. 찾으려는 작업을 "item" 입력에 연결합니다.
1. "index" 출력에 리스트 내 해당 작업의 위치가 표시됩니다.

## 중요 참고 사항

- 리스트에서 항목을 찾지 못한 경우 노드는 -1을 반환합니다.
- 인덱스 위치는 0부터 시작합니다 (첫 번째 항목의 인덱스는 0).
- 항목이 여러 번 나타나는 경우 처음 나타난 위치를 찾습니다.
- 리스트나 항목이 변경되면 노드가 자동으로 업데이트됩니다.

## 자주 묻는 질문 및 문제 해결

- **항목을 찾을 수 없음 (Item Not Found)**: 항목이 리스트에 없으면 출력이 -1이 됩니다.
- **입력 없음 (No Input)**: 리스트나 항목이 연결되지 않으면 출력이 -1이 됩니다.
- **잘못된 입력 (Invalid Input)**: 입력이 리스트가 아니면 출력이 -1이 됩니다.
- **타입 불일치 (Type Mismatch)**: 올바른 비교를 위해 항목 타입이 리스트 항목들의 타입과 일치해야 합니다.
- **대소문자 구분 (Case Sensitivity)**: 문자열 비교는 대소문자를 구분합니다.
