# 엄격 모드 레퍼런스 (Strict Mode Reference)

엄격 모드(Strict Mode)는 노드가 워커 서브프로세스 격리 환경에서 문제없이 실행될 수 있는지를 사전 검증하는 진단 도구입니다.

## 엄격 모드 검사 항목

엄격 모드가 활성화되면 다음 규칙을 위반하는 노드에 대해 경고 또는 오류를 발생시킵니다:

1. **파라미터 직렬화 가능성**: 모든 파라미터 기본값과 입출력 데이터는 프로세스 간 전송(IPC)을 위해 JSON 직렬화가 가능해야 합니다.
2. **글로벌 엔진 상태 접근 금지**: 노드가 `griptape_nodes.engine` 싱글톤이나 글로벌 컨텍스트에 직접 접근하지 않고 제공된 메서드만 사용해야 합니다.
3. **상태 격리**: 노드 실행 간에 공유되는 가변 글로벌 변수를 유지하지 않아야 합니다.
4. **올바른 수명 주기 사용**: UI 관련 로직과 실행 로직이 올바르게 분리되어 있어야 합니다.

## 엄격 모드 활성화 방법

개발 중 설정 파일이나 환경 변수로 엄격 모드를 켤 수 있습니다:

```bash
GTN_CONFIG_STRICT_MODE=true gtn
```
