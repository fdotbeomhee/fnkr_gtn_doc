# 노드 작업 가이드 (Working with Nodes)

이 페이지에서는 캔버스에서 워크플로우를 구축할 때 수행하는 일상적인 작업들을 다룹니다. 노드 추가, 선택 및 이동, 이름 변경, 복제, 잠금, 삭제, 노드 간 연결선 배선, 파라미터 편집 등을 설명합니다. 워크플로우가 구성된 후 실행하는 방법에 대해서는 [워크플로우 실행](running_workflows.md)을 참조하세요. 노드들을 그룹으로 묶는 방법은 [노드 그룹](node_groups.md)을 참조하세요.

## 노드 추가

**Add Node** 메뉴를 여는 세 가지 방법:

- 커서가 캔버스 위에 있을 때 `Tab` 키를 누릅니다.
- 커서가 캔버스 위에 있을 때 `Shift+A`를 누릅니다. (커서가 캔버스 밖에 있을 때 `Shift+A`를 누르면 대신 모든 노드가 선택됩니다 — [선택 및 이동](#선택-및-이동) 참조).
- 빈 캔버스를 마우스 오른쪽 버튼으로 클릭하고 **Add Node**를 선택합니다.

메뉴가 커서 위치에 열리고 노드를 선택하면 해당 위치에 새 노드가 배치됩니다. 이름, 설명 또는 태그로 필터링하거나 카테고리 트리를 탐색할 수 있는 검색 가능한 목록입니다. 즐겨찾기 노드가 있는 경우 **Favorites** 섹션(별표를 눌러 추가)이, 최근 추가한 노드가 있는 경우 **Recent** 섹션이 카테고리 목록 위에 표시됩니다.

<!-- screenshot (#5166): the Add Node menu open at the cursor, showing search results and category tree -->

왼쪽 사이드바의 **Nodes** 탭에서 노드 유형을 캔버스로 직접 드래그할 수도 있습니다.

## 선택 및 이동

노드를 클릭하여 선택합니다. `Cmd/Ctrl+A`는 플로우의 모든 노드를 선택하고 `Escape`는 선택을 해제합니다. 빈 캔버스를 드래그하여 상자 안에 포함된 모든 항목을 선택할 수 있습니다.

`Shift` 키(또는 `Cmd/Ctrl` 키)를 누른 채 추가 노드를 클릭하여 다중 선택을 구성할 수 있습니다. 둘 이상의 노드가 선택된 상태에서 그중 하나를 드래그하면 전체 선택 항목이 함께 이동하며, 선택 영역 위에 **Settings → Editor → Button Customization** 설정에 따라 Copy, Duplicate, Lock, Reset, Delete, Create Group 등의 일괄 적용 작업이 포함된 플로팅 툴바가 나타납니다.

<!-- screenshot (#5166): two or more selected nodes with the floating multi-node toolbar visible above them -->

화살표 키는 해당 방향에서 가장 가까운 노드로 선택을 이동시키므로 마우스를 사용하지 않고 연결된 노드 체인을 빠르게 탐색할 수 있습니다. `F` 키는 현재 선택 항목을 화면에 맞추고(선택 항목이 없으면 전체 그래프 맞춤), `Shift+G`는 그래프를 깔끔한 레이아웃으로 자동 정렬합니다.

## 이름 변경

모든 노드의 표시 이름은 워크플로우 내에서 고유 식별자 역할을 겸하므로, 노드 이름을 바꾸면 해당 노드에 대한 모든 참조도 함께 업데이트됩니다.

단일 노드의 이름을 바꾸려면 노드를 선택하고 `R` 키를 누르거나, 마우스를 올렸을 때 이름 옆에 나타나는 작은 연필 아이콘을 클릭하거나, 우클릭 메뉴에서 **Rename**을 선택합니다. 새 이름을 입력하고 `Enter` 키를 누르거나(바깥쪽 클릭) 적용하고, `Escape` 키를 눌러 취소합니다.

여러 노드의 이름을 한 번에 바꾸려면 노드들을 선택하고 `R` 키를 누르거나 그중 하나를 우클릭하고 **Rename**을 선택합니다. 그러면 **Rename nodes** 대화 상자가 열리며 단일 기본 이름을 전체 선택 항목에 적용합니다. 첫 번째 노드는 기본 이름을 그대로 받고 나머지는 `Base_1`, `Base_2` 등의 접미사가 붙습니다.

<!-- screenshot (#5166): the Rename nodes dialog with a base name typed in and the preview text showing Base, Base_1, Base_2 -->

## 복제, 복사 및 붙여넣기

- **Duplicate** (`Cmd/Ctrl+D` 또는 노드/다중 노드 툴바의 Duplicate 작업)는 선택한 노드의 독립된 복사본을 원본 바로 옆에 연결선 없이 생성합니다.
- **Copy** (`Cmd/Ctrl+C`)는 파라미터 값을 포함하여 선택한 노드를 시스템 클립보드로 직렬화합니다.
- **Paste** (`Cmd/Ctrl+V`)는 마지막으로 복사한 항목으로부터 새 노드를 생성하여 커서 근처에 배치합니다.

복사/붙여넣기는 열려 있는 두 워크플로우 탭 간에 노드를 이동하는 방법이기도 합니다. 한 탭에서 복사하고 다른 탭으로 전환하여 붙여넣으면 됩니다.

## 잠금

노드를 잠그면 실수로 인한 변경을 방지할 수 있습니다. 잠긴 노드는 다시 잠금을 해제할 때까지 실행하거나 삭제할 수 없으며, 파라미터를 편집하거나 파라미터를 추가할 수 없습니다.

`L` 키(다중 선택에서도 작동함), 헤더의 자물쇠 아이콘, 또는 우클릭 메뉴의 **Lock**/**Unlock**을 사용하여 노드의 잠금 상태를 전환합니다. Note 노드는 잠글 수 없으며 잠금 옵션이 적용되지 않습니다.

## 삭제

하나 이상의 노드를 선택하고 `Delete` 키(일부 키보드에서는 `Backspace`)를 누르거나 우클릭 메뉴 또는 툴바에서 **Delete Node**를 사용합니다. 노드를 삭제하면 해당 노드가 가지고 있던 모든 연결이 제거됩니다. 연결선 중간에 위치한 [도트 노드](#도트dot-및-재라우팅reroute-노드)를 삭제하면 양쪽 끝이 직접 다시 연결되어 나머지 연결선이 유지됩니다.

그룹을 삭제하면 그룹 래퍼만 제거되고 자식 노드는 그룹 해제된 상태로 캔버스에 유지됩니다. 자세한 내용은 [노드 그룹](node_groups.md#그룹-해제-ungrouping)을 참조하세요.

### 워크플로우 실행 중 삭제

실행이 끝날 때까지 기다리지 않고 노드를 삭제할 수 있습니다. 실행에 해당 노드가 여전히 필요한지 여부에 따라 결과가 달라집니다:

- **실행에 해당 노드가 필요 없는 경우** — 해당 노드의 작업이 이미 끝났거나 실행 경로에 도달하지 않는 노드인 경우 실행이 정상적으로 계속 진행됩니다. 실행 체인에 연결되지 않고 캔버스 한쪽에 떨어져 있는 노드가 여기에 해당합니다.
- **실행에 해당 노드가 여전히 필요한 경우** — 실행이 취소됩니다. 엔진은 삭제된 노드를 기다리고 있던 노드가 무엇인지 보고하므로 실행이 중단된 이유를 확인할 수 있습니다. 실행이 정리되는 즉시 실행 버튼이 다시 활성화됩니다.

체인의 더 뒤쪽에 위치한 노드는 아직 시작되지 않았더라도 여전히 필요한 노드로 간주됩니다. 실행이 결국 해당 노드에 도달할 것이고, 도달했을 때 입력이 누락된 상태가 되기 때문입니다. 중간의 다른 노드를 통해 간접적으로 데이터를 공급하는 노드도 마찬가지입니다.

두 번째 동작 방식은 의도된 것입니다. 의존하는 노드 없이 실행을 계속 진행하면 실제 값 대신 해당 파라미터의 기본값을 사용하여 완료되므로, 워크플로우가 조용히 잘못된 결과를 생성하면서도 겉으로는 성공한 것처럼 보이기 때문입니다.

## 파라미터 연결

입력 또는 출력 역할을 할 수 있는 모든 파라미터는 해당 행의 왼쪽(입력) 또는 오른쪽(출력) 가장자리에 작은 핸들을 가집니다. 한 핸들에서 다른 핸들로 드래그하여 연결선을 만듭니다. 핸들에서 빈 캔버스로 드래그하면 해당 핸들에 미리 배선된 Add Node 메뉴가 열리며, 이는 체인의 *다음* 노드를 빠르게 추가할 수 있는 방법입니다.

에디터는 호환 가능한 유형 간의 연결만 완료할 수 있도록 허용합니다. 드래그하는 동안 캔버스의 호환되지 않는 핸들은 흐리게 표시되어 연결이 가능한 위치를 쉽게 확인할 수 있습니다. 대부분의 파라미터는 둘 이상의 유형을 수용하며(예: URL 문자열도 수용하는 이미지 입력), 허용되는 구체적인 유형은 노드 정의에 의해 각 파라미터에 지정되어 있습니다.

연결을 제거하려면 해당 연결선을 클릭하여 선택한 후 `Delete`를 누르거나, 연결선에 마우스를 올려 나타나는 연결 버튼을 사용합니다(**Settings → Editor → Node Settings**에서 **Show Connection Buttons on Hover**가 활성화된 경우).

## 도트(Dot) 및 재라우팅(Reroute) 노드

**도트 노드**는 기존 연결선 중간에 배치하여 다른 노드를 우회하도록 경로를 꺾거나 복잡한 캔버스를 정리할 수 있는 로직이 없는 통과용 노드입니다. 연결선에 마우스를 올리거나 선택한 상태에서 `I` 키를 누르면 해당 지점에 도트 노드가 삽입됩니다. 기존 연결은 두 개로 분할되어 새 도트 노드를 통해 라우팅되며 전달되는 데이터에는 아무런 변화가 없습니다.

<!-- screenshot (#5166): a connection with a dot node inserted partway along its path -->

도트 노드를 삭제하면 인접한 두 노드가 직접 다시 연결되므로 도트 노드를 제거해도 플로우가 끊어지지 않습니다.

## 노트 (Notes)

**노트**는 자신이나 공동 작업자에게 맥락(그래프의 특정 섹션 용도, TODO, 업스트림 종속성에 대한 경고 등)을 남기기 위해 캔버스에 배치하는 자유롭게 떠 있는 비실행 텍스트 블록입니다. 커서가 캔버스 위에 있을 때 `N` 키를 누르면 커서 위치에 노트를 생성합니다.

노트는 잠글 수 없으며 실행이나 다중 노드 툴바의 Run/Reset 작업에 참여하지 않습니다.

## 속성 패널 (Properties panel)

노드를 선택하면 노드 자체에 인라인으로 표시되는 파라미터 행과 함께 **Properties** 패널(오른쪽 사이드바)에 해당 파라미터가 열립니다. 동일한 값이지만 전용으로 항상 표시되는 공간이므로 노드에 파라미터가 많거나 노드를 접었을 때 작업하기 편리합니다. `Cmd/Ctrl+B`, 우클릭 메뉴의 **Property Panel** 항목, 또는 노드 헤더 버튼(추가한 경우)을 사용하여 이 패널이 위치한 오른쪽 사이드바를 열 수 있습니다.

<!-- screenshot (#5166): the Properties panel showing a selected node's parameters -->

Properties 패널에서 값을 편집하는 것과 노드의 인라인 행에서 동일한 파라미터를 편집하는 것은 동일한 기본값을 업데이트합니다.

### 커스텀 파라미터 추가

일부 노드는 기본 제공 파라미터 외에 사용자가 직접 파라미터를 추가할 수 있도록 지원합니다. 노드가 이를 지원하는 경우 파라미터 목록 하단(노드 자체 및 Properties 패널)에 **Add parameter** 행이 표시되거나 우클릭 메뉴에 **Add parameter**가 나타납니다.

이를 열면 **Add New Parameter** 대화 상자가 표시되며 다음을 설정할 수 있습니다:

| 필드 | 제어 대상 |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| **Name** | 파라미터의 내부 이름입니다. 노드 내에서 고유해야 합니다. |
| **Display Name** | UI에 표시되는 레이블입니다. 내부 이름과 다르게 표시하고 싶을 때 사용합니다. |
| **Type** | `Any`, `str`, `bool`, `int`, `float`, `dict`, `json` 또는 미디어 유형 `image`, `audio`, `video` 중 하나입니다. |
| **Tooltip** | 마우스를 올렸을 때 표시되는 도움말 텍스트입니다. |
| **Input / Output** | 파라미터를 입력 연결, 출력 연결 또는 둘 다로 배선할 수 있는지 여부입니다. |
| **Default Value** | 아무것도 설정하거나 연결하지 않았을 때 파라미터가 시작하는 기본값입니다. |

선택한 유형에 따라 추가 옵션이 나타납니다. 텍스트의 경우 여러 줄/Markdown 토글, 숫자의 경우 min/max/step이 포함된 슬라이더, 드롭다운의 경우 고정된 선택지 세트(선택적 아이콘, 부제목, 검색 상자 포함)가 제공됩니다.

<!-- screenshot (#5166): the Add New Parameter dialog with the type dropdown open -->

### 기존 커스텀 파라미터 구성

커스텀 파라미터가 생성된 후 마우스 오른쪽 버튼을 클릭하거나(Properties 패널의 해당 행에서) **Configure parameter**를 선택하면 현재 설정이 채워진 동일한 대화 상자가 다시 열립니다. 이 옵션은 직접 추가한 파라미터에만 표시되며 노드 정의와 함께 제공되는 기본 파라미터는 이 방식으로 편집할 수 없습니다.

### 연결된 파라미터 숨기기

**Hide Connected Parameters**(`Shift+H` 또는 **Settings → Editor → Node Settings**)를 켜면 입력에 이미 유입 연결이 있는 모든 파라미터 행을 접을 수 있습니다. 복잡한 워크플로우를 정리하는 도구로, 값이 캔버스의 다른 곳에서 유입되는 경우 편집 가능한 입력 필드가 공간을 차지하도록 둘 필요가 없기 때문입니다. 다시 끄면 모든 행이 즉시 복원됩니다.

!!! tip "특정 파라미터를 항상 표시하도록 유지"

    Node Settings의 메인 토글 옆에 있는 **Ignore Hide Connected (Display Nodes)** 및 **Ignore Hide Connected (Save Nodes)**를 활성화하면 이름에 "display" 또는 "save"가 포함된 파라미터는 숨김 대상에서 제외됩니다. 입력이 연결되어 있는 동안에도 출력 경로를 주시하거나 미리보기를 확인하고 싶은 노드에 유용합니다.
