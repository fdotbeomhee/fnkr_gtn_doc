# 키보드 단축키 (Keyboard Shortcuts)

에디터의 모든 단축키에 대한 참조 안내서이며, 작업 목적별로 분류되어 있습니다. 보조키(modifier key)가 다른 경우 macOS 및 Windows/Linux 단축키가 별도의 열로 나열됩니다.

!!! note "입력 중에는 단축키가 방해하지 않습니다"

    텍스트 필드, 노드의 파라미터 또는 Code 패널에 입력하는 동안에는 대부분의 단일 키 캔버스 단축키(예: `R` 또는 `N`)가 무시되므로, 단축키가 트리거되는 대신 입력 중인 위치에 일반 문자가 정상적으로 입력됩니다.

이 단축키들이 작동하는 에디터 영역에 대한 개요는 [에디터 둘러보기](index.md)를 참조하세요.

## 노드 추가 및 편집 (Adding & editing nodes)

| 작업 | macOS | Windows / Linux |
| ---------------------------------------------------------- | ------------------- | ------------------- |
| 커서 위치에 노드 추가 (캔버스 전용) | Tab | Tab |
| 커서 위치에 노드 추가 (캔버스 밖이면 전체 선택) | Shift+A | Shift+A |
| 커서 위치에 Add Node 메뉴 열기 | 캔버스 더블클릭 | 캔버스 더블클릭 |
| 커서 위치에 Note 노드 생성 | N | N |
| 선택한 노드 이름 변경 | R | R |
| 선택한 노드 복제 | Cmd+D | Ctrl+D |
| 선택한 노드 잠금 / 잠금 해제 | L | L |
| 선택한 노드 또는 연결 삭제 | Delete / Backspace | Delete / Backspace |

## 선택 (Selection)

| 작업 | macOS | Windows / Linux |
| ----------------------------------------------------- | -------------------- | -------------------- |
| 모든 노드 선택 | Cmd+A | Ctrl+A |
| 현재 선택 해제 | Escape | Escape |
| 선택 항목에 노드 추가 또는 제거 | 노드 Shift-클릭 | 노드 Shift-클릭 |
| 빈 캔버스를 드래그하여 여러 노드 선택 | 빈 캔버스 드래그 | 빈 캔버스 드래그 |
| 해당 방향의 가장 가까운 노드로 선택 이동 | 화살표 키 | 화살표 키 |

## 클립보드 (Clipboard)

| 작업 | macOS | Windows / Linux |
| ------------------------------------------------------ | ----- | --------------- |
| 선택한 노드 복사 | Cmd+C | Ctrl+C |
| 노드 또는 클립보드의 이미지/미디어 파일 붙여넣기 | Cmd+V | Ctrl+V |

## 탐색 및 보기 (Navigation & view)

| 작업 | macOS | Windows / Linux |
| ------------------------------------------------------------------ | ------------------- | ------------------- |
| 선택한 노드를 화면에 맞춤 (선택 항목이 없으면 전체 그래프 맞춤) | F | F |
| 선택한 그룹을 내부 노드에 맞춤 (그 외에는 선택 항목 맞춤) | Shift+F | Shift+F |
| 캔버스 화면 이동 (노드 위에 있을 때도 작동) | Space 누른 채 드래그 | Space 누른 채 드래그 |
| 캔버스 화면 이동 | 마우스 가운데 클릭 + 드래그 | 마우스 가운데 클릭 + 드래그 |
| 스크러비 줌 — 오른쪽으로 드래그하면 확대, 왼쪽은 축소 | Z 누른 채 드래그 | Z 누른 채 드래그 |
| 확대 | Cmd+= | Alt+= |
| 축소 | Cmd+- | Alt+- |
| 확대 / 축소 | 스크롤 또는 핀치 | 스크롤 또는 핀치 |

## 그룹 및 레이아웃 (Groups & layout)

| 작업 | macOS | Windows / Linux |
| ------------------------------------------------ | ----------- | --------------- |
| 선택 항목으로 그룹 생성 (기본 유형) | Cmd+G | Ctrl+G |
| 유형을 직접 선택하여 그룹 생성 | Shift+Cmd+G | Shift+Ctrl+G |
| 그래프 자동 정렬 | Shift+G | Shift+G |

그룹 유형의 의미와 자동 정렬이 그래프를 배치하는 방식에 대한 자세한 내용은 [노드 그룹](node_groups.md)을 참조하세요.

## 연결 (Connections)

| 작업 | macOS | Windows / Linux |
| -------------------------------------------------------------- | -------- | --------------- |
| 이미 연결이 존재하는 파라미터 표시 전환 | Shift+H | Shift+H |
| 마우스 오버/선택된 연결선에 도트(재라우팅) 노드 삽입 | I | I |
| 연결선에 마우스 오버 시 연결 작업 버튼 표시 | Cmd 누른 채 유지 | Ctrl 누른 채 유지 |

## 워크플로우 / 파일 (Workflow / file)

| 작업 | macOS | Windows / Linux |
| --------------------------------- | --------------- | ---------------- |
| 저장 | Cmd+S | Ctrl+S |
| 다른 이름으로 저장 (Save As) | Shift+Cmd+S | Shift+Ctrl+S |
| 새 버전으로 저장 (Save As New Version) | Option+Shift+S | Alt+Shift+S |
| 워크플로우 열기 | Cmd+O | Ctrl+O |
| 새 워크플로우 | Shift+Cmd+O | Shift+Ctrl+O |
| 선택한 노드까지 실행 | Cmd+Enter | Ctrl+Enter |
| 전체 워크플로우 실행 | Shift+Cmd+Enter | Shift+Ctrl+Enter |
| 워크플로우를 이미지로 다운로드 | Cmd+I | Ctrl+I |
| 오른쪽 사이드바 토글 | Cmd+B | Ctrl+B |
| 왼쪽 사이드바 토글 | Shift+Cmd+B | Shift+Ctrl+B |
| 단축키 안내 표시 | Shift+? | Shift+? |
