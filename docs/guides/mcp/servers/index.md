# 예제 MCP 서버

이 섹션에서는 Griptape Nodes와 원활하게 연동되는 예제 MCP 서버에 대한 설정 가이드와 설명서를 제공합니다. 이는 커뮤니티에서 제공하는 수많은 MCP 서버 중 일부에 불과합니다.

## 추가 MCP 서버를 찾을 수 있는 곳

[공식 MCP 서버 저장소](https://github.com/modelcontextprotocol/servers)에는 참조 구현체 및 커뮤니티에서 구축한 방대한 서버 모음이 포함되어 있습니다. 이 저장소는 MCP의 다재다능함을 보여주며, 대규모 언어 모델(LLM)에 도구와 데이터 소스에 대한 안전하고 통제된 접근 권한을 부여하는 방법을 제시합니다.

### 공식 저장소 주요 특징:

- 일반적인 사용 사례를 위한 **참조 구현체**
- 전 세계 개발자들의 **커뮤니티 기여**
- **다양한 언어 지원** (TypeScript, Python, JavaScript 등)
- `npx`, `uvx`, `pip`를 통한 **간편한 설치**
- 각 서버에 대한 **포괄적인 설명서**

## 제공되는 서버 설명서

### 로컬 애플리케이션 (stdio)

이 서버들은 로컬 머신에서 실행되며 소프트웨어 및 파일에 직접 접근할 수 있도록 해줍니다:

- **[Blender](./blender.md)** - 3D 모델링, 씬(Scene) 생성 및 조작 (서드파티)
- **[Maya](./maya.md)** - Autodesk Maya를 활용한 3D 모델링, 애니메이션 및 씬 생성 (서드파티)
- **[Fetch](./fetch.md)** - 웹 콘텐츠 가져오기 및 처리
- **[Filesystem](./filesystem.md)** - 파일 및 디렉터리 작업
- **[Time](./time.md)** - 날짜 및 시간 작업

### 웹 서비스 (streamable_http)

이 서버들은 웹 기반 애플리케이션 및 서비스에 연결합니다:

- **[Exa](./exa.md)** - 고급 웹 검색 및 리서치 기능

## 더 많은 옵션이 필요하신가요?

- 수백 개의 추가 서버를 확인하려면 **[공식 저장소](https://github.com/modelcontextprotocol/servers)를 둘러보세요**
- **[MCP Servers](https://mcpservers.org/) 살펴보기** - 추천 및 공식 옵션이 포함된 큐레이션된 MCP 서버 모음
- MCPHub, MCP Servers Hub 및 기타 큐레이션된 목록과 같은 **커뮤니티 디렉터리 확인하기**
- 여러 프로그래밍 언어로 제공되는 MCP SDK를 사용하여 **직접 구축하기**

MCP 생태계는 지속적으로 성장하고 있으며, 커뮤니티를 통해 새로운 서버가 정기적으로 추가되고 있습니다!
