# MCP 서버 (MCP Servers)

**MCP servers** 드롭다운을 사용하면 대화를 위해 하나 이상의 MCP 서버를 에이전트에 연결할 수 있습니다. 이를 통해 구성된 서버에 따라 파일, 웹 검색, Blender, Maya 등 다양한 외부 도구에 에이전트가 접근할 수 있습니다.

## 대화 도중 서버 편집하기

MCP 서버를 변경한 내용은 **다음 메시지**부터 바로 적용됩니다. 엔진을 재시작하거나 새 대화를 시작할 필요가 없습니다. 이는 서버의 모든 항목(명령어, 인수, 환경 변수, 작업 디렉터리, URL, 헤더 및 **규칙(Rules)**)에 적용됩니다.

저장 후 다음 메시지를 보내면 에이전트가 업데이트된 서버를 사용합니다. 대화 기록은 그대로 유지되므로 질문을 바로 이어서 할 수 있습니다.

변경하지 않은 서버는 기존 연결을 유지하므로, 특정 서버 하나를 편집하더라도 다른 서버의 동작이 느려지거나 중단되지 않습니다.

편집한 서버의 재연결 필요 여부는 변경한 내용에 따라 달라집니다:

- **Rules(규칙)**를 편집하는 경우 재연결 없이 즉시 적용됩니다. 규칙은 매 메시지마다 에이전트에 새로 전송되기 때문입니다.
- Griptape Nodes가 서버에 연결하는 방식(명령어, 인수, 환경 변수, 작업 디렉터리, URL, 헤더 또는 타임아웃)을 편집하는 경우, 해당 항목들은 연결이 열릴 때 고정되므로 다음 메시지 전송 시 재연결됩니다. 이로 인해 에이전트의 첫 번째 도구 호출 전에 잠시 지연이 발생할 수 있습니다.

서버를 끄거나 삭제하면 다음 메시지부터 에이전트가 해당 서버 사용을 중지하고 Griptape Nodes가 연결을 종료합니다.
