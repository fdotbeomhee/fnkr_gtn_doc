# Griptape Cloud

Griptape Cloud는 Griptape Nodes의 기본 AI 제공자입니다. Griptape의 호스팅 프록시를 통해 요청을 라우팅하므로 개별 제공자 계정이나 키 없이 단일 Griptape API 키로 다양한 모델 카탈로그에 접근할 수 있습니다.

## 설정

별도의 설정이 필요하지 않습니다. Griptape Cloud 계정으로 Griptape Nodes를 설치한 경우, 이 제공자를 즉시 사용할 수 있습니다.

## 사용 가능한 모델

Griptape Cloud는 여러 제공자의 모델을 제공합니다:

- **Anthropic** — Claude Opus, Sonnet, Haiku
- **Google** — Gemini Pro 및 Flash 변형 모델
- **OpenAI** — GPT 및 o 시리즈 모델
- **Meta** — Llama 모델
- **DeepSeek** — DeepSeek V3 및 R1

전체 목록은 [에이전트](../index.md)의 **Model** 드롭다운에서 확인할 수 있습니다.
