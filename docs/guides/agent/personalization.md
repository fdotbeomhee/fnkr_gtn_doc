# 개인화 (Personalization)

에이전트가 사용자와 대화하는 방식과 보유할 컨텍스트를 맞춤 설정할 수 있습니다. **Settings → Agent Settings**를 열고 **Personalization** 섹션으로 스크롤하세요.

<!-- TODO(#5095): screenshot of the full Personalization section -->

| 필드 | 설명 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Address me as** | 에이전트가 사용자를 부를 때 사용하는 이름 또는 닉네임 |
| **Tone** | 커뮤니케이션 스타일 (예: Concise(간결함), Formal(격식체), Casual(친근함)) |
| **My role** | 직책 또는 전문 분야 — 에이전트에게 사용자의 배경에 대한 컨텍스트 제공 |
| **About me** | 관심사, 배경 또는 에이전트가 알기를 원하는 모든 컨텍스트에 대한 자유 형식 텍스트 |
| **Additional instructions** | 모든 응답에 추가되는 추가 규칙 — 페르소나 설정, 출력 형식 정의 또는 도메인별 제약 조건 추가에 사용 |

이 필드들이 결합되어 에이전트의 시스템 프롬프트를 구성합니다. 컨텍스트를 많이 제공할수록 응답이 더욱 사용자에게 맞춤화됩니다.
