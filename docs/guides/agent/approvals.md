# 승인 (Approvals) {: #approvals }

에이전트가 수행하면 비용이 발생하거나 프로젝트가 변경되는 작업이 있습니다. 워크플로우 실행, 노드 실행, 이미지 생성, 또는 사용자의 MCP 서버 도구 사용이 여기에 해당합니다. 에이전트는 이러한 작업을 수행하기 전에 사용자에게 묻습니다. 따라서 "이 노드는 어떻게 작동하나요?"와 같은 질문이 사용자가 요청하지 않은 워크플로우 실행으로 이어지지 않습니다.

## 에이전트가 묻는 항목 (What the agent asks about) {: #what-the-agent-asks-about }

에이전트는 다음 작업을 수행하기 전에 묻습니다:

- 워크플로우, 플로우 또는 단일 노드 실행
- 이미지 생성
- 대화에 연결한 MCP 서버의 도구 사용 ([외부 도구 (MCP 서버)](./mcp_servers.md) 참조)

그 외의 작업은 묻지 않고 실행됩니다. 캔버스 읽기, 라이브러리 및 노드 목록 조회, 노드 생성 및 연결, 파라미터 값 설정, 워크플로우 저장이 여기에 포함됩니다.

## 승인 카드에 응답하기 (Answering an approval card) {: #answering-an-approval-card }

에이전트가 이러한 작업 중 하나를 수행하려고 하면 응답이 일시 중지되고 스레드에 승인 카드가 나타납니다. 카드에는 에이전트가 사용하려는 도구와 전송할 내용이 표시됩니다. 다음 중 하나를 선택합니다:

- **Approve once** — 이번에만 실행합니다. 같은 작업을 다시 하려고 하면 에이전트가 다시 묻습니다.
- **Approve for conversation** — 실행하고, 이 스레드에서 같은 작업을 묻지 않고 다시 수행할 수 있도록 허용합니다. 에이전트가 여러 항목을 함께 물었다면 이 중 하나를 대화 단위로 승인할 때 함께 포함된 다른 항목도 승인됩니다.
- **Deny** — 중지합니다. 에이전트에게 거부되었음을 알리며, 재시도하거나 같은 일을 다른 방법으로 시도하지 말라고 전달합니다. 에이전트는 텍스트로 답하거나 먼저 사용자에게 묻습니다.

응답에 포함된 모든 카드에 답하면 응답이 즉시 계속됩니다.

응답 대신 새 메시지를 보내면 대기 중인 모든 카드는 **Deny**로 처리되고, 에이전트는 새 메시지에 응답합니다.

응답이 화면에 표시된 동안 카드에 답하세요. 편집기를 새로 고치면 카드가 다시 표시되지 않습니다. 새 메시지를 보내면 에이전트가 그 지점부터 이어서 진행합니다.

## "Approve for conversation" 유효 기간 (How long "Approve for conversation" lasts) {: #how-long-approve-for-conversation-lasts }

**Approve for conversation** 선택은 해당 선택을 한 스레드에만 적용됩니다. 새 스레드는 아무것도 승인되지 않은 상태로 시작되므로 에이전트가 다시 묻습니다.

스레드에 승인 항목이 있는 동안에는 모델 선택기 아래에 **Allowed in this chat** 줄이 표시되며 승인 항목이 나열됩니다. 해당 줄의 **Reset**을 클릭하면 모든 승인이 취소되고, 이후 에이전트는 다시 묻습니다.

에이전트가 한 단계에서 여러 작업을 함께 보내면, 그 단계를 대화 단위로 승인할 때 그 안의 각 작업이 개별적으로 승인됩니다. 예를 들어 플로우를 시작하는 단계를 승인하면, 같은 스레드에서 이후의 플로우 시작 요청은 다른 작업과 함께 묶여 있는지와 관계없이 묻지 않고 실행됩니다.
