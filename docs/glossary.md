# 아티스트 및 크리에이터를 위한 Griptape Nodes 용어집

## Griptape Nodes란 무엇인가요?

Griptape Nodes는 아티스트와 크리에이터가 깊은 기술적 전문 지식 없이도 AI 기반 프로젝트를 구축할 수 있도록 지원하는 툴킷입니다. Griptape Nodes를 예술 작품 제작, 이미지 생성, 텍스트 처리, 워크플로우 중심 애플리케이션 구축 등을 위해 서로 연결할 수 있는 일련의 빌딩 블록이라고 생각하시면 됩니다.

### 핵심 Griptape Nodes 개념

- **Workflow (워크플로우)**: 노드, 연결선, 설정값을 포함하는 문서입니다. 기술적으로 워크플로우도 스크립트의 일종이지만 스크립트라는 용어가 워크플로우와 명확히 다른 의미를 전달할 수 있도록 워크플로우를 스크립트라고 부르는 것은 지양합니다. 저장된 파일 자체를 부르는 말이기도 합니다.

- **Workflow Editor (워크플로우 에디터)**: 노드를 추가하고 연결하며 구성하는 작업 공간입니다.

- **Flow (플로우)**: 하나의 기능 단위를 구성하는 연결된 노드들의 집합입니다. 하나의 워크플로우는 0개 이상의 플로우를 포함할 수 있습니다.

- **Sub-Flow (서브 플로우)**: Loop, Branch, Reference (때로는 Group) 내에서 실행되는 독립된 노드 세트입니다. 응집력 있는 단위로 기능하는 논리적으로 구분되고 내부에 격리된 플로우 부분을 의미합니다.

- **Reference (레퍼런스)**: 다른 플로우에 대한 링크로, 현재 컨텍스트 내에 해당 플로우를 서브 플로우로 임베드합니다.

- **Group (그룹)**: 노드들의 시각적 클러스터링(묶음)입니다. 그룹이 하나의 단위로 실행되는 경우 서브 플로우 역할을 할 수 있지만 단순 그룹화 자체가 실행을 의미하는 것은 아니며 주관적으로 연관된 노드들의 집합일 수 있습니다.

- **Script (스크립트)**: 코드를 실행하는 Python 스크립트입니다. 워크플로우를 설명할 때 이 용어를 사용하는 것은 피해야 하며 도구, 매크로 또는 플로우 구축 보조 수단을 지칭할 때 사용됩니다.

- **Libraries (라이브러리)**: 기능을 확장하는 노드 정의 및/또는 스크립트의 모음입니다. 설치 및 관리는 [라이브러리](guides/libraries.md)를 참조하세요.

- **Node (노드)**: 워크플로우를 구성하는 퍼즐 조각 하나하나입니다. 노드는 더 큰 결과물을 만들기 위해 연결할 수 있는 레고 블록과 같습니다. 각 노드는 하나의 특정 작업(예: 이미지 생성, 텍스트 처리 등)을 수행합니다. 다음과 같은 **유형**이 있습니다:

    - **DataNode**: 정보를 처리하는 노드입니다. 데이터를 한 형태에서 다른 형태로 변환하거나 사용자가 설정한 데이터를 보관합니다.
    - **ControlNode**: "실제 작업(연산)"을 수행하는 노드입니다. ControlNode는 보통 더 많은 작업을 수행하므로 DataNode보다 실행 시간이 더 오래 걸립니다.
    - **DriverNode**: 프로젝트를 외부 서비스(이미지 생성기, 검색 엔진 등)에 연결하는 노드입니다.

- **Tool (도구)**: 특정 기능을 수행하는 즉시 사용 가능한 컴포넌트입니다. 디지털 도구 상자의 브러시와 같으며 각각 특정 목적을 위해 설계되었습니다.

    - **CalculatorTool**: 수학 계산을 수행합니다.
    - **DateTimeTool**: 날짜와 시간을 다룹니다.
    - **FileManagerTool**: 파일 관리(저장, 로드 등)를 지원합니다.
    - **WebScraperTool**: 웹사이트에서 정보를 수집합니다.
    - **PromptSummaryTool**: 긴 텍스트의 요약을 생성합니다.

- **Driver (드라이버)**: 프로젝트와 외부 AI 서비스 또는 데이터베이스 간의 연결자입니다. 프로젝트가 특화된 서비스와 통신할 수 있게 해주는 어댑터와 같습니다.

    - **PromptDriver**: AI 텍스트 생성기(GPT 모델 등)와 통신합니다.
    - **WebSearchDriver**: 검색 엔진에 연결하여 정보를 검색합니다.
    - **EmbeddingDriver**: 단어와 개념을 AI가 이해할 수 있는 수치 형태로 변환합니다.
    - **ImageGenerationDriver**: AI 이미지 생성기(DALL-E 등)에 연결합니다.
    - **AudioTranscriptionDriver**: 음성 오디오를 텍스트로 변환합니다.

- **Engine (엔진)**: 창의적인 요청을 처리하는 핵심 구동부입니다. 입력을 창의적인 출력으로 변환하는 특화된 컴포넌트입니다.

    - **RagEngine**: 제공된 정보를 기반으로 질문을 처리하고 답변을 생성합니다.
    - **PromptSummaryEngine**: 긴 텍스트의 간결한 요약을 생성합니다.
    - **CsvExtractionEngine**: 스프레드시트 형식의 파일에서 정보를 추출합니다.
    - **JsonExtractionEngine**: 구조화된 데이터 파일에서 정보를 추출합니다.

- **Artifact (아티팩트)**: 생성된 이미지나 텍스트처럼 프로젝트 실행 중에 생성되는 콘텐츠 조각입니다. 창의적인 프로세스의 출력물입니다.

    - **ErrorArtifact**: 문제가 발생했을 때 나타나는 알림입니다.

- **Agent (에이전트)**: 여러 도구를 조합하여 사용자를 대신해 작업을 수행할 수 있는 조력자입니다. 일련의 작업을 스스로 판단하여 진행하는 비서와 같습니다.

- **Ruleset (룰셋/규칙 세트)**: 프로젝트가 동작하는 방식을 제어하는 가이드라인 모음입니다. 다양한 상황에서 프로젝트가 어떻게 반응해야 하는지 알려주는 레시피와 같습니다.

    - **Rule (규칙)**: 룰셋 내의 단일 지침(예: "사용자가 이미지를 요청하면 이미지를 생성할 것")입니다.

### 노드 구성 및 활동

- **Parameter (파라미터)**: 노드에서 조정할 수 있는 설정이나 값입니다. 음악 신디사이저의 노브나 슬라이더처럼 동작 방식을 미세 조정할 수 있습니다.

    - **ParameterMode**: 파라미터가 입력용인지, 출력용인지, 내부용인지 또는 이들의 조합인지를 나타냅니다.
    - **ParameterValue**: 파라미터의 "내부" 값 (노드가 내부적으로 사용하는 데이터)
    - **ParameterOutputValues**: 파라미터의 결과 또는 "출력" 값 (노드의 동작 결과로 생성된 데이터)
    - **ParameterUIOptions**: 사용자 인터페이스에서 파라미터가 표시되는 방식에 대한 설정입니다.
    - **Port (포트)**: 파라미터의 왼쪽 및/또는 오른쪽에 표시되는 원형 표시기입니다. 왼쪽 포트는 들어오는 연결을 수락할 수 있음을 나타내고, 오른쪽 포트는 나가는 연결을 지원함을 나타냅니다.
    - **Pin (핀)**: "Port"와 동일한 의미로 혼용됩니다.

- **Default Value (기본값)**: 변경하기 전에 파라미터에 미리 설정되어 있는 값입니다. 기기의 공장 출하 초기 설정과 같습니다.

- **Parameter Validation (파라미터 유효성 검사)**: 입력한 값이 올바른지 확인하는 검사입니다. 숫자가 필요한 곳에 텍스트를 입력하는 등의 오류를 방지합니다.

- **Off-prompt (오프 프롬프트)**: LLM과 작업할 때도 특정 정보를 비공개로 안전하게 유지하는 Griptape만의 핵심 기법입니다.

- **Stream Mode (스트림 모드)**: 사진을 따로따로 찍는 대신 라이브 비디오 피드를 보는 것과 같은 연속 처리 모드입니다.

- **Type Hints (타입 힌트)**: 파라미터가 어떤 종류의 정보를 기대하는지 알려주는 라벨입니다. 미술 용품 상자에 안에 무엇이 들어있는지 적혀 있는 라벨과 같습니다.

    - **Any**: 파라미터가 모든 종류의 정보를 수락할 수 있음을 의미하는 타입 힌트입니다.
    - **List**: 항목들의 컬렉션(색상이나 모양의 배열 등)을 위한 타입 힌트입니다.
    - **Literal**: 파라미터가 특정 사전 설정 값만 수락함을 나타내는 타입 힌트입니다.
    - **Union type**: 파라미터가 여러 특정 유형의 정보를 수락할 수 있음을 나타내는 타입 힌트입니다.

- **Connection (연결)**: 노드들이 서로 통신할 수 있게 해주는 링크입니다. 서로 다른 장비들을 연결하는 케이블과 같습니다.

## 쉬운 기술 용어 설명

- **Data Types (데이터 유형)**:

    - **Dictionary (dict, 딕셔너리)**: 라벨과 값의 쌍으로 정보를 저장하는 방식입니다. 각 항목에 고유한 라벨이 붙어 있는 정리된 수납장과 같습니다.
    - **Key-Value Pair (키-값 쌍)**: 정보(값)와 그에 대응하는 라벨(키)의 묶음입니다. 딕셔너리는 키-값 쌍의 모음입니다.
    - **Integer (int, 정수)**: 5, -10, 1000과 같이 소수점이 없는 정수입니다.
    - **Float (float, 부동소수점수)**: 3.14, -0.5, 2.0과 같이 소수점이 있는 숫자입니다.
    - **String (str, 문자열)**: "hello", 'Python', "123"과 같이 따옴표로 묶인 텍스트입니다.
    - **Boolean (bool, 불리언)**: True 또는 False 중 하나를 나타냅니다.
    - **List (list, 리스트)**: [1, 2, 3]이나 ["apple", "banana", "cherry"]처럼 수정 가능한 순서가 있는 항목 모음입니다.
    - **Tuple (tuple, 튜플)**: (1, 2, 3)이나 ("red", "green", "blue")처럼 생성 후 수정할 수 없는 순서가 있는 항목 모음입니다.
    - **Set (set, 세트/집합)**: {1, 2, 3}이나 {"apple", "banana", "cherry"}처럼 중복되지 않는 고유 항목들의 순서 없는 모음입니다.
    - **None (NoneType)**: 값이 없거나 null 상태를 나타냅니다.

- **Environment Variable (환경 변수)**: 컴퓨터가 프로그램에 중요한 정보를 전달하기 위해 보관하는 메모와 같습니다.

- **API Key (API 키)**: AI 이미지 생성기와 같은 외부 서비스에 대한 프로젝트의 접근 권한을 부여하는 특수 비밀번호입니다. 특정 온라인 서비스를 이용할 수 있게 해주는 회원증과 같습니다.

<a id="secret-keys"></a>

- **Secret Keys (비밀 키)**: 안전하게 보관해야 하지만 특정 작업에 반드시 필요한 API 토큰, 비밀번호, 액세스 키 등의 개인 자격 증명입니다.
- **Secrets Manager (비밀 정보 관리자)**: 비밀 키가 유출되지 않고 *안전하게* 유지되도록 관리하는 실제 메커니즘입니다.

<a id="configuration-settings"></a>

- **Configuration Settings (구성 설정)**: Griptape Nodes 엔진과 그 구성 요소가 동작하는 방식을 제어하는 파라미터 및 옵션입니다.

<a id="project-files"></a>

- **Project Files (프로젝트 파일)**: Griptape 프로젝트를 구성하는 문서, 스크립트 및 기타 리소스입니다.

<a id="generated-assets"></a>

- **Generated Assets (생성된 에셋)**: 출력물, 보고서, 시각화 등 실행 중에 Griptape Nodes 엔진에 의해 생성된 파일 및 데이터입니다.

<a id=".env"></a>

- **.env**: 환경 변수, 특히 API 키와 같은 민감한 정보를 저장하는 데 사용되는 특수 파일입니다.

## 아티스트를 위한 AI 용어

- **Temperature Control (온도 조절)**: AI의 응답이 얼마나 창의적일지 또는 예측 가능할지를 제어하는 설정입니다. 온도가 낮을수록 예측 가능하고, 온도가 높을수록 창의적이고 다양해집니다.

- **Embedding Model (임베딩 모델)**: 단어, 이미지 또는 기타 콘텐츠를 그 의미를 담은 숫자로 변환하는 AI 도구입니다. 이를 통해 AI가 서로 다른 개념 간의 관계를 이해할 수 있습니다.

- **LLM (Large Language Model, 대규모 언어 모델)**: 인간과 유사한 언어를 이해하고 생성할 수 있도록 방대한 양의 텍스트 데이터로 학습된 AI 시스템입니다. LLM은 글 작성, 질문 답변, 정보 요약, 창의적 콘텐츠 생성 등을 수행할 수 있습니다.

- **NLP (Natural Language Processing, 자연어 처리)**: 컴퓨터가 인간의 언어를 이해하고 생성할 수 있도록 돕는 AI 분야입니다.

- **Prompt (프롬프트)**: AI 모델을 안내하기 위해 제공하는 입력 텍스트입니다. 아티스트에게는 크리에이티브 브리프나 공동 작업자에게 주는 지침과 유사합니다.

- **Vector Store (벡터 저장소)**: 단순한 정보뿐만 아니라 의미와 관계를 포착하는 방식으로 정보를 저장하는 특수 데이터베이스입니다.

- **Diffusion Models (디퓨전 모델)**: 텍스트 설명을 기반으로 무작위 노이즈를 점진적으로 정교한 시각 이미지로 변환하여 이미지를 생성하는 AI 시스템입니다. 대표적인 예로 Stable Diffusion과 Midjourney가 있습니다.

- **Text-to-Image Generation (텍스트-이미지 생성)**: 작성된 설명을 바탕으로 이미지를 생성하여 아티스트가 텍스트 프롬프트를 통해 개념을 시각화할 수 있도록 하는 기술입니다.

- **Style Transfer (스타일 전송/변환)**: 한 이미지(예: 유명한 그림)의 시각적 스타일을 다른 이미지의 내용에 적용하는 AI 기술입니다.

- **Inpainting/Outpainting (인페인팅/아웃페인팅)**: 주변 맥락을 기반으로 이미지의 누락된 부분을 채우거나(Inpainting) 원본 테두리 너머로 확장하는(Outpainting) 도구입니다.

- **Fine-tuning (파인 튜닝/미세 조정)**: 사전 학습된 AI 모델을 특정 스타일, 주제 또는 예술적 요소를 인식하고 생성하도록 맞춤 조정하는 과정입니다.

- **Latent Space (잠재 공간)**: AI 모델이 개념을 구성하는 수학적 표현 공간입니다. 아티스트는 이 공간을 탐색하여 아이디어 간의 창의적인 변형과 전환을 찾을 수 있습니다.

- **Tokens (토큰)**: AI 언어 모델이 텍스트를 처리하는 기본 단위로 단어 또는 단어의 일부분과 유사합니다. 토큰 한도를 이해하면 효과적인 프롬프트를 작성하는 데 도움이 됩니다.

- **Multimodal AI (멀티모달 AI)**: 여러 유형의 콘텐츠(텍스트, 이미지, 오디오)를 동시에 처리할 수 있는 시스템으로 더욱 통합된 창작 워크플로우를 가능하게 합니다.

- **LoRA (Low-Rank Adaptation, 로라)**: 아티스트가 방대한 컴퓨팅 자원 없이도 특정 스타일에 맞게 AI 모델을 학습시킬 수 있는 기법입니다.

- **Sampling Methods (샘플링 방식)**: AI가 이미지를 생성하는 방식을 제어하는 다양한 알고리즘(DDIM, Euler 등)으로 디테일 수준, 창의성 및 일관성에 영향을 미칩니다.

## 유용한 프로그래밍 개념

- **Callback (콜백)**: 특정 이벤트가 발생할 때 자동으로 실행되는 함수입니다. 움직임이 감지되면 사진을 찍도록 카메라를 설정하는 것과 같습니다.

- **Custom Parameter Types (사용자 지정 파라미터 유형)**: 특정 프로젝트 요구사항에 맞게 정의할 수 있는 특화된 설정입니다.

- **Exception Handling (예외 처리)**: 프로젝트에서 오류를 처리하는 방식입니다. 문제가 발생했을 때를 대비한 백업 계획을 갖추는 것과 같습니다.

    - **Authentication Error (인증 오류)**: 프로젝트가 서비스 이용 권한이 있음을 증명하지 못할 때 발생하는 오류입니다.
    - **KeyError (키 오류)**: 잘못된 라벨을 사용하여 정보에 접근하려고 할 때 발생하는 오류입니다.
    - **SyntaxError (구문 오류)**: 코드의 잘못된 형식으로 인해 발생하는 오류입니다.
    - **ValueError (값 오류)**: 부적절한 값을 사용하려고 할 때 발생하는 오류입니다.

- **Metadata (메타데이터)**: 콘텐츠나 컴포넌트에 대한 추가 정보입니다. 디지털 사진 파일에 저장된 정보(카메라 종류, 촬영 날짜 등)와 같습니다.

## 추가 용어

- **Python (파이썬)**: Griptape이 구축된 대중적인 프로그래밍 언어입니다. 다른 프로그래밍 언어에 비해 읽고 이해하기 쉬운 것으로 잘 알려져 있습니다.

- **API (Application Programming Interface)**: 서로 다른 소프트웨어 애플리케이션이 서로 통신할 수 있도록 해주는 규칙 모음입니다. 아티스트에게는 다양한 오디오 장비가 서로 호환되도록 해주는 표준화된 커넥터와 같습니다.

- **JSON (JavaScript Object Notation)**: 데이터를 저장하고 전송하기 위한 일반적인 형식입니다. 정보를 정리하기 위한 표준화된 템플릿과 같습니다.

- **CSV (Comma-Separated Values)**: 스프레드시트 데이터와 같은 표 형식 데이터를 저장하는 간단한 파일 형식입니다. 각 줄은 행을 나타내고 쉼표는 각 열의 값을 구분합니다.

- **UI (User Interface, 사용자 인터페이스)**: 사용자가 소프트웨어와 상호작용할 수 있도록 해주는 시각적 요소와 컨트롤입니다. 버튼, 슬라이더, 텍스트 필드 등이 포함됩니다. Griptape Nodes에서는 UI를 "Editor(에디터)"라고 부릅니다.

- **Framework (프레임워크)**: 애플리케이션을 더 쉽게 구축할 수 있도록 구조와 기능을 제공하는 사전 구축된 코드 세트입니다. 필요한 기본 재료와 도구가 갖춰진 미술 용품 키트와 같습니다.
